## 최초 전환 요청과 범위

사용자가 지정한 `AGENT/`와 `ㅁㄴㅇㅁㄴㅇㅁㄴㅇㅁㄴㅇ/`의 문서를 변경한다. 작업 시작 시 Git 변경은 없었다. 작업 전 문서 142개(AGENT 136개·조사 6개)의 내용을 확보하고 이전 턴의 전체 학습 결과와 대조했다.

최초 전환 당시 루트 AGENTS.md·prompt.md·README.md와 BE·FE 문서는 후속 전환 대상으로 남겼다. 아래 최초 검증 기록은 그때의 두 경로 범위에 대한 결과이며, 같은 날 이어진 루트·BE·FE 정비 결과는 마지막 절에 따로 기록한다. TODO·TODO_LOG와 그 링크 대상은 읽거나 수정하지 않는다. 코드·schema·migration·환경·DB·외부 계정 설정·커밋은 변경하지 않는다.

## 반영 내용

- Bonsai 전체 기능·UX 재현 후 차별화, Gummble 화면 조사 기준.
- 대표·영업·운영·프로젝트 담당자·실무자·외부 고객의 시나리오.
- 고객·거래·견적·문서·수행·시간·청구·입금 등 21개 초기 기능군.
- 공식 출처·API 참고, Gummble·실계정 미확인 상태.
- PM·UX·Software·DB 전환과 기존 32개 모델 처리 후보.
- 기존 구현·검증의 날짜와 현재 목표를 분리.
- 작업 시작 로그/완료 판정의 구분, COMMON 폴더 허용, 모바일 테이블 일괄 금지 해소.
- OneHand 자체 이용료 과금과 고객에게 보내는 청구·입금 기능을 구분하고 과거 베타 순서를 새 선행 조건에서 분리.
- 이전 제품명이 있는 여섯 문서와 과거 비교 파일의 이름·내부 참조 정리.

## 최초 전환 검토 경계

현재 구현의 32개 모델·51개 handler·기존 테스트 결과는 이전 소스 확인 기록이다. 이번에는 실행 코드·실제 DB를 재검증하지 않는다. Gummble 앱·화면·flow 검색과 Bonsai 실계정 조작도 하지 않았다.

최초 전환 당시 범위 밖 문서에 이전 제품 기준과 이전 파일명 참조가 남아 있었다. 후속 정비에서는 호환용 이전 제품명 파일을 다시 만들지 않고 사용자의 최신 방향과 [PM 036](../../PM_AGENT/DECISIONS/036_bonsai_benchmark_transition.md)을 적용한다.

## 루트·BE·FE 후속 문서 정비

2026-11-17 사용자 요청으로 남아 있던 제품·조사 기준을 통일했다. 작업 시작 시 Git 변경은 없었으며, 최초 전환에서 남겼던 루트 지침과 BE·FE 문서 21개를 수정했다. 이 검토 기록과 PM 036·ROADMAP도 후속 범위에 맞춰 갱신하여 총 24개 Markdown 파일을 변경했다.

- 루트 제품 방향·에이전트 지침·작업 프롬프트를 Bonsai·Gummble 기준으로 연결한다.
- 연락처·그룹 중심의 기존 목표 설명을 고객·거래·견적·문서·수행·청구·입금의 업무 의미에 맞게 수정한다.
- BE·FE의 전환 결정·기능 대응표·DB 계획·UX·전환 영향 링크를 현재 파일에 연결한다.
- Figma가 필수 선행 단계가 아니며 기능별 화면 제작과 계약 설계를 병행한다는 기준을 루트에도 반영한다.
- 기존 코드의 동작, 운영 URL, 과거 검증 날짜·결과는 이번 제품 검증 결과로 바꾸지 않는다.
