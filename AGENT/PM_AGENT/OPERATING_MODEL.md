# 역할별 문서 운영

현재 기준은 [folk 전환 결정](DECISIONS/036_folk_benchmark_transition.md)이다.

| 역할 | 책임 | 주요 산출물 |
| --- | --- | --- |
| PM | 최종 범위·단계·수용 기준 | PRD, 기능 대응표, 결정 |
| UXUI | 원본 근거·흐름·화면·상태 | Nicelydone/실계정 조사, 화면 계약 |
| Software | API·DB·FE/BE·검증 | 전환 영향, schema 제안, 기술 계약 |

## 작업 흐름

1. 기능 대응표에서 작업 대상과 현재 차이를 확인한다.
2. 화면과 공식 자료의 버전·권한·동작을 대조한다.
3. mock 흐름을 검토하며 데이터 의미를 함께 정한다.
4. API·DB·권한·오류 계약을 연결한다.
5. 기능 단위로 구현·검증하고 기존 의존을 제거한다.
6. 완료·미확인·차이를 관련 정본에 반영한다.

기존 작업 계획 폴더 운영은 [문서 규칙](CONVENTION/DOCUMENTATION.md)을 따른다. 사용자가 특정 폴더를 제외하면 링크를 통해 우회해서 읽거나 수정하지 않는다. 이번 문서 정비에서 TODO·TODO_LOG는 제외한다.

제품/UX/기술 문서 충돌은 하나의 파일만 수정하지 않고 모든 영향을 맞춘다. 과거 결정은 삭제하지 않고 대체 상태를 표시한다.
