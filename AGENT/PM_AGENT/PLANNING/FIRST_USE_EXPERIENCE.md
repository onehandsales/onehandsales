# First Use Experience

Status: 실제 화면 관찰 후 상세 확정
Updated: 2026-11-17

Bonsai 가입·초대 참여부터 첫 업무 기록 저장까지 조사한다. 기존 직군·Kit 선택을 필수 단계로 두지 않는다.

- 신규 계정과 초대받은 멤버의 진입 차이.
- 회사/업무 공간 설정, 기본 탐색, 가져오기·연동 안내와 건너뛰기.
- 첫 고객·담당자·거래 또는 프로젝트 생성 경로.
- 저장·뒤로가기·재진입·첫 기록 재조회.
- 대표·영업·프로젝트 담당자의 초기 권한 차이.

이는 조사 항목이며 실제 화면 순서를 확인한 결과가 아니다. [UX 흐름](../../UXUI_AGENT/PLANNING/FIRST_USE_FLOW.md)에 Gummble 식별자와 실계정 관찰을 연결한다. 기존 직업 선택 UI와 온보딩 완료 처리는 [현재 구현](IMPLEMENTATION_STATUS.md)의 기록으로 구분한다.
