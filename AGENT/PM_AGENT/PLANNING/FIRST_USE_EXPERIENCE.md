# First Use Experience

Status: 조사 후 상세 확정
Date: 2026-11-15

가입부터 첫 저장·재조회까지 folk의 실제 흐름을 기준으로 한다. 직군별 Kit 선택·미리보기를 필수 단계로 두던 기존 방침은 대체됐다.

## 조사할 흐름

- 가입·인증·Workspace 생성 또는 초대 수락.
- 기본 화면, 연락처 연결/가져오기 권유와 건너뛰기.
- Group 생성 및 People/Companies의 기본 탭·보기.
- 첫 연락처 저장 후 상세·목록에서 확인.
- 필드·작업·메모로 이어지는 다음 행동.

이 순서를 실제 folk 온보딩으로 확인한 것은 아니다. 조사 체크리스트이며 Nicelydone/실계정 관찰로 순서와 필수 여부를 확정한다.

현재 직업 선택 UI는 기존 구현이고, folk 기준 온보딩 전환 완료가 아니다. [UX 흐름](../../UXUI_AGENT/PLANNING/FIRST_USE_FLOW.md)과 [구현 현황](IMPLEMENTATION_STATUS.md)을 함께 본다.
