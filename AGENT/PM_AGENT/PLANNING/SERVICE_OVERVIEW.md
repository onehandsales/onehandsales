# 서비스 기획 개요

OneHand CRM은 직업별 업무 흐름에 맞는 CRM을 처음부터 완성된 형태로 제공하는 서비스를 지향한다.

현재 구현은 고정형 고객사 관리 기능을 제거한 전환 상태이며, 인증/계정/지원 접수/공개 문의 foundation을 유지한다.

## 대상 사용자

- 1인 사업자와 개인 영업자
- 부동산 중개, 보험/재무 상담, 헤드헌팅, 프리랜서, 교육/코칭처럼 직업별 고객 관리 흐름이 뚜렷한 사용자
- 복잡한 설정형 CRM보다 바로 쓸 수 있는 업무 흐름을 원하는 사용자

## 핵심 문제

- 직업마다 필요한 고객 기록, 상담 기록, 후속 연락, 상태 관리 방식이 다르다.
- 빈 CRM을 직접 설계해야 하면 시작 비용이 크다.
- 모바일과 데스크톱에서 같은 업무 흐름을 안정적으로 이어가야 한다.

## 현재 구현 요약

- BE는 인증/세션, 사용자 프로필, 오류 신고, 지원 문의, 공개 문의, health check, 관리자 권한 확인을 제공한다.
- FE/user-web은 `/app` 빈 홈, `/app/more`, 계정 설정 모달, 도움말 접수, 공개 문의, locale 공개 사이트를 제공한다.
- FE/admin-web은 access token 입력 후 `/admin/api/me` 확인 흐름만 유지한다.
- Prisma schema는 User/Auth session과 지원 접수 계열 모델만 남긴다.

## 후속 방향

다음 CRM 코어는 기존 고정 테이블을 되살리지 않고 Workspace/Object/Attribute/Record/List/View 기반으로 설계한다.
