# 서비스 기획 개요

onehand.sales는 개인 영업자가 회사 정보를 빠르게 정리하고 다시 찾을 수 있도록 돕는 경량 CRM이다.

## 대상 사용자

- 여러 고객사를 혼자 관리하는 개인 영업자
- 고객사별 메모와 주소/지역/분야를 빠르게 정리해야 하는 소규모 사업자
- 복잡한 팀 CRM보다 빠른 입력과 검색이 중요한 사용자

## 핵심 문제

- 고객사 정보가 메신저, 메모, 스프레드시트에 흩어진다.
- 회사별 메모가 기본 정보와 분리되어 추적이 어렵다.
- 모바일과 데스크톱에서 같은 업무 데이터를 빠르게 찾아야 한다.

## 주요 도메인

- 회사: 고객사 기본 정보, 분야, 지역, 메모
- 검색: 회사 데이터 조회
- 휴지통: 삭제 항목 미리보기와 복구

## 현재 구현 요약

- BE는 회사 API, 검색/휴지통, 지원 접수, 관리자 권한 확인을 제공한다.
- FE/user-web은 `/app` 이후 홈/회사/휴지통/더보기와 계정 모달을 제공한다.
- FE/admin-web은 access token 입력 후 `/admin/api/me` 확인 흐름만 유지한다.
- Prisma schema는 현재 활성 도메인 모델만 남긴다.
