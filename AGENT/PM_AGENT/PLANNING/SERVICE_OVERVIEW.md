# 서비스 기획 개요

onehand.sales는 개인 영업자가 회사, 담당자, 제품, 딜을 빠르게 정리하고 다음 행동을 놓치지 않도록 돕는 경량 CRM이다.

## 대상 사용자

- 여러 고객사와 담당자를 혼자 관리하는 개인 영업자
- 제품 또는 제안 단위로 딜을 추적해야 하는 소규모 사업자
- 복잡한 팀 CRM보다 빠른 입력과 명확한 딜 상태가 중요한 사용자

## 핵심 문제

- 고객과 딜 정보가 메신저, 메모, 스프레드시트에 흩어진다.
- 다음 행동과 메모가 딜 상태와 분리되어 추적이 어렵다.
- 모바일과 데스크톱에서 같은 업무 데이터를 빠르게 찾아야 한다.

## 주요 도메인

- 회사: 고객사 기본 정보, 분야, 지역, 메모
- 담당자: 연락처, 소속, 직급/부서, 메모
- 제품: 제품명, 가격, 카테고리, 상태, 메모
- 딜: 단계, 금액, 연결 회사/담당자/제품, 다음 행동, 활동 로그
- 검색: 주요 업무 데이터 통합 조회
- 휴지통: 삭제 항목 미리보기와 복구

## 현재 구현 요약

- BE는 핵심 도메인 API와 제품 분석, 지원 접수, 관리자 권한 확인을 제공한다.
- FE/user-web은 `/app` 이후 핵심 CRM 화면과 계정 모달을 제공한다.
- FE/admin-web은 access token 입력 후 `/admin/api/me` 확인 흐름만 유지한다.
- Prisma schema는 현재 활성 도메인 모델만 남긴다.
