# Success Metrics

Status: Proposed verification metrics
Updated: 2026-11-17

Bonsai 전체 재현의 조사·구현·검증 수준을 따로 측정한다. 수집한 실제 측정값이나 확정 목표 수치는 아직 없다.

| 관점 | 측정 |
| --- | --- |
| 조사 | 기능 목록 중 공식 출처·화면·관찰 조건이 기록된 항목 수 |
| 구현 | 계약과 실행 코드가 연결된 기능 수 |
| 검증 | 저장·재조회·권한·오류·계산까지 검증한 흐름 수 |
| UX | 원본 대비 화면·문구·상호작용 차이와 미확인 상태 수 |
| 연결성 | 거래·견적·문서·프로젝트·청구 간 값·상태 불일치 수 |
| 접근 제어 | Workspace·멤버·고객 포털 간 노출 오류 수 |
| 운영 | 외부 연동 실패·중복 처리·재시도 및 실제 실행 검증 상태 |

분모인 전체 세부 기능 목록은 조사하면서 확장한다. 목록 미수집을 기능 완료로 계산하지 않는다. 고객 활성화·구매·매출 지표는 이후 판매 타깃과 출시 범위를 정할 때 정의한다.
