# PRD

## 제품 정의

onehand.sales는 개인 영업자를 위한 경량 CRM이다. 현재 구현은 회사 정보를 빠르게 기록하고, 메모와 검색으로 다시 찾고, 삭제한 회사 데이터를 복구할 수 있게 하는 데 집중한다.

## 주 타겟

- 혼자 여러 고객을 관리하는 B2B/B2C 영업자
- 고객사 기록과 후속 메모를 빠르게 정리해야 하는 소규모 사업자
- 스프레드시트보다 빠르고 모바일 친화적인 업무 기록이 필요한 사용자

## 핵심 가치

- 입력할 곳이 명확하다.
- 회사의 메모 흐름이 상세 화면에서 이어진다.
- 회사 검색과 상세 이동이 빠르다.
- 삭제한 데이터는 짧은 복구 기간 안에서 되돌릴 수 있다.

## MVP 포함 기능

- OAuth 로그인과 앱 세션
- 내 프로필, 기기, 세션 관리
- 회사 CRUD, 메모, 개인 비밀 메모
- 회사 xlsx export
- 회사 검색
- 휴지통
- 오류 신고, 지원 문의, 공개 문의
- 관리자 권한 확인 API

## 성공 기준

- 신규 사용자가 `/app`에서 회사를 생성하고 상세 정보를 보강할 수 있다.
- 사용자가 검색으로 주요 데이터를 다시 찾을 수 있다.
- 삭제와 복구 정책이 도메인별로 일관된다.
- 현재 문서와 코드 범위가 일치한다.
