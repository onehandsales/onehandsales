# PRD

## 제품 정의

onehand.sales는 개인 영업자를 위한 경량 CRM이다. 현재 구현은 회사 정보를 빠르게 기록하고, 검색과 export로 다시 활용할 수 있게 하는 데 집중한다.

## 주 타겟

- 혼자 여러 고객을 관리하는 B2B/B2C 영업자
- 고객사 기본 정보를 빠르게 정리해야 하는 소규모 사업자
- 스프레드시트보다 빠르고 모바일 친화적인 업무 기록이 필요한 사용자

## 핵심 가치

- 입력할 곳이 명확하다.
- 회사 기본 정보를 목록과 상세 화면에서 빠르게 확인한다.
- 회사 검색과 상세 이동이 빠르다.
- 회사 데이터를 XLSX로 내보낼 수 있다.

## MVP 포함 기능

- OAuth 로그인과 앱 세션
- 내 프로필, 기기, 세션 관리
- 회사 생성/조회/수정, 회사 분야/지역 옵션
- 회사 xlsx export
- 회사 검색
- 오류 신고, 지원 문의, 공개 문의
- 관리자 권한 확인 API

## 성공 기준

- 신규 사용자가 `/app`에서 회사를 생성하고 상세 정보를 보강할 수 있다.
- 사용자가 검색으로 주요 데이터를 다시 찾을 수 있다.
- 현재 남은 API와 화면만 사용자에게 노출된다.
- 현재 문서와 코드 범위가 일치한다.
