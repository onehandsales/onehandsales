# PRD

## 제품 정의

onehand.sales는 개인 영업자를 위한 경량 CRM이다. 사용자는 회사, 담당자, 제품, 딜을 연결하고 다음 행동과 메모를 딜 중심으로 관리한다.

## 주 타겟

- 혼자 여러 고객을 관리하는 B2B/B2C 영업자
- 제품 또는 제안 단위로 거래 흐름을 추적하는 소규모 사업자
- 스프레드시트보다 빠르고 모바일 친화적인 업무 기록이 필요한 사용자

## 핵심 가치

- 입력할 곳이 명확하다.
- 딜 상태와 다음 행동이 한 화면에서 이어진다.
- 회사/담당자/제품/딜을 서로 연결해 검색과 상세 이동이 빠르다.
- 삭제한 데이터는 짧은 복구 기간 안에서 되돌릴 수 있다.

## MVP 포함 기능

- OAuth 로그인과 앱 세션
- 내 프로필, 기기, 세션 관리
- 회사/담당자/제품/딜 CRUD
- 딜 다음 행동, 메모, 활동 로그
- 도메인별 xlsx export
- 통합검색
- 휴지통
- 오류 신고, 지원 문의, 공개 문의
- 제품 분석 이벤트 수집
- 관리자 권한 확인 API

## 성공 기준

- 신규 사용자가 `/app`에서 핵심 데이터를 생성하고 딜까지 연결할 수 있다.
- 사용자가 검색으로 주요 데이터를 다시 찾을 수 있다.
- 삭제와 복구 정책이 도메인별로 일관된다.
- 현재 문서와 코드 범위가 일치한다.
