# PRD

## 제품 정의

OneHand CRM은 사용자의 직업과 업무 흐름에 맞는 CRM을 처음부터 완성된 형태로 제공하는 서비스를 지향한다.

현재 구현은 고정형 고객사 관리 기능을 제거한 뒤, 인증/계정/지원 접수/공개 문의 foundation만 유지하는 전환 상태다.

## 주 타겟

- 혼자 고객, 문의, 계약, 후속 연락을 관리하는 1인 사업자와 개인 영업자
- 부동산 중개, 보험/재무 상담, 헤드헌팅, 프리랜서, 교육/코칭처럼 직업별 업무 구조가 뚜렷한 사용자
- 스프레드시트보다 바로 쓸 수 있는 업무형 CRM을 원하는 사용자

## 핵심 가치

- 가입과 로그인 흐름이 안전하다.
- 사용자는 자기 계정, 표시 언어, 시간대, 기본 국가/통화, 로그인 기기를 확인할 수 있다.
- 서비스 도입 문의와 지원 요청이 제품 안팎에서 접수된다.
- 다음 CRM 코어는 직업별 record와 view를 유연하게 만들 수 있어야 한다.

## 현재 포함 기능

- OAuth 로그인과 앱 세션
- 내 프로필, 기기, 세션 관리
- 오류 신고, 지원 문의, 공개 문의
- 관리자 권한 확인 API
- `/app` 빈 홈과 `/app/more` 더보기 화면
- locale 기반 공개 사이트

## 성공 기준

- 현재 남은 API와 화면만 사용자에게 노출된다.
- 현재 문서와 코드 범위가 일치한다.
- 공개 문의의 회사명/회사 규모 입력은 유지된다.
- 다음 CRM 코어를 설계할 때 기존 고정 테이블에 의존하지 않는다.
