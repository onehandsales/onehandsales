## 첫 구현 단위 제안

Workspace 진입 → Group 생성 → Person/Company 등록·추가 → Table 조회·필드 편집 → Pipeline 분류 → 상세 확인을 하나의 완결된 흐름으로 검증한다. 이후 메모·작업·커스텀 객체 및 연동을 연결한다.

“1개월에 folk 전체 완성”은 확정 일정이 아니다. 화면 수집 후 작업량을 산정한다. 진행률은 확인한 흐름 수/전체 조사 목록, 구현·검증 완료 수를 따로 기록한다.

## 기능별 완료 기준

- 화면 및 공식 동작 근거가 연결되어 있다.
- 입력·출력·오류·권한·삭제 영향이 계약에 있다.
- 실제 저장 후 새로고침·다른 화면에서도 일관된다.
- 원본과 다른 동작을 임의로 동등 구현으로 처리하지 않는다.
- 미확인 기능은 삭제하거나 완료 처리하지 않고 조사 대기로 남긴다.
