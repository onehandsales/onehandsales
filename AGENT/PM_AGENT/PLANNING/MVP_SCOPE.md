# MVP 기능 범위

현재 MVP는 로그인 이후 핵심 CRM 관리에 집중한다.

## 포함

- OAuth 기반 로그인과 앱 세션 관리
- 내 프로필, 연결 계정, 로그인 기기, 세션 관리
- 회사 CRUD, 메모, 비밀 메모, xlsx export
- `/app` 홈의 핵심 데이터 요약
- 회사 검색
- 휴지통 목록, 미리보기, 복구
- 오류 신고, 지원 문의, 공개 문의
- 관리자 access token 권한 확인

## 제외

- 팀/조직 권한 구조
- 결제와 구독 운영 화면
- 대량 데이터 관리 기능
- 외부 업무 도구 양방향 연동

## 완료 기준

- 남은 기능이 BE/FE/Prisma에서 모두 빌드된다.
- 사용자 화면의 `/app` 이후 route가 현재 활성 기능만 노출한다.
- 문서와 코드의 도메인 목록이 일치한다.
