# 첫 구현 범위

Status: Proposed first delivery / 전체 목표와 구분
Updated: 2026-11-17

최종 목표는 Bonsai 전체 기능·UX 재현이다. 기존 파일명은 유지하지만 이 문서는 축소된 최종 제품이 아닌 첫 검증 단위를 설명한다.

## 첫 단위 제안

계정·업무 공간 진입 → 고객 회사·담당자 등록 → 거래 생성·단계 변경 → 거래 상세·후속 작업 확인 → 재조회.

이후 같은 고객의 견적·합의 문서·프로젝트·작업·시간·청구·입금까지 연결한다. 상세 화면과 입력 순서는 Gummble 및 실제 계정 근거로 정하며 위 순서를 원본의 필수 온보딩으로 보지 않는다.

## 첫 단위의 검증

데이터 소유·권한, 중복 제출, 저장 실패·재시도, 다른 Workspace 접근 차단, 목록/상세/새로고침 후 일관성을 검증한다. 기존 로그인·세션 정책을 임의로 변경하지 않는다.

## 전체 범위 유지

고객 포털, 반복 작업·청구, 인력 배정, 비용·예산·보고서, 자동화·연동·설정·AI 등은 [기능 대응표](BONSAI_FEATURE_PARITY_MATRIX.md)에 유지한다. 미확인 기능을 제외로 처리하지 않는다.

mock은 계약 확정 전에 만들 수 있다. 실연동은 해당 기능의 API·DB·권한·계산·상태 계약을 먼저 확정한다. 특정 직군·Kit 선정이나 Gummble 연결 완료가 문서 조사 전체를 막는 조건은 아니다.
