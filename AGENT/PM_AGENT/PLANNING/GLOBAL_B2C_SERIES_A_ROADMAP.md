# Global B2C Roadmap

현재 로드맵은 피벗 후 foundation 안정화와 다음 CRM 코어 설계에 맞춘다.

## 1차 목표

- 인증/세션/계정 설정 foundation 안정화
- 로그인 이후 `/app` 빈 홈과 `/app/more` 품질 안정화
- 지원/오류 신고와 공개 문의 flow 검증
- 직업별 CRM 코어의 Workspace/Object/Attribute/Record/List/View 모델 결정

## 보류 목표

- 고정형 고객사 관리 재도입
- 팀/조직 기능
- 결제/구독
- 외부 도구 연동
- 대량 데이터 운영 기능
