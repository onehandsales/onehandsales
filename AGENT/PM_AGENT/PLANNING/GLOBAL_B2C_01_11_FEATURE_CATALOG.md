# Global B2C Feature Catalog

피벗 이후 이 문서는 현재 활성 기능만 요약한다.

## 활성 기능

- OAuth 로그인과 앱 세션
- 사용자 프로필, 연결 계정, 기기, 세션 관리
- `/app` 빈 홈과 `/app/more`
- 오류 신고, 지원 문의, 공개 문의
- 관리자 권한 확인
- locale 기반 공개 사이트

## 보류 범위

- Workspace/Object/Attribute/Record/List/View 기반 CRM 코어
- 팀 협업과 조직 권한
- 결제/구독
- 대량 데이터 운영
- 외부 업무 도구 연동
