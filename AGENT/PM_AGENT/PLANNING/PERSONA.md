# Persona

## 1차 핵심 페르소나

개인 영업자 또는 소규모 사업자. 혼자 고객사, 담당자, 제품, 딜을 관리하며 빠른 입력과 명확한 다음 행동 추적이 필요하다.

## 행동 특성

- 고객과 거래 정보를 여러 도구에 나눠 적는다.
- 이동 중에도 핵심 정보를 확인해야 한다.
- 복잡한 CRM 설정 대신 바로 입력하고 찾는 흐름을 선호한다.
- 딜 단계와 다음 행동이 분리되면 업무 누락이 생긴다.

## 필요한 화면

- 홈 요약
- 회사/담당자/제품/딜 목록
- 딜 상세와 다음 행동
- 통합검색
- 휴지통
- 계정 관리
