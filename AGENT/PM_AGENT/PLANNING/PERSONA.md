# Persona

Status: 역할별 조사 시나리오 / 판매 타깃 미확정
Updated: 2026-11-17

Bonsai 전체 재현을 먼저 진행한다. 대표나 회사의 영업사원도 사용 시나리오에 포함된다. 서비스 사업자를 설명하는 Bonsai의 제품 소개를 OneHand CRM의 특정 업종·규모 제한으로 옮기지 않는다.

| 역할 | 확인할 업무 | 권한에서 확인할 것 |
| --- | --- | --- |
| 대표·책임자 | 거래 현황, 프로젝트 손익, 미수금, 팀 운영 | 전체 데이터·재무·설정 접근 |
| 영업 담당자 | 회사·담당자, 거래·후속 연락, 견적·제안 | 담당 범위, 견적 작성·발송 권한 |
| 운영·프로젝트 담당자 | 작업·일정·인력·예산 관리 | 프로젝트 접근과 재무 정보의 구분 |
| 실무자 | 배정 작업, 시간 기록, 파일·댓글 | 자기 일·공유된 프로젝트 접근 |
| 외부 고객 | 문서 확인·서명, 자료 전달, 청구·결제 | 해당 고객에게 공유한 정보만 접근 |

이 표의 직무는 Bonsai 기본 권한 프로필 이름과 동일하지 않다. 공식 역할·사용자 정의 권한은 [근거 B23](../../UXUI_AGENT/PLANNING/BONSAI_BENCHMARK_RESEARCH.md)과 실계정으로 대조한다.

개발·디자인·청소 사례는 이해를 위한 예시다. 구매 수요나 지원 업종을 확정하는 근거가 아니다. [이전 직군 가설](../PERSONA/TARGET_OCCUPATION_PERSONAS.md)은 역사 자료이며 첫 Kit을 요구하지 않는다.
