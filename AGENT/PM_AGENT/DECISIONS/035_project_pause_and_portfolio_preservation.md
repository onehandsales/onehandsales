# OneHand CRM 개발 보류와 포트폴리오 보존

- 결정일: 2026-11-14
- 상태: 사용자 결정 반영

## 1. 결정

OneHand CRM은 서비스 사업화와 신규 기능 개발을 일단 보류하고, 현재 결과물을 포트폴리오와 기술 참고 자료로 보존한다. 새로운 프로젝트에 일부 기능이나 설계 경험을 연결할 가능성은 열어둔다. 재개 시점과 후속 프로젝트는 확정하지 않는다.

사용자가 밝힌 의도는 다음과 같다.

> 일단 이대로 포트폴리오로 두려고, 뭐 나중에 갑자기 새로운 프로젝트에 연결 할 수도 있고

## 2. 이유

사용자가 설명한 보류 이유는 다음 여섯 가지다.

1. CRM 도메인의 업무 경험과 이해가 부족하여 실제 필요한 요구를 파악하기 어렵다.
2. B2B와 B2C를 함께 대상으로 잡으면서 범위가 커졌다.
3. CRM을 직접 사용한 경험 없이 개발하여 설계와 기능의 타당성에 대한 의문이 반복됐다.
4. 시간이 지나도 서비스 동작과 데이터 구조를 이해하고 유지하기 어려울 수 있다는 우려가 있다.
5. 기존 CRM의 기본 기능과 함께 제공할 차별화 방향이 명확하지 않다.
6. 사용자가 다른 대안 대신 OneHand CRM을 선택해야 할 이유가 충분히 구체화되지 않았다.

미래의 학습 능력이나 CRM 시장 전체의 가능성에 대한 확정 판단으로 확대하지 않는다. 현재 프로젝트에 추가 시간을 투자하는 판단과, 이미 만든 기술적 결과물의 보존을 구분한다.

## 3. 적용 범위

- 코드, Git 이력, schema와 migration, 테스트, 기획·API 계약·작업 기록을 보존한다.
- 현재 구현과 미완성 기능, 과거에 제거한 기능을 구분해 포트폴리오에서 설명한다.
- 기존 로드맵과 미완료 TODO는 과거 계획으로 남기며 자동 실행하지 않는다.
- 향후 재사용 범위는 새로운 요구가 구체화됐을 때 판단한다.
- 제품의 현재 개발 상태는 이 결정이 우선하며, 기존 No Setup CRM 기획과 기술 규칙은 당시 목표·구현의 참고 자료로 유지한다.

## 4. 이번에 결정하거나 실행하지 않은 것

- 프로젝트나 Git 이력의 삭제
- 원격 저장소 archive 설정, 배포 중지, 외부 DB·계정·구독 변경
- 포트폴리오를 위한 추가 기능 완성, 전면 리팩터링, 공용 라이브러리 추출
- 특정 직군으로 재출시하거나 다른 서비스로 전환하는 일정
- 유료 고객, 매출, 리텐션, 운영 성능 등 확인되지 않은 성과 주장
