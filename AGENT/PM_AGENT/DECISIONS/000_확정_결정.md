# 확정 결정

## 현재 제품 방향

onehand.sales는 개인 영업자를 위한 경량 CRM으로 유지한다. 현재 구현 핵심은 회사 정보를 빠르게 기록하고, 검색과 export로 다시 활용할 수 있게 하는 것이다.

## 활성 도메인

- User/Auth
- Company
- Search
- Error Report
- Support Request
- Public Contact Request
- Admin 권한 확인

## Backend 결정

- 모든 사용자 업무 API는 현재 사용자 ownership을 검증한다.
- Company는 생성/조회/수정, 분야/지역 옵션, xlsx export만 제공한다.
- 관리자 API는 `GET /admin/api/me`만 유지한다.
- xlsx export는 현재 Company만 제공한다.

## Frontend 결정

- 로그인 이후 업무 화면은 `/app` 아래에 둔다.
- 회사 생성은 목록 맥락의 `/app/companies/new`와 확장 화면 `/app/companies/new/full`을 함께 둔다.
- `/app/contacts/*`, `/app/products/*`, `/app/deals/*`, `/app/export`는 현재 `/app`으로 redirect한다.
- 계정 설정은 보호 route 위의 query 기반 모달로 제공한다.
- Admin Web은 access token 권한 확인 화면만 유지한다.

## 문서 결정

- 문서는 현재 코드에 남은 기능만 활성 기능으로 설명한다.
- 이전 도메인 전용 문서 파일은 삭제하지 않고 비활성 문서로 남긴다.
