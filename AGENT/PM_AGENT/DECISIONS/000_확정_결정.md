# 확정 결정

Status: Current PM baseline
Updated: 2026-11-17

## 제품

- OneHand CRM은 Bonsai의 전체 기능·UX를 재현하고 이후 차별화한다.
- 공식 도움말·공식 API·Gummble·실계정 관찰을 구분해 사용한다.
- 대표·영업·운영·프로젝트 담당자·실무자·고객 역할을 포함한다. 최종 판매 업종이나 규모는 별도로 검증한다.
- 첫 Kit 선택이나 특정 타깃 확정을 문서 조사·프로토타입의 선행 조건으로 두지 않는다.
- 기존 브랜드·저장소 이름은 유지한다. 구현 순서를 최종 기능 제외로 바꾸지 않는다.

## 현재와 목표

현재 범용 CRM 코어의 기록은 [IMPLEMENTATION_STATUS](../PLANNING/IMPLEMENTATION_STATUS.md)다. 문서 갱신이 Bonsai 기능 구현이나 코드 재검증을 뜻하지 않는다.

고객·거래·견적·문서·프로젝트·작업·시간·청구·입금의 연결과 권한을 새로 설계한다. 기존 엔진의 유지 여부는 기능과 의존을 대조해 정하며 DB 제거를 먼저 실행하지 않는다.

## 적용 순서

사용자의 최신 지시, [036 전환 결정](036_bonsai_benchmark_transition.md), [UX 025](../../UXUI_AGENT/DECISIONS/025_uxui_bonsai_reference.md)를 기준으로 한다. PM 032~035 등 역사 자료의 충돌하는 제한을 되살리지 않는다. 보안·시간대·계층·트랜잭션·API 계약 원칙은 유지한다.

현재 문서 변경 범위는 AGENT와 조사 폴더다. 실행 계획은 [기능 대응표](../PLANNING/BONSAI_FEATURE_PARITY_MATRIX.md), [DB 계획](../../SOFTWARE_AGENT/DB_SCHEMA/BONSAI_SCHEMA_PLAN.md), [전환 영향](../../SOFTWARE_AGENT/COMMON/BONSAI_TRANSITION_MATRIX.md)에 연결한다.
