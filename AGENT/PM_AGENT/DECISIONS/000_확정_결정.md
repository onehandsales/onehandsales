# 확정 결정

Status: Current PM baseline
Date: 2026-11-15

## 제품

- OneHand CRM은 folk의 기능과 UX를 기준으로 전환한다.
- Nicelydone MCP로 화면을 조사하고 folk 공식 도움말/API, 실제 계정으로 대조한다.
- 최종 목표는 전체 대응이다. 단계별 구현을 최종 기능 제외로 해석하지 않는다.
- 타겟 직군은 미확정이다. 직군별 Kit·개인 전용·고정 산업군을 개발 선행 조건으로 두지 않는다.
- 기존 제품명·브랜드명·저장소명은 유지한다.

## 구현

현재 32개 Prisma 모델과 Workspace/Object/List/Attribute/Record/View 코드가 존재한다. 현재 구현은 [IMPLEMENTATION_STATUS](../PLANNING/IMPLEMENTATION_STATUS.md)가 정본이다.

People/Companies 기본 정보, Group별 확장, Custom objects, Views 등을 위한 재설계가 필요하다. 모든 동적 모델 삭제나 Object→Group 단순 이름 변경으로 결론내리지 않는다. Workspace/Team/인증 기반을 보존하면서 새 의미와의 정합성을 검토한다.

## 기존 결정과 적용 순서

[036 전환 결정](036_folk_benchmark_transition.md)이 PM 032~035의 충돌하는 부분을 대체한다. 이전 결정·회고는 당시 기록으로 남긴다. UX 기준은 [025 folk reference](../../UXUI_AGENT/DECISIONS/025_uxui_folk_reference.md)다.

보안, 시간대, 계층·트랜잭션·API 계약 등 충돌하지 않는 기술 정책은 유지한다. 사용자 최신 지시가 우선하며 문서에 없는 도메인 제약을 임의로 추가하지 않는다.

## 작업 범위

이번 변경은 문서 정비다. DB/schema/실행 코드를 삭제하지 않는다. 실제 전환은 [기능 대응표](../PLANNING/FOLK_FEATURE_PARITY_MATRIX.md), [DB 계획](../../SOFTWARE_AGENT/DB_SCHEMA/FOLK_SCHEMA_PLAN.md), [전환 영향](../../SOFTWARE_AGENT/COMMON/FOLK_TRANSITION_MATRIX.md)에 따라 구체화한다.
