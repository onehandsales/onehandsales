# 확정 결정

## 현재 제품 방향

onehand.sales는 개인 영업자를 위한 경량 CRM으로 유지한다. 핵심은 회사, 담당자, 제품, 딜을 빠르게 연결하고 다음 행동과 메모를 딜 중심으로 관리하는 것이다.

## 활성 도메인

- User/Auth
- Company
- Contact
- Product
- Deal
- Search
- Trash
- Product Analytics
- Error Report
- Support Request
- Public Contact Request
- Admin 권한 확인

## Backend 결정

- 모든 사용자 업무 API는 현재 사용자 ownership을 검증한다.
- Company/Contact/Product/Deal과 관련 로그는 soft delete를 사용한다.
- 관리자 API는 `GET /admin/api/me`만 유지한다.
- 도메인별 export는 Company/Contact/Product/Deal만 제공한다.

## Frontend 결정

- 로그인 이후 업무 화면은 `/app` 아래에 둔다.
- 회사/담당자/제품/딜 생성은 목록 맥락의 `/new`와 확장 화면 `/new/full`을 함께 둔다.
- 계정 설정은 보호 route 위의 query 기반 모달로 제공한다.
- Admin Web은 access token 권한 확인 화면만 유지한다.

## 문서 결정

- 문서는 현재 코드에 남은 기능만 활성 기능으로 설명한다.
- 이전 도메인 전용 문서 파일은 삭제하지 않고 비활성 문서로 남긴다.
