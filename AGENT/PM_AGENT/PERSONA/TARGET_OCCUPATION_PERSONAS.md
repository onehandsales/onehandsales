# Target Occupation Personas

현재 서비스는 개인 또는 소규모 조직의 영업 데이터 관리에 집중한다.

| 우선순위 | 직군 | 이유 |
| --- | --- | --- |
| 매우 높음 | 중소기업 B2B 영업자 | 고객사, 담당자, 제품, 딜을 반복적으로 연결해 관리한다. |
| 매우 높음 | 1인 사업자/컨설턴트 | 고객과 제안 정보를 혼자 정리해야 한다. |
| 높음 | 보험설계사/재무상담사 | 고객, 상품, 진행 상태, 다음 행동 추적이 중요하다. |
| 높음 | 헤드헌터/채용 컨설턴트 | 고객사와 포지션별 진행 단계를 관리해야 한다. |
| 중간 | 부동산/분양 영업자 | 고객, 물건, 거래 단계, 메모 관리가 필요하다. |

핵심 기준은 팀 협업보다 개인의 빠른 기록, 검색, 딜 추적 효율이다.
