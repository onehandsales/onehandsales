# Target Occupation Personas

현재 서비스는 개인 또는 소규모 조직의 영업 데이터 관리에 집중한다.

| 우선순위 | 직군 | 이유 |
| --- | --- | --- |
| 매우 높음 | 중소기업 B2B 영업자 | 고객사 기본 정보와 메모를 반복적으로 정리한다. |
| 매우 높음 | 1인 사업자/컨설턴트 | 고객사와 제안 맥락을 혼자 정리해야 한다. |
| 높음 | 보험설계사/재무상담사 | 고객사/고객 메모와 후속 확인이 중요하다. |
| 높음 | 헤드헌터/채용 컨설턴트 | 고객사와 연락 맥락을 빠르게 찾아야 한다. |
| 중간 | 부동산/분양 영업자 | 고객 관련 메모와 지역 정보를 관리해야 한다. |

핵심 기준은 팀 협업보다 개인의 빠른 기록, 검색, 회사별 메모 정리 효율이다.
