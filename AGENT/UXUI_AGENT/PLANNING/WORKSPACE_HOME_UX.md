# Workspace / Business Navigation UX

Status: 화면 조사 대기
Updated: 2026-11-17

Bonsai의 실제 첫 화면·사이드바·업무 영역 탐색을 조사한다. 아래는 조사 목록이며 확인된 메뉴 순서가 아니다.

- 계정·업무 공간·팀·권한·설정.
- 고객 회사·담당자, 거래·견적·합의 문서.
- 프로젝트·작업·시간·인력 배정.
- 청구·입금·비용·보고서.
- Forms·예약·고객 포털·외부 연동.
- 전체 검색, 개인 보기·즐겨찾기, 역할별 메뉴 접근.

계정의 회사 설정과 고객 회사 목록을 구분한다. 같은 업무라도 대표·영업·실무자·고객에게 표시되는 정보와 진입점이 다를 수 있다.

순서·아이콘·크기·기본 펼침·모바일 탐색은 Gummble과 실제 계정에서 확인한다. 기존 Object/List 사이드바와 ViewFavorite는 현재 구현이며 목표 탐색 구조로 고정하지 않는다.
