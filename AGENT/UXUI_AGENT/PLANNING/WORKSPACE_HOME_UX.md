# Workspace / Group Navigation UX

Status: Target research
Date: 2026-11-15

folk의 실제 첫 화면과 사이드바를 조사한다. Kit 기반 Workspace 이름, 개인 영업 대시보드, 기존 빈 홈을 목표 화면으로 확정하지 않는다.

## 구분해야 할 정보

- Workspace 전환·설정·멤버.
- 전체 연락처와 Group 목록.
- Group의 People/Companies/Custom object 탭.
- 탭의 Table/Pipeline view와 추가·정렬·숨김 동작.
- Tasks, 메시지, Dashboard 등 독립 탐색 항목.
- 검색, 즐겨찾기 또는 개인화 범위.

정확한 순서·아이콘·여백·초기 펼침 상태는 화면 수집 후 기록한다. 그룹 삭제, 그룹에서 연락처 제외, 연락처 삭제를 다른 동작으로 검토한다.

현재 앱의 Object/List 사이드바와 ViewFavorite는 재사용 가능성을 검토하는 기존 코드다. folk 탐색 구조와 동일하다고 가정하지 않는다.
