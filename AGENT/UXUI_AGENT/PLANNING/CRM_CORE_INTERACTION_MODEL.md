Updated: 2026-11-17

| 사용자 행동 | 구분할 데이터·상태 | 계약에서 확인할 것 |
| --- | --- | --- |
| 고객·담당자 등록 | 계정 경계와 고객 주체 | 중복·회사 연결·공개 범위 |
| 거래 단계 변경 | 영업 상태·담당자·금액 | 권한·허용 전이·실패 되돌림 |
| 견적 작성·수정 | 항목·단가·수량·원가·합계 | 통화·반올림·버전·수정 영향 |
| 문서 만들기·발송·서명 | 견적 원본과 고객에게 전달한 내용 | 수신자·발송 snapshot·서명·취소·재발송 |
| 견적에서 프로젝트 생성 | 선택 항목과 수행 업무 | 작업·배정 변환·중복 제출·값 복사 |
| 작업·시간 기록 | 수행 상태와 청구 가능 여부 | 담당자·기한·기간·재청구 방지 |
| 청구·입금 기록 | 청구 금액·입금·잔액 | 부분 입금·취소·중복 이벤트 |
| 포털 공유 | 내부 데이터와 고객 공개 정보 | 고객별 접근·공유 해제 |
| 보기 변경 | 업무 데이터와 표시 설정 | 개인/팀 공유·저장·충돌 |
| 삭제·보관·연결 해제 | 원본과 연결·발송 이력 | 영향 범위·보존·복구 |
