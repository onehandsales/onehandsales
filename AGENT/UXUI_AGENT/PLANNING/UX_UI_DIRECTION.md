# UX/UI Direction

## Product UX Principle

onehand.sales는 개인 영업자가 빠르게 기록하고 다시 찾는 업무 도구다. 화면은 조용하고 밀도 있게 구성하며, 장식보다 정보 스캔과 반복 사용 효율을 우선한다.

## First Screen

로그인 이후 첫 화면은 `/app` 홈이다. 현재 홈은 고정형 CRM 도메인을 제거한 빈 foundation 화면이며, 후속 CRM 코어가 확정되기 전까지 존재하지 않는 업무 데이터를 암시하지 않는다.

## Navigation Priority

- 홈
- 더보기/계정
- 도움말

## List Direction

현재 활성 앱 도메인 목록은 없다.

후속 CRM record 목록을 만들 때는 검색, 필터, 정렬, 페이지네이션 상태를 명확히 보여준다. 빈 상태는 존재하지 않는 기능을 홍보하지 말고 다음에 할 수 있는 실제 행동으로 이어져야 한다.

## Detail Direction

현재 활성 record 상세 화면은 없다.

후속 CRM record 상세는 직업별 핵심 속성과 수정 진입이 명확해야 한다.

## Create / Edit Direction

현재 활성 앱 record 생성/수정 화면은 없다.

후속 CRM record 생성은 목록 맥락이 중요하면 오른쪽 문서형 패널을 우선한다. 저장 후에는 사용자가 방금 만든 record 위치를 잃지 않게 한다.

## Mobile Direction

- 하단 navigation과 주요 action button은 엄지 조작 범위 안에 둔다.
- 계정 설정, 도움말, 공개 문의 form이 작은 화면에서 겹치지 않아야 한다.
- 표 형태 정보는 모바일에서 카드가 아니라 compact row/list로 재구성한다.

## Writing Direction

- 버튼은 명령형으로 짧게 쓴다.
- 실패 메시지는 원인과 다음 행동을 함께 제시한다.
- 빈 상태 문구는 기능 설명보다 바로 할 수 있는 행동을 안내한다.
