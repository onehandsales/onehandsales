# 업무 목록 / 상세 UX

Status: Bonsai target research
Updated: 2026-11-17

고객·거래·프로젝트·작업·문서·청구 목록과 상세를 같은 데이터로 대조한다. [조사 정본](BONSAI_BENCHMARK_RESEARCH.md)의 B02, B04, B06, B07, B10, B21, B27을 참고한다.

## 목록과 보기

모듈별 표시 방식, 보기 생성·이름·공유, 필터·정렬·그룹·열, 검색·선택·일괄 작업을 조사한다. 페이지네이션·무한 스크롤·데이터가 많을 때의 상태는 실제 화면으로 확인한다.

## 보드와 일정

거래 파이프라인, 작업 보드, 프로젝트·인력 일정은 서로 다른 상태와 데이터를 다룬다. 카드 이동·일정 변경이 저장하는 필드, 허용 전이, 낙관적 표시와 실패 복구를 계약으로 연결한다. 기존 KANBAN renderer만으로 이 기능들이 완성됐다고 보지 않는다.

## 상세와 편집

고객 정보와 연결된 거래·문서·프로젝트·청구를 구분한다. 편집 가능한 원본과 발송·서명·청구 후 보존할 내용을 확인한다. 패널·모달·전체 페이지, 닫기·돌아가기·포커스 복귀는 원본 관찰 후 정한다.

## 저장·삭제

자동 저장 여부와 저장 버튼을 화면별로 확인한다. 기존 앱의 preview/save/undo·version 충돌 처리는 현재 계약이며 Bonsai 공통 정책으로 옮기지 않는다.

연결 해제, 프로젝트 보관, 거래 실패, 문서 취소, 청구서 취소·입금 취소, 레코드 삭제는 각각 영향과 복구 조건을 조사한다. 확인되지 않은 cascade를 가정하지 않는다.
