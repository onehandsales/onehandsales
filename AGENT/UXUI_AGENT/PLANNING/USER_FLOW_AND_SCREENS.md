# User Flow / 화면 목록

## 핵심 User Flow

### Flow 0. 로그인 후 홈 확인

1. 사용자가 로그인한다.
2. `/app` 홈에서 핵심 요약을 본다.
3. 빠른 실행 또는 하단 navigation으로 주요 도메인에 이동한다.

### Flow 1. 기본 데이터 등록

1. 회사 목록으로 이동한다.
2. `new` 화면 또는 패널에서 새 row를 생성한다.
3. 생성 직후 상세 또는 목록에서 값이 반영된 것을 확인한다.

### Flow 2. 회사 메모 관리

1. 회사 상세를 연다.
2. 일반 메모 또는 개인 비밀 메모를 생성한다.
3. 메모를 수정하거나 삭제하고, 휴지통에서 복구 가능 상태를 확인한다.

### Flow 3. Export

1. 회사 목록에서 검색과 필터를 적용한다.
2. xlsx export를 실행한다.
3. 다운로드된 파일이 현재 조건과 일치하는지 확인한다.

### Flow 4. 통합검색

1. 상단 검색을 연다.
2. 회사 키워드를 입력한다.
3. 결과를 선택해 회사 상세로 이동한다.

### Flow 5. 휴지통 복구

1. 휴지통 목록을 연다.
2. 회사, 회사 일반 메모, 회사 개인 비밀 메모 항목을 미리 본다.
3. 복구 기간이 남은 항목을 복구한다.

## User Web 화면 목록

| 화면 | Route |
| --- | --- |
| 홈 | `/app` |
| 회사 목록 | `/app/companies` |
| 회사 생성 | `/app/companies/new`, `/app/companies/new/full` |
| 회사 상세 | `/app/companies/:companyId` |
| 휴지통 | `/app/trash` |
| 더보기 | `/app/more` |
| 계정 모달 | 보호 route 위의 `?account=settings` |

현재 `/app/contacts/*`, `/app/products/*`, `/app/deals/*`, `/app/export`는 `/app`으로 redirect한다.

## 우선순위

1. 홈과 회사 목록/상세를 업무 시작점으로 둔다.
2. 회사 생성은 목록 맥락을 유지하는 오른쪽 문서형 패널을 우선한다.
3. 검색과 휴지통은 회사 도메인의 공통 보조 flow로 둔다.
4. 모바일에서는 목록 탐색, 상세 확인, 메모 입력과 복구 flow를 먼저 안정화한다.
