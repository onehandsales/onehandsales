Gummble은 이 세션에 호출 도구가 노출되지 않아 Bonsai 앱·화면·flow를 검색하지 않았다. Bonsai 컬렉션의 존재·충분성도 미확인이다. 실제 Bonsai 계정 조작, 요금제별 권한 시험, 외부 발송·서명·결제는 수행하지 않았다.

## 확인된 기능 경계

- B03/B05: 견적 계산과 고객에게 보내는 합의 문서는 구분된다. 견적에서 프로젝트와 선택적 작업·배정을 만드는 기능을 설명한다. 문서에 가져온 견적 수정은 원본 수정·문서 재생성 경로를 확인해야 한다.
- B08/B09/B11: 프로젝트 과금 방식, 시간의 청구 여부, 청구서 발행, 실제 입금은 별도 상태다. 부분 입금 기록은 잔액을 남긴다.
- B12/B19/B23: 내부 사용자·고객 포털·연동 정보의 공개 범위를 구분한다. 역할 이름만으로 모든 필드 접근을 허용하지 않는다.
- B21: 보기 설정은 모듈별로 관리된다. 현재 범용 View 구조와 동일하다고 가정하지 않는다.
- B27: 공개 API의 리소스는 제품 기능의 일부 근거다. API 미노출 기능을 제품에서 제외하지 않으며 내부 DB 구조를 API로 역확정하지 않는다.

| 항목 | 공식 자료에서 확인한 조건 | 후속 확인 |
| --- | --- | --- |
| 문서 버전 | B25는 2026-07-27 이후 생성 계정의 Document Builder 사용을 안내 | Gummble 캡처와 실계정의 버전·메뉴·기능 대조 |
| 자동화 | B22는 Document Builder 미지원 안내를 포함 | 구형 Proposal 자동화를 새 문서에 적용하지 않음 |
| 문서 결제 | B26은 미국·영국·호주 계정과 Bonsai Payments 조건을 설명하며 미지원 국가의 draft invoice 경로도 안내 | 국가·계정별 서명/선금/잔금/중단 후 복귀 상태 |
| 사용자 필드 필터 | B20(2026-05-27)은 미지원, B21(2026-08-14)은 지원 설명 | 화면·대상·필드 유형별 실제 동작 확인 |
| 호출 제한 | B27 REST는 credential 기준, B28 MCP는 IP 기준 수치를 각각 설명 | 서로 다른 API 표면의 조건으로 기록하고 적용 대상을 확인 |
| 날짜·시간 | B27은 date와 UTC timestamp 표현을 구분 | 기한·예약·반복·리테이너 주기의 업무 시간대 |
| 계정 회사와 고객 회사 | 권한 설명의 company account와 CRM Companies는 문맥이 다름 | Workspace 경계와 고객 주체를 혼동하지 않음 |

국내 전자세금계산서, 현장 이동·배차 최적화, 임의 업종별 가격 계산의 제공 여부는 확인되지 않았다. 미확인을 지원·미지원으로 단정하지 않는다.
