# Gummble 조사 절차

Updated: 2026-11-17
Status: 조사 도구 선정 / 연결·Bonsai 자료 조회 미수행

## 역할

Gummble은 Bonsai 화면·사용 흐름·문구·상호작용 참고 자료를 찾는 도구다. 기능 의미는 Bonsai 공식 도움말, 공개 계약은 공식 API, 실제 상태 변화는 계정 관찰과 대조한다.

공식 MCP 안내: [Gummble MCP](https://docs.gummble.com/docs/mcp)
서버 주소: `https://mcp.gummble.com/mcp`

공식 안내는 OAuth 기반 원격 MCP와 검색·상세 조회 도구를 설명한다. 주소가 문서에 있다는 사실은 현재 연결 성공을 뜻하지 않는다. 이 세션에서 Gummble 도구를 호출하지 않았고 계정·플랜 접근 가능 여부와 Bonsai 자료 보유 여부도 미확인이다.

## 조사 순서

1. 실제 사용 가능한 도구와 인증·접근 상태를 확인한다.
2. Bonsai 앱을 검색하고 제품 도메인·앱 식별자가 일치하는지 확인한다.
3. 화면·flow별 ID, 원본 링크, 캡처일·버전, viewport와 관련 기능 ID를 기록한다.
4. 고객·거래·견적·문서·프로젝트·작업·시간·청구·포털 흐름을 같은 업무 예시로 연결한다.
5. 빈 상태·오류·권한·저장·취소·모바일 자료가 있는지 확인한다.
6. 공식 자료 또는 실제 계정과 다르면 버전 차이·미확인 상태를 기록한다.

자료가 없으면 해당 기능을 제외하지 않고 공식 자료·실제 계정에서 보완한다. 수치·색상·레이아웃을 원본 확인 없이 확정하지 않는다. 연결 대기 중에도 공식 문서 학습, 기능 목록, 계약 초안은 진행한다.

## 결과 기록

[조사 정본](BONSAI_BENCHMARK_RESEARCH.md)의 양식을 사용한다. 연결 성공, 앱 검색 성공, 화면 수집, 계정 검증을 각각 기록한다. Gummble MCP와 Bonsai 계정 데이터를 다루는 Bonsai MCP는 목적과 권한이 다른 서비스다.
