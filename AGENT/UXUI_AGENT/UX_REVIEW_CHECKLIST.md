# UX Review Checklist

Date: 2026-11-15

- [ ] [025 folk 기준](DECISIONS/025_uxui_folk_reference.md)을 사용하고 이전 Kit/Notion/Attio 결정을 현행으로 적용하지 않았는가.
- [ ] 각 화면·flow에 출처, 날짜, 플랜·역할·기기·locale이 있는가.
- [ ] 실제 관찰과 공식 문서, 우리 설계 제안을 구분했는가.
- [ ] 객체 탭, Group, View, Pipeline 열의 의미가 구분되는가.
- [ ] 기본 연락처 정보와 그룹별 필드가 다른 화면에서도 일관되는가.
- [ ] 생성·편집·자동 저장·실패·재시도·취소·재진입을 확인했는가.
- [ ] 그룹 제외, 레코드 삭제, View 삭제와 복구 영향이 명확한가.
- [ ] Notes/Tasks의 공개 범위와 역할별 제한을 확인했는가.
- [ ] 정상·빈·로딩·오류·권한 제한 상태를 비교했는가.
- [ ] 모바일·키보드·포커스·스크롤과 긴 데이터에서 사용 가능한가.
- [ ] 원본과 다른 layout·상호작용·문구를 차이 목록에 남겼는가.
- [ ] mock 데이터와 실제 저장되는 기능을 구분했는가.
- [ ] API·권한·DB 요구와 [기능 대응표](../PM_AGENT/PLANNING/FOLK_FEATURE_PARITY_MATRIX.md)가 연결되는가.
- [ ] User Web 기능을 Admin Web에서 구현 완료처럼 암시하지 않는가.

Nicelydone 미연결 또는 관찰하지 않은 상태는 검증 완료가 아닌 대기로 기록한다.
