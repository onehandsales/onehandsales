# UX Review Checklist

Updated: 2026-11-17

- [ ] [Bonsai UX 기준](DECISIONS/025_uxui_bonsai_reference.md)과 전체 재현 목표를 따르는가.
- [ ] 공식 자료·Gummble·실계정·설계 제안의 확인 상태를 구분했는가.
- [ ] 화면별 날짜·버전·계정 생성 시기·국가·플랜·역할·기기를 기록했는가.
- [ ] 고객·거래·견적·문서·프로젝트·작업·청구·입금의 의미가 구분되는가.
- [ ] 원본 수정과 발송 문서·청구 내용의 변경 범위를 확인했는가.
- [ ] 저장·전송·서명·결제·취소·재시도·재진입을 구분했는가.
- [ ] 금액·통화·날짜·기한·부분 입금이 연결 화면에서 일관되는가.
- [ ] 내부 재무 정보·팀 권한·고객 포털의 노출 범위를 확인했는가.
- [ ] 정상·빈·로딩·오류·권한 제한 상태를 비교했는가.
- [ ] 키보드·포커스·스크롤·모바일과 긴 데이터 사용성을 검토했는가.
- [ ] 화면별 저장 방식과 동시 수정·실패 복구가 계약에 있는가.
- [ ] 원본과 다른 배치·상호작용·문구·기능을 차이로 기록했는가.
- [ ] mock, 실제 저장, 외부 실행 검증을 구분했는가.
- [ ] API·DB·권한·검증 항목이 [기능 대응표](../PM_AGENT/PLANNING/BONSAI_FEATURE_PARITY_MATRIX.md)에 연결되는가.
- [ ] 고객 포털과 운영자용 Admin Web을 구분했는가.

Gummble 미연결이나 관찰하지 않은 동작은 대기로 남긴다. 이전 Kit·개인 전용·패널 고정·모바일 테이블 일괄 금지를 적용하지 않는다.
