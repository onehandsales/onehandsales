# 이전 혼합 UX 기준 종료 기록

Status: Historical / Superseded
Updated: 2026-11-16

이전의 여러 제품을 조합하는 UX 기준은 종료됐다. 현재 제품·UX의 유일한 참고 기준은 **folk**이며 [UX 025](025_uxui_folk_reference.md)로 대체한다.

사용자 요청으로 이전 참고 제품명이 포함된 파일명·본문·현재 문서의 참조를 정리했다. 이전 세부 지침은 Git 이력에 남으며 현재 작업의 요구사항으로 적용하지 않는다.

새 화면은 Nicelydone MCP의 folk 자료, folk 공식 문서, 실제 계정 관찰을 구분해 조사하고 [근거 문서](../PLANNING/FOLK_BENCHMARK_RESEARCH.md)에 연결한다. 과거 레이아웃을 새 기준으로 일괄 승계하지 않는다.
