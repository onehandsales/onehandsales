# UX/UI Admin Tone Decision

## 결정

Admin Web은 같은 화이트/중립 그레이 기반의 신뢰 톤을 쓰되 현재는 관리자 권한 확인 흐름에만 집중한다.

## 원칙

- 로그인과 권한 확인 상태를 명확히 보여준다.
- User Web의 도메인 화면을 암시하지 않는다.
- 색상은 상태, 위험도, 제한된 action accent에만 사용하고 블루 중심 톤으로 만들지 않는다.

## 이유

Admin은 사용자 앱처럼 빠르고 부드러운 입력 경험보다 권한 확인의 명확성이 더 중요하다.

따라서 현재 화면은 과도한 정보 밀도보다 로그인 상태, 관리자 여부, 접근 차단 상태를 분명히 보여주는 데 집중한다.
