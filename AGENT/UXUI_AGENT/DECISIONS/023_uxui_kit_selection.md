# UX/UI Kit Selection Decision

Date: 2026-09-12

## 1. 결정

Kit 선택 UX는 템플릿 선택이 아니라 업무 유형 선택으로 설계한다.

사용자는 CRM 구조를 직접 고르는 것이 아니라, 자신이 하는 일을 선택한다.

## 2. Kit 카드 기준

Kit 카드에는 아래를 우선 표시한다.

- 직업/업무 이름
- 관리할 주요 대상
- 대표 관계 또는 흐름
- 첫 Record 후보

## 3. Kit 미리보기 기준

미리보기에는 아래를 포함한다.

- 관리 대상
- 핵심 관계
- 기본 보기
- 첫 행동

미리보기에는 아래를 노출하지 않는다.

- 전체 필드 설정
- schema editor
- 고급 권한
- 자동화 builder

## 4. 기타/직접 설명 기준

MVP에서 `기타/직접 설명`은 자유 CRM builder로 이어지면 안 된다.

사용자의 업무 설명을 수집하거나 후속 Kit 준비로 연결할 수 있지만, 즉시 완성된 CRM 생성을 과장하지 않는다.
