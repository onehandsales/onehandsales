Status: Historical / Superseded

이 문서는 이전 UX 참고 기준을 종료했다는 기록이다. 사용자 요청에 따라 과거 참고 제품명과 세부 지침을 현재 문서에서 정리했다. 이전 본문은 Git 이력에서 확인할 수 있다.

현재 제품·UX의 유일한 참고 기준은 **folk**다. [UX 025](025_uxui_folk_reference.md)의 화면·상호작용 조사 절차와 [현재 UX 방향](../PLANNING/UX_UI_DIRECTION.md)을 따른다. 과거 화면 패턴을 folk에서 확인한 동작으로 바꾸어 해석하지 않는다.
