# UX/UI First Use Flow Decision

Date: 2026-09-12

## 1. 결정

OneHand CRM의 첫 사용 flow는 아래 순서를 기준으로 한다.

```text
로그인/가입
-> 업무 유형 선택
-> Kit 미리보기
-> Workspace 준비
-> 첫 Record 생성
-> 기본 보기 확인
-> 다음 행동 안내
```

## 2. 이유

제품의 첫 가치는 자유로운 설정이 아니라 "내 일에 맞는 CRM이 바로 준비된다"는 경험이다.

첫 사용자가 설정부터 배우면 OneHand CRM의 차별점이 약해진다.

## 3. UX 기준

- 업무 유형 선택은 CRM 설정이 아니라 업무 선택으로 보여야 한다.
- Kit 미리보기는 관리 대상과 관계를 짧게 보여준다.
- Workspace home은 첫 Record 생성으로 이어져야 한다.
- 첫 Record 생성 필드는 최소화한다.
- 저장 후 기본 보기에서 Record를 다시 확인할 수 있어야 한다.

## 4. 제외

- 첫 사용 중 Team 초대 강제
- 결제/구독 유도
- Object/Field/Relation builder
- 자동화 builder
- 대량 import
