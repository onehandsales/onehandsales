각 플로우의 ANALYSIS.md와 모든 원본 화면을 순서대로 읽고, 입력·전후 변화·종료 상태·다른 흐름과의 연결을 기록했다. 이 완료 표시는 확보된 캡처의 검토 완료이며, 최신 Bonsai 전체 기능·공식 정책·실계정 동작 검증의 완료가 아니다.

## 확인 방법과 결과

화면은 두 장씩 순서대로 비교하는 열람용 이미지를 사용하고 필요한 부분은 원본으로 확인했다. 동일 화면이 다른 플로우에 반복되어도 앞뒤 문맥을 다시 읽었다. 단순 파일 개수·OCR·기존 분석 요약만으로 검토를 대신하지 않았다. 열람용 이미지와 검증 스크립트는 임시 폴더에 두었으며 원본 자산은 수정하지 않았다.

| 대조 항목 | 결과 |
| --- | --- |
| 원본 분석 문서 | 134개: 상위 42개·하위 92개 |
| 분석의 Screen ID 순서 ↔ 로컬 파일 순서 | 134개 전부 일치; 단계 번호 연속 |
| 플로우 이미지 | 754개 모두 디코딩 성공, 원본 2880 × 1800 px |
| 고유 화면 ID / 고유 SHA-256 | 각각 642개; 같은 화면 ID의 이미지 바이트 일치 |
| 분야별 기록 ↔ 원본 플로우·화면 수 | 134/134개·754/754장, 누락 0·중복 배정 0 |
| UI Elements | 75/75개 모두 flows 안에 같은 Screen ID·같은 이미지 바이트로 존재 |
| 그 외 로컬 이미지 | bonsai_analysis 아래 flows·ui_elements 외 별도 이미지 없음 |
| 문서 연결 | steps의 로컬 링크·F번호 앵커 존재 여부 검사 |
| 파일 무결성 | 새 문서 UTF-8·잘못된 대체 문자·줄 끝 공백 검사 |

이 숫자는 로컬에 확보한 스냅샷의 대조 결과다. Gummble의 최신 서비스 목록을 이번 단계에서 다시 조회하거나 새 화면을 수집한 결과는 아니다. 기존 원본은 Gummble Latest/version 2146로 기록되어 있으나 개별 제품 빌드·캡처일은 미확인이다.

## flows 기준 2차 재검토

2026-11-18 KST에 134개 ANALYSIS.md와 754장 화면을 플로우 순서대로 다시 대조했다. 전체 406개 열람 묶음에서 빠진 화면은 없었고, 분야별 8개 기록의 원본 연결·화면 수와 업무 연결도의 해석을 함께 확인했다. 중복 화면도 해당 흐름에서 다시 읽었다.

- [F070](06_청구와회계.md#f070): 시간 추가 후 Drafted가 유지되는 점을 명시하고, 업무 연결도에서 초안 포함을 Billed 전환으로 읽을 수 있는 표현을 수정했다. Billed 표시는 다른 흐름의 별도 관찰로 남겼다.
- [F081](06_청구와회계.md#f081): Foundation 미리보기 뒤 Studio 형태로 돌아오는 중간 조작이 없는 점을 추가했다. 팁 체크와 저장 성공은 확인되지만 최종 저장 레이아웃은 재조회하지 않았음을 명시했다.
- [F122](02_설정과구독.md#f122): 하단의 Google Sheets·Xero·Hubspot 카드와 연동 요청 링크를 추가했다. 설정 화면에서 보이는 12개 카드와 실제 연동 실행을 구분했다.
- 업무 연결도에서 프로젝트와 제안서의 연결 선택, 고객 서명 미확인, 집계 조회를 더 명확히 표시했다. 보완 후 원본 ID·단계 순서·이미지 무결성·분야 배정·로컬 링크·앵커를 재검사했다.

결과는 **로컬 flows 기준 플로우 누락 0·단계 누락 0·중복 배정 0**이다. 이미지에 없는 중간 조작이나 최신 기능은 검토 누락과 구분하여 다음 단계의 확인 과제로 유지한다.

## 이번 학습에서 특히 주의할 점

- 프로젝트 진행 단계, 문서의 발송·수락·서명, 작업 완료, 청구됨, 결제됨은 각각 다른 상태다.
- 이름이 기능 실행을 뜻해도 실제 캡처는 오류·요금제 안내·설정 화면에서 끝날 수 있다. 자동 발송·입금 기록·CSV 가져오기·고객 모드 등의 도달 상태를 개별 기록했다.
- 기존 분석의 수치 오류를 발견했다. [F054 대시보드 작업 완료](03_고객과대시보드.md#f054)의 미청구 금액은 $120.42에서 $160.42로 달라진다. 원본 분석은 보존하고 이번 재검토에 정정 근거를 남겼다.
- 폼 정의와 제출 화면의 질문 차이, 제출/응답 이름 차이, 날짜·작업 개수·프로젝트 상태의 불연속을 기록했다. 생략된 조작을 추정해 자동화 규칙으로 만들지 않았다.
- 공식 도움말·API 인용은 기존 조사 기록으로 읽었다. 최신 기능·버전·권한·정책 대조와 실제 계정 재현은 별도 확인이 필요하다.
