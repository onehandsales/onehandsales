# 1단계 — 공개 사이트와 지원

공개 사이트의 메뉴·소개·검색·템플릿·지원·법적 문서를 화면 순서대로 검토한다. 홍보 이미지 내부의 데이터는 실제 업무 조작 결과와 구분한다. 가격·정책·제휴 조건은 캡처 당시 문구이며 현재 유효성은 2단계 확인 대상이다.

## F082 — 홈페이지의 기능 탐색과 가입 유도

원본: [Landing page](../../flows/Landing%20page/ANALYSIS.md) · 화면 **11/11** 확인.

- 01 대시보드·모바일 폼 이미지 →02 고객/프로젝트/재무 3영역 링크 →03~04 후기 3번에서 1번으로 변경 →05 청구·은행·회계 소개 →06 브랜딩·고객 경험 →07 평점·후기 →08 지원·체험 →09 가입 CTA →10 푸터 →11 하단 고지다. hero는 이 흐름에 없고 로그인/온보딩 시작 화면에서 보인다.
- 상단 Product/Industries/Templates/Pricing/Resources/Reviews와 로그인·체험 진입을 반복 유지한다. 목업 내부 폼·금액·브랜딩은 이 페이지에서 편집한 데이터가 아니다. 후기 전환이 자동인지 클릭인지는 미확인이다.
- 08~09의 7일 체험·첫 2주 환불 홍보와 다른 앱 화면의 14일 체험을 하나의 정책으로 합치지 않는다. 금융·세금 지원과 제휴 고지도 당시 소개 내용이다.
- 푸터는 회사·제품·고객군·자료·템플릿 그룹, 소셜 링크와 고지로 구성된다. 링크를 표시한 것과 목적지를 실제 연 것은 구분한다. 전체 페이지 사이 생략 구간·모바일 조작은 미수록이다.
