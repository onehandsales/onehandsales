## F101 — 프로젝트 상세의 업무 묶음

원본: [Project detail](../../flows/Project%20detail/ANALYSIS.md) · 화면 **6/6** 확인.

- 01–02: 보드 → Overview. 헤더에 이름·고객·Automations·진행 단계·멤버와 Overview/Invoices/Tasks/Time Tracking/Team/Settings 탭. 작업/문서는 비어 있고 생성 활동·청구/비용 요약이 나온다. 보드 이름에는 Studio가 있지만 상세에는 없어 시점 차이를 보존한다.
- 03: Tasks에는 Untitled 1개(To Do/No due date), Initial Chat 2개(In Progress/Today/JD)가 이미 있다. 개요에서 탭을 바꿨다고 세 작업이 자동 생성된 것은 아니다. 같은 제목을 객체 식별자로 쓸 수 없다.
- 04: Time Tracking에는 7초와 1시간 기록, 각각 $20.00 표시, 합계 1.00 Hours/$20.04. **1.00 Hours를 정확히 3,600초로 역산하면 7초가 사라진다.** Timesheets는 아직 없고 Invoice Unbilled Hours 진입이 있다. 고객은 청구된 시간만 볼 수 있다는 문구를 확인했다. 행의 $20.00은 단가로 보이지만 이 화면만으로 확정하지 않는다.
- 05: Team에는 Joe Doe 1명, 추가/제거 진입. Collaborator는 제한된 접근과 기능을 가지며 회사 데이터·프로젝트 문서에 접근할 수 없다는 안내가 있다. 실제 역할별 권한 호출을 검사한 것은 아니다.
- 06: Settings에 Hourly Rate·US$20/USD, 시작일 2월 6일, 종료일 없음. Description은 선택·Markdown 지원이며 고객/contractor/collaborator에게 보인다는 안내다. 자동 리마인더는 미결제 청구서·만료 예정 제안서·서명 대기 계약 대상으로 설명된다.
- 내부 Your Notes(F020)와 외부에 보이는 Description을 구분한다. 이 루트에서 Invoices 탭 내부, 문서/링크 추가, 이메일, Automations 실행은 수록되지 않았다.

- 01–03: 작업 상세 → 상태 드롭다운 To Do/In Progress/Done 및 Settings → Status Settings. To Do 보라, In Progress 파랑, 구분선 아래 Done 초록, Add Status가 보인다. 하위 작업 유무의 중간 차이는 별도 시점이다.
- 04–06: To Do 이름 편집/8색 팔레트 → 주황 선택 → 팔레트 닫힘과 Task status updated 성공. 행에는 이동 핸들도 보인다.
- 현재 작업의 In Progress를 바꾼 흐름과 상태 정의의 색상 변경을 구분한다. 새 상태 추가·삭제·순서 저장·Done 특수 제약·정의 적용 범위·정확한 색상 값은 미확인이다.

## F096 — 작업 보관

## F098 — 작업 삭제 확인

원본: [Deleting a task](../../flows/Project%20detail/Adding%20a%20task/Deleting%20a%20task/ANALYSIS.md) · 화면 **4/4** 확인.

## F131 — 템플릿 구성 작업 편집

원본: [Editing a template task](../../flows/Tasks/Editing%20a%20template%20task/ANALYSIS.md) · 화면 **8/8** 확인.

- 01–03: 빈 템플릿 → Edit Template Task 모달 → Update company guideline 입력. Title·Description·Files·Subtasks와 Delete Task/Save Task가 있다. 신규 항목이 Edit로 열리는 중간 과정은 생략되었다.
- 04–05: JPG 파일명 카드/구름 아이콘/제거 X → 색상 이미지 미리보기, 첫 하위 작업 Send invite for initial chat 입력. 파일 카드의 아이콘만으로 업로드 완료를 판정하지 않는다.
- 06–08: 첫 하위 Save 후 일반 행 → Prepare proposal 두 번째 행 → 전체 모달 닫힘·템플릿에 작업 1개. 하위 Save와 전체 Save Task가 별도다. 접힌 목록에서 파일/하위 항목 보존까지 재조회한 것은 아니다.
- 이 편집에는 프로젝트·담당자·기한 선택이 없다. 적용된 작업으로 변경 전파, 첨부 공유/복제, 취소 시 저장 범위와 삭제 결과는 미확인이다.

## F128 — 템플릿을 프로젝트 작업으로 적용

원본: [Adding a task (template)](../../flows/Tasks/Adding%20a%20task%20%28template%29/ANALYSIS.md) · 화면 **7/7** 확인.

- 01–02: 전체 작업 보드 → Add from a task template 툴팁. 기존 Initial Chat의 In Progress→Done은 별도 변화이며 템플릿 버튼의 효과가 아니다.

## F125 — 전역 타이머 시작·일시정지·완료

원본: [Starting time tracking](../../flows/Starting%20time%20tracking/ANALYSIS.md) · 화면 **10/10** 확인.

- 01–03: 대시보드 → Start New Timer 0초/미청구 시간 없음 → Active Timer 2초, 프로젝트/작업 미선택, 날짜·요율·설명 입력. 시작 대시보드와 이후 날짜·프로젝트 수가 달라 전체를 같은 시점으로 보지 않는다.
- 04–06: 프로젝트 목록에 고객 보조명 → Design Project with Doe Studio 선택·Rate 20·Changes Saved → 요율 없는 시간도 청구서에 추가하거나 내부 추적 가능하다는 도움말. 프로젝트 선택 전 실행과 프로젝트 없이 완료 가능 여부는 다르다.
- 07–08: 작업은 미선택, Creating a proposal 설명 입력 → 팝오버 닫혀도 상단 타이머 35초로 진행. 창 닫힘과 타이머 정지를 분리한다.
- 09–10: 1분 16초 일시정지·Resume Timer/Done → 0초의 새 타이머와 Doe Company/프로젝트/날짜/설명이 붙은 1분 16초 요약. Done 클릭 자체는 사이에 생략됐다. 작업을 선택하지 않은 완료 결과가 보인다.
- 프로젝트 요율 상속 우선순위·0/빈 요율 차이·삭제·다중 탭/기기·새로고침 지속·실시간 프로토콜은 미확인이다. 설명은 제안서 생성 명령이 아니다.

## F133 — 시간 목록과 기간별 인사이트

원본: [Time Tracking](../../flows/Time%20Tracking/ANALYSIS.md) · 화면 **6/6** 확인.

- 01–03: 대시보드 → 날짜 그룹 표에 Initial Chat 7초/$0.04와 1시간/$20 → 2월 7일 Creating a proposal 1분 16초/$0.42가 별도 날짜 그룹에 추가. Task/Description·Project·Value·Member·Time 열, 검색/Filters/List/Add Hours/행 메뉴가 있다.
- 04–06: Insights의 By Project·1월 23일–2월 6일 보고서 → 같은 수치의 그래프/스크롤 상태 → 프로젝트별 두 기록과 합계 01:00:07/$20.04. 미청구와 청구 시간·금액을 각각 표시하며 이때 청구는 0이다.
- 목록의 2월 7일 기록은 보고서 기간 밖이다. 합계 차이를 누락 버그로 판단하지 않는다. 화면 간 그래프 모양 차이도 수치 증가의 증거가 아니다.
- F125의 설명·시간과 일치하지만 ID로 동일 기록을 확인하지 않았다. 필터/목록 메뉴·내보내기·다중 통화·초 단위 반올림·청구 전환 조건은 미확인이다.
