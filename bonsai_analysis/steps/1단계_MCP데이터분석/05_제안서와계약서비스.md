# 1단계 학습 — 제안서·계약·서비스

검토 기준: 로컬 Gummble 화면을 단계 순서로 직접 확인하고 기존 ANALYSIS와 대조했다. 기존 문서의 공식 도움말/API 인용은 이전 조사 결과이며, 이 단계에서 현행 공식 규칙으로 재확인한 것은 아니다.

문서 내용·표현 스타일·발송·수락/서명·보관·입금·자동화 실행을 구분해 읽는다.

- 19: 목록에 Created/Sent 2/8이 보이지만 생성 화면에서 목록까지 서명·발송 조작은 생략되어 있다. 계약 생성이 자동 발송된다고 해석하지 않는다. 조항의 법적 효력·국가별 적합성은 이 캡처로 판단하지 않는다.
