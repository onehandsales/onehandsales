# Bonsai 기능 지도와 확인 사항

Updated: 2026-11-18

Bonsai는 고객·영업, 프로젝트 수행, 재무 관리를 연결하는 제품으로 학습한다. 현재 목표는 전체 기능·UX 재현이며 일부 CRM 화면만 만드는 범위로 축소하지 않는다.

## 전체 기능군

| 기능군 | 배울 내용 |
| --- | --- |
| P01 가입·계정·업무 공간·팀·권한 | 가입·초대·역할별 접근, 계정과 고객 회사 구분 |
| P02 고객 회사·담당자·활동·메모 | 고객·담당자 연결, 중복·삭제·공유 범위 |
| P03 거래·파이프라인·후속 작업 | 단계·금액·담당자·성사/실패·프로젝트 연결 |
| P04 서비스·단가표·견적 계산 | 항목·단가·수량·원가·할인·문서/프로젝트 전환 |
| P05 제안·계약·문서·템플릿·서명 | 신규/기존 문서 버전·수신자·발송·서명·수정 |
| P06 프로젝트·상태·파일·협업 | 고객·거래 연결, 과금 방식·상태·공유 범위 |
| P07 작업·하위 작업·반복·일정·Gantt | 기한·의존·배정·반복·보드/일정 상태 |
| P08 시간 기록·타임시트 | 수동/타이머·청구 가능·미청구/청구됨 |
| P09 예산·비용·수익성 | 원가·예산 사용량·비용 재청구·계산 기준 |
| P10 인력 배정·워크로드·휴가 | 가용량·초과 배정·일정 변경 |
| P11 청구서·항목·입금·잔액 | 발행·전액/부분 입금·취소·실패·반올림 |

| P13 고객 포털·공유·브랜딩 | 고객별 문서·파일·작업·청구 공개와 접근 차단 |
| P14 문의 양식·상담 예약 | 양식 구성·응답·예약·취소·캘린더 충돌 |
| P15 필드·보기·검색·가져오기/내보내기 | 지원 대상·유형·필터·정렬·저장·공유·일괄 처리 |
| P16 알림·이메일·캘린더·활동 기록 | 공유·제외·중복 동기화·실패·해제 |
| P17 자동화·워크플로 | 트리거·행동·실패/재시도·버전 제한 |
| P18 보고서·대시보드·내보내기 | 필터·집계·재무 권한·금액 의미 |
| P19 외부 연동·공개 API·MCP·AI | 연동별 제공 기능·권한·AI 적용 지점; Webhook 제공 범위 별도 조사 |
| P20 설정·요금제·계정 구독·지역 기능 | 고객 청구와 제품 이용료 구분; 국가·플랜·Tax/금융 기능 범위 |
| P21 반응형·접근성·모바일 경로 | viewport·키보드·포커스·중단 후 복귀 |

이 표는 초기 기능군 지도다. 세부 화면·권한·예외·국가·요금제별 제공 범위는 계속 확장한다. [기능 대응표](../AGENT/PM_AGENT/PLANNING/BONSAI_FEATURE_PARITY_MATRIX.md)의 동일 Pxx ID와 연결하며, 공식 출처는 [B01~B31](../AGENT/UXUI_AGENT/PLANNING/BONSAI_BENCHMARK_RESEARCH.md)에서 확인한다.

## 중심 흐름에서 놓치지 않을 차이

- 견적 계산과 고객에게 보내는 합의 문서는 다르다. 견적에서 프로젝트·작업을 만드는 동작은 원본·복사·수정 범위를 확인한다.
- 수행 시간과 청구 가능한 시간, 청구된 금액과 실제 받은 금액을 구분한다.
- 반복 청구서와 자동 결제 구독, 프로젝트 리테이너와 OneHand 제품 구독을 구분한다.
- 회사 대표·영업·프로젝트 담당자·실무자·외부 고객의 권한을 각각 확인한다.
- 고객 포털은 OneHand 운영자용 Admin Web과 다른 화면이다.

이는 Bonsai를 다른 모든 CRM보다 우월하다고 단정하는 비교가 아니다. 이 프로젝트에서는 사용자가 선택한 Bonsai의 연결 방식과 UX를 재현한다.

## 버전과 조건

| 확인 사항 | 현재 근거와 후속 작업 |
| --- | --- |
| Document Builder | 공식 안내는 2026-07-27 이후 생성 계정의 새 문서 경험을 설명한다. 이전 Proposal 화면과 섞지 않는다. |
| 견적에서 문서 생성 | 가져온 견적의 항목·가격을 문서에서 직접 바꾸는 것과 원본 견적 수정·문서 재생성은 다르다. |
| 자동화 | 공식 Workflow Automations 안내의 새 Document Builder 미지원 조건을 보존한다. |
| 문서 결제 | 국가·Bonsai Payments 활성화 조건 및 미지원 국가의 draft invoice 경로가 있다. |
| 사용자 필드 필터 | 두 공식 문서의 날짜·설명 차이가 있어 실제 대상 화면·필드 유형을 확인한다. |
| 국내·업종 요구 | 국내 PG·전자세금계산서·면적별 자동 가격·현장 배차는 미확인이다. 원본 기능으로 확정하지 않는다. |

각 조건의 공식 URL과 확인 상태는 [조사 정본의 버전·조건 표](../AGENT/UXUI_AGENT/PLANNING/BONSAI_BENCHMARK_RESEARCH.md)에 있다.
