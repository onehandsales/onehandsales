2026-11-17 확인 자료와 B01~B31·G01 출처, 문서 충돌·미확인은 [Bonsai 조사 정본](../AGENT/UXUI_AGENT/PLANNING/BONSAI_BENCHMARK_RESEARCH.md)에서 관리한다. [공식 REST API](https://docs.hellobonsai.com/api)와 [Gummble 절차](../AGENT/UXUI_AGENT/PLANNING/GUMMBLE_RESEARCH_GUIDE.md)를 함께 읽는다. 2026-11-18 Gummble의 Bonsai Web 134개 플로우·754단계·고유 화면 642개를 재조회·배치한 상태는 [플로우 색인](README.md)과 [검토 결과](FLOW_ASSET_REVIEW.md)에 기록했다. 실계정 검증은 미수행이며 이번 원본 배치에서 공식 문서를 새로 조회하지 않았다.

## 과거 비교 조사 출처

아래는 2026-11-16 조사 기록이다. 다른 제품을 현재 참고 기준으로 삼지 않으며 이번 작업에서 타사 자료를 재검증하지 않았다. 아래 링크는 당시 조사 중 실제로 본문을 조회한 자료다. 제품이 달라지는 경우가 있어 조회일과 문서의 제품 버전을 구분한다.

## 출처를 구분하는 기준

- **공식 도움말·제품 문서**: 서비스 운영사가 제공하는 사용 설명, 기능 문서, 공식 릴리스 기록.
- **공식 설명·공지**: 운영사의 제품 소개, 활용 가이드, 제품 변경 공지. 세부 조작이나 모든 예외를 증명하지는 않는다.
- **과거 1차 설명**: 창업자가 외부 플랫폼에 직접 게시한 제품 설명. 해당 시점의 설명이며 현재 제품 검증을 대신하지 않는다.
- 제품별 가상 예시는 문서에서 확인한 기능을 이해하기 쉽게 적용한 것이다. 실제 고객 사례, 실제 계정 검증, 국내 제공 범위를 증명하는 자료가 아니다.

## Distrobird 확인 한계

공식 사이트 `https://www.distrobird.com`은 웹 조회에서 접근 제한이 있었고, 별도 HTTP 조회에서도 429 응답을 받았다. `support.distrobird.com`, `help.distrobird.com`, `docs.distrobird.com`에서는 공개 도움말을 찾지 못했다. 현재 서비스의 종료나 기능 삭제를 뜻한다고 해석하지 않는다.

AppSumo 전체 페이지를 운영사의 공식 도움말로 부르지 않는다. 이 자료에서 사용한 근거는 **Distrobird 공동창업자 Edwin이 직접 작성한 2023-09-11 설명**이다. 소비자 리뷰, 별점, 판매 플랫폼의 기능 체크표는 제품 기능을 확정하는 근거로 사용하지 않았다. Distrobird를 최종 후보로 고를 때에는 현재 운영사가 제공하는 도움말이나 실제 계정 확인이 추가로 필요하다.
