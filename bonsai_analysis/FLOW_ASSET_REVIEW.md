## 시각 검토

고유 화면 642개를 54장의 모음 이미지로 모두 열어 플로우 분류와 대략적인 화면 상태를 대조했다. 잘못된 앱 화면이나 눈에 띄는 깨진 이미지·잘못된 배치는 발견하지 못했다. 로딩·빈 목록·입력 오류·404·요금제 제한도 원본에 수록된 상태이므로 유지했다.

전체 축소본 검토는 642개 화면의 작은 문구·필드 정책을 모두 원본 크기로 다시 읽은 검토와 구분한다.

## 검토 범위의 구분

파일·문서 검증과 시각 검토를 별도로 기록했다. PNG 디코딩·SHA-256 통과가 분석 내용의 의미까지 재검증했다는 뜻은 아니다. 기존 R1/R2 이미지 관찰 이력은 유지했다.

이번 작업에서는 Bonsai 계정의 발송·삭제·서명·결제나 공식 도움말·API 문서 재조회를 수행하지 않았다. 각 분석의 8절에 남겨 둔 미확인 정책·실행 결과는 유지한다.

MCP의 앱 이름 검색은 상위 42개를 반환한다. 기존 하위 92개를 포함한 134개는 각각 다시 조회했으며, 화면 전체 집합도 앱 카탈로그와 대조했다. MCP에 별도 전체 하위 트리 조회 기능은 없어, 모든 가능한 분기를 새로 발견했다고 주장하지 않는다.
