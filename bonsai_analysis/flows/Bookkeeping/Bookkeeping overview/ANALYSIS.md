## 2. 플로우 목적과 연결

장부 손익의 월별 툴팁과 비용 분류별 비중·세부 항목을 탐색한다.

- 로그인한 내부 사용자 관점. 재무 보기 권한과 계정 통화 범위는 미확인.
- 시작: Overview 상단 그래프. 종료: 비용 분류 집계의 스크롤 하단.
- 모든 단계가 읽기·표시 상태이며 비용 생성·편집 과정은 포함하지 않는다.
- 프론트 구현: 그래프 포인트 팝오버, 복수 아코디언, 비용 0인 항목, 스크롤 중 사이드바 유지.

- 상위 흐름: [Bookkeeping](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Bookkeeping/Bookkeeping overview`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Bookkeeping Overview**이다. Other Income 160, Expenses 165, Profit -5가 함께 보이며 수입·지출 그래프가 존재한다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **분류 집계 하단**이다. 값이 없는 그룹도 0%·0금액으로 존재한다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Bookkeeping](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
