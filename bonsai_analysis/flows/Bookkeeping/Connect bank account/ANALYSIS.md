## 2. 플로우 목적과 연결

비용 자동 수집을 위해 은행·카드 연결 화면에서 Plaid 데이터 공유 안내까지 진입한다.

- 시작: 비용 추적 안내. 종료: Plaid Continue 전 단계.
- 은행 선택·로그인·권한 동의 완료·계좌 연결 성공은 수록되지 않았다.
- 프론트 구현: 연결 전 안내와 CSV 대안, 외부 제공자 모달 진입, 취소 후 복귀를 구분한다.

- 상위 흐름: [Bookkeeping](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Bookkeeping/Connect bank account`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Expenses 시작 안내**이다. 비용 추적 시작 안내 상태. 실제 등록 비용 목록과 안내용 샘플을 구분해야 한다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Plaid 데이터 공유 안내**이다. 외부 제공자 동의·인증 진입 전 단계. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Bookkeeping](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

비용 목록에서 은행 연결 소개를 거쳐 Plaid Continue 화면까지 기록된다. 은행 선택·인증·거래 동기화 결과는 없다. 소개의 은행 로고와 소요 시간 문구는 연결된 계정이나 측정 결과가 아니다.

### 업무 규칙과 연결 시 주의점

- 관찰: 은행·신용카드 연결과 Bulk Import CSV 대안이 보인다.
- 관찰: 외부 Plaid 창에서 은행 인증·데이터 공유를 안내한다.
- 문서 확인: 이미 가져온 비용은 은행 연결 해제 시에도 남는다고 설명한다.
- 미확인: 실제 금융기관 목록·승인 범위·연동 오류·재연결·거래 중복 처리.
