기존 검토 기록: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **11/11단계**. 계정 재현은 수행하지 않았다.

추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/11단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-f01f87a5-8396-4774-8387-e11c5e0afe03>).

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

이름·금액·분류를 입력한 비용에 청구 가능 여부와 반복 간격을 설정하고, 오류를 수정한 뒤 이미지를 첨부해 미청구 비용을 생성한다.

- 시작: Expenses 시작 안내. 종료: 미청구 비용 생성 성공 알림과 새 목록 행.
- 기록은 프로젝트 미선택 상태를 포함한다. 프로젝트 필수 여부를 UI 라벨보다 강하게 확정하지 않는다.
- 하위 이미지·메모 추가 흐름이 생성 폼 중간에 연결된다.
- 프론트 구현: 조건부 반복 입력, 폼 값 보존, 오류 배너, 이미지 미리보기, 생성 후 목록.

- 상위 흐름: [Bookkeeping](../ANALYSIS.md)
- 하위 흐름: [Adding an image and note](Adding%20an%20image%20and%20note/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Bookkeeping/Adding a recurring expense`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Expenses 시작 안내**이다. 비용 추적 시작 안내 상태. 실제 등록 비용 목록과 안내용 샘플을 구분해야 한다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **반복 비용 생성 결과**이다. You created a new unbilled expense. 알림. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Bookkeeping](<../ANALYSIS.md>), [Adding an image and note](<Adding an image and note/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 양수 반복 간격 검증과 최초 비용 목록 반영을 재현한다. 차기 발생·수정·중단 및 입력일과 결과일 차이는 별도 검토한다.
- [이 흐름의 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-f01f87a5-8396-4774-8387-e11c5e0afe03>)와 [공통 웹 상태·연결 기준](<../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.


### 동일 재현을 위한 남은 분석 (R4)

- Billable/Recurring 옆 정보 아이콘, 조건부 행·오류 띠·첨부 열 크기를 각각 명세해야 한다. 버튼 녹색이 다른 화면들과 같다고 가정하지 않는다. 날짜 차이 원인·프로젝트 미선택 허용 규칙은 추가 근거가 필요하다.
- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
