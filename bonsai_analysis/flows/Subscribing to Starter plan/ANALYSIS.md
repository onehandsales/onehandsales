## 2. 플로우 목적과 연결

체험 종료 후 Starter 플랜·월 결제를 선택해 결제 확인을 거쳐 구독 설정과 영수증 목록을 확인한다.

- Bonsai 자체 사용료 결제이며 고객 청구서 결제·Stripe 수금 연동과 구분한다.
- 모든 금액·기능은 캡처 당시 표시값. 실제 구독/카드 입력은 수행하지 않았다.

- 하위 흐름: [Canceling subscription](Canceling%20subscription/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Subscribing to Starter plan`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **체험 종료 게이트**이다. 유료플랜 선택 요구. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Team Seat와 구독 영수증**이다. 구독 청구기간 영수증1개. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Canceling subscription](<Canceling subscription/ANALYSIS.md>), [Pricing](<../Pricing/ANALYSIS.md>), [Settings](<../Settings/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
