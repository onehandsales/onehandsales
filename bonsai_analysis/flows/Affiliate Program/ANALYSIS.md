## 2. 플로우 목적과 연결

방문자가 제휴 소개·보상·귀속 기간을 읽고 외부 신청 또는 문의로 이동한다.

- Copying referral link의 무료 구독 보상과 Affiliate의 금전 수수료를 구분한다.
- 신청서·승인·대시보드·지급은 수록되지 않았다.


- 폴더 위치: `bonsai_analysis/flows/Affiliate Program`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **제휴 프로그램 소개**이다. 방문자를 소개하고 수수료를 받는 프로그램 홍보. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **제휴 최종 CTA**이다. 앞의 가입 CTA와 문의 대안을 반복한다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Landing page](<../Landing page/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
