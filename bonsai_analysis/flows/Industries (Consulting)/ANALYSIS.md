## 2. 플로우 목적과 연결

업종 메뉴에서 Consulting 소개를 열고 프로젝트·청구·협업·재무·시간 기능을 살펴본다.

- 동일 공개 레이아웃의 업종별 콘텐츠 변형이다.
- 실제 앱 Projects·Invoicing·Client portal·Time Tracking과 비교할 목업을 포함한다.


- 폴더 위치: `bonsai_analysis/flows/Industries (Consulting)`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Industries 메가 메뉴**이다. 업종별 공개 소개를 선택하는 메뉴. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **재무·시간 기능 카드**이다. Income & Expenses 선차트와 Time Tracked 막대차트, Billed Amount 배지. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Landing page](<../Landing page/ANALYSIS.md>) · [Products (CRM)](<../Products (CRM)/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
