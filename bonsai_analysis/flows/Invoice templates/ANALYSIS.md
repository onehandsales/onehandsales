## 2. 플로우 목적과 연결

Templates 메뉴에서 공개 청구서 템플릿 페이지를 열어 파일 형식·업종별 예시·앱 기능 차이를 살펴본다.

- 메뉴2장+긴 소개 페이지9장으로 구성되며 실제 파일 다운로드·청구서 생성은 없다.
- Using invoice generator와 앱 Invoicing 진입을 별도로 제공한다.


- 폴더 위치: `bonsai_analysis/flows/Invoice templates`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Templates 메가 메뉴 계약 기본**이다. Contract Templates 연녹색 활성·오른쪽 화살표, Featured contract templates. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Word 형식 장단점**이다. 쉬운 사용·비용·맞춤 편집과 오류·기능 제한·자동화/분석 부재 비교. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Filtering all templates](<../Filtering all templates/ANALYSIS.md>) · [Using invoice generator](<../Using invoice generator/ANALYSIS.md>) · [Invoices](<../Invoices/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

### R2 재검토에서 보완한 해석

메가 메뉴에서 Invoice Templates를 선택한 뒤 공개 소개·형식별 다운로드·업종 예시로 이어진다. Try Bonsai 앱 진입과 Word/PDF/Excel/Google 파일 링크는 다르다. 카드의 Task management 라벨 불일치와 목업 서명을 제품 필수 규칙으로 옮기지 않는다.

### 업무 규칙과 연결 시 주의점

- 무료 파일 다운로드·외부 Google 문서·Bonsai 앱 사용은 서로 다른 경로다.
- Task management로 표시된 청구서 카드 라벨 오류를 업무 유형으로 반영하지 않는다.
- 열람 추적·자동 알림·온라인 수금 등 앱 기능을 Word/PDF 파일 자체 기능으로 확대하지 않는다.
- 자료의 예시 서명·항목·금액은 실제 입력 필수값이나 세금 정책을 확정하지 않는다.

## 6. 공식 도움말과 API 대조

아래 URL과 5절의 문서 규칙은 **R2의 2026-11-20 대조 기록**이다. 공통 상세 대조 문서는 현재 체크아웃에 없다. R3에서 모든 URL을 다시 읽은 것은 아니며, 새로 확인한 자료와 적용 범위는 [이번 공식 자료 검토](<../../FE_REVIEW.md#official-sources>)에 구분했다. 과거 캡처에 현재 규칙을 소급 적용하지 않는다. 실제 계정이나 내부 API는 실행하지 않았다.

- [Templates API](https://docs.hellobonsai.com/api/tag/templates): R2 본문 대조 기록(S032). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.
- [공식 Invoice template](https://www.hellobonsai.com/invoice-template): R2 본문 대조 기록(S053). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.
- [Invoices API](https://docs.hellobonsai.com/api/tag/invoices): R2 본문 대조 기록(S054). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.

화면과 대조할 때는 5절의 R2 해석 및 8절의 미확인 항목을 함께 적용한다. 현재 문서에만 있는 필수값·요금제·역할·새 UI를 과거 화면의 동작으로 확정하지 않는다.

- [API 검토 범위](<../../FE_REVIEW.md#api-boundary>): 이 흐름의 내부 endpoint·실제 요청/응답·DB 스키마는 확인하지 않았다. 공개 API 목록에 없는 기능의 미지원 여부도 확정하지 않는다.
