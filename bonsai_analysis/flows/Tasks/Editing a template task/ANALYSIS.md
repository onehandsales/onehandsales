## 2. 플로우 목적과 연결

템플릿 안의 작업 제목·첨부·하위 작업을 편집하고 템플릿 작업 목록에 반영하는 흐름이다.

- 시작 화면은 작업이 없는 Default Task 템플릿이다. 다음 화면의 모달 제목은 Edit Template Task다.
- 빈 템플릿에서 편집 모달로 이어지는 진입 과정을 모두 포착한 것은 아니므로 기존 작업 생성인지 새 항목 편집인지 단정하지 않는다.
- 종료: Update company guideline 한 행이 템플릿에 표시된다. 실제 프로젝트 적용은 별도다.

- 상위 흐름: [Tasks](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Tasks/Editing a template task`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **빈 템플릿 생성 성공**이다. 이름이 있는 템플릿 상세와 성공 피드백. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **템플릿 작업 목록에 반영**이다. 빈 목록이 한 작업 목록으로 바뀜. 별도 성공 토스트는 이 캡처에 없음. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Tasks](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 6. 공식 도움말과 API 대조

아래 URL과 5절의 문서 규칙은 **R2의 2026-11-20 대조 기록**이다. 공통 상세 대조 문서는 현재 체크아웃에 없다. R3에서 모든 URL을 다시 읽은 것은 아니며, 새로 확인한 자료와 적용 범위는 [이번 공식 자료 검토](<../../../FE_REVIEW.md#official-sources>)에 구분했다. 과거 캡처에 현재 규칙을 소급 적용하지 않는다. 실제 계정이나 내부 API는 실행하지 않았다.

- [Templates API](https://docs.hellobonsai.com/api/tag/templates): R2 본문 대조 기록(S032). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.

- [Task templates 도움말](https://help.hellobonsai.com/en/articles/11488590-leveraging-task-templates): R2 본문 대조 기록(S091). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.

화면과 대조할 때는 5절의 R2 해석 및 8절의 미확인 항목을 함께 적용한다. 현재 문서에만 있는 필수값·요금제·역할·새 UI를 과거 화면의 동작으로 확정하지 않는다.

- [이 흐름의 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-91a75fcf-9857-41ff-85c2-c2de0bae87d9>)와 [공통 웹 상태·연결 기준](<../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
