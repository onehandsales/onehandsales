## 2. 플로우 목적과 연결

재설정 이메일을 요청한 뒤 새 비밀번호 입력·강도 오류·수정·성공으로 이어지는 복구 흐름이다.

- 메일함과 재설정 링크 자체는 수록되지 않았다.
- 초대 수락과 달리 완료 후 자동 로그인하지 않고 로그인 페이지를 보여준다.

- 상위 흐름: [Logging in](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Logging in/Resetting password`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **로그인 — 빈 인증 폼**이다. 로그인 입력 전 화면이다. 계정 삭제 완료나 비밀번호 재설정 완료 안내는 없다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **비밀번호 재설정 성공**이다. 자동 로그인 화면이 아님. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Logging in](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
