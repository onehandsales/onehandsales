## 2. 플로우 목적과 연결

공개 랜딩에서 로그인 폼으로 들어가 이메일·비밀번호·CAPTCHA를 거쳐 대시보드로 이동한다.

- 로그인 성공 경로5단계. 실패는 초대 플로우, 복구는 하위 Resetting password 참고.
- 2FA 화면은 이 흐름에 없다. 2FA가 없다는 정책으로 해석하지 않는다.

- 하위 흐름: [Resetting password](Resetting%20password/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Logging in`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **공개 랜딩 히어로**이다. 미인증 마케팅 페이지. 그래픽의 인보이스·비용은 실제 계정 데이터가 아님. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **로그인 후 대시보드**이다. 인증 후 조직 데이터 화면. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Resetting password](<Resetting password/ANALYSIS.md>), [Onboarding](<../Onboarding/ANALYSIS.md>), [Logging out](<../Logging out/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
