## 2. 플로우 목적과 연결

인보이스 테마를 Foundation으로 바꾸고 지급 후 팁 허용을 켠다.

- 전체 화면 Invoice Settings에서 시작한다.
- 설정 저장 후 인보이스 목록으로 복귀하며 성공 토스트가 나타난다.

- 상위 흐름: [Invoices](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Updating invoice settings`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **인보이스 표현 설정 Studio**이다. 문서 테마와 결제 페이지 레이아웃을 별도 선택. 미리보기는 실제 청구서가 아니다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **인보이스 설정 저장 후 목록**이다. 설정 저장 성공. 기존 캡처와 목록 데이터가 달라 촬영 시점 차이 가능. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Invoices](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
