# Editing default values (Invoices) 플로우 분석

검토 상태: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **4/4단계**. 계정 재현은 수행하지 않았다.

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

새 인보이스의 기본 연체료와 세율을 변경한다.

- Invoices > Default Values에서 시작한다.
- 샘플 값 Late Fee10%, Tax5%는 캡처 관찰이며 우리 제품의 법적·기본 정책으로 채택하지 않는다.

- 상위 흐름: [Invoices](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Editing default values (Invoices)`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **향후 인보이스 기본값**이다. 저장 전 기본 설정 조회. 회색 예시는 실제 저장값인지 placeholder인지 구분 필요. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **기본값 저장 성공**이다. 저장 성공 표시. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Invoices](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
