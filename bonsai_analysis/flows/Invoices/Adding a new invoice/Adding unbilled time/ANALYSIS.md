프로젝트 미청구 시간을 기간·반올림 옵션으로 골라 기존 인보이스에 청구 항목으로 추가한다.

- 1시간7초의 시간 내역이20.04로 추가되어 총70.04가 되는 경로다.

- 상위 흐름: [Adding a new invoice](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Adding a new invoice/Adding unbilled time`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Flyer Design 항목 적용**이다. 이름 오류 테두리가 사라진 정상 입력 상태. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **시간 항목과 시간표가 추가된 초안**이다. 초안 작성 완료. 지급완료 아님. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a new invoice](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 단계 01: 별도 저장 버튼이 없어도 서버 저장 방식은 단정하지 않는다.
- 단계 02: 자동으로 열린 것인지 링크 클릭인지 정확한 트리거 미확인.
- 단계 03: 드롭다운 전체 옵션·다중 프로젝트·세금 포함 여부 미확인.
- 단계 04: 이 화면 자체는 입금/발송 성공을 뜻하지 않는다. /item→/hr 변경 경위 미수록.
- 단계 05: 원본기록 개별ID·표시순서·편집/삭제 영향 미확인.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 시간 선택·초안 항목·표시 정밀도·합계 70.04를 검증한다. 초안에 추가한 시간, Billed, Paid를 독립 상태로 둔다.
