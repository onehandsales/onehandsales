# Editing invoice header 플로우 분석

검토 상태: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **2/2단계**. 계정 재현은 수행하지 않았다.

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

인보이스 상단에 브랜드용 배경 이미지를 적용한다.

- Setup > Header Image의 빈 상태와 적용 결과 두 장만 수록됐다.
- 파일 선택·유효성 검사·저장 진행은 중간에 없다.

- 상위 흐름: [Adding a new invoice](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Adding a new invoice/Editing invoice header`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **구독 인보이스 초안 편집 상단**이다. 초안. 빈 항목명·수량1·단가/합계0. 미청구 시간 안내가 존재. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **인보이스 헤더 이미지 적용**이다. 헤더 파일 적용 상태. 업로드 선택창·진행률은 없음. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a new invoice](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
