기존 검토 기록: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **5/5단계**. 계정 재현은 수행하지 않았다.

추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/5단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-be9884fd-760f-4d30-b3e0-92b55ad8274c>).

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

빈 항목 오류를 확인하고 서비스 라이브러리에서 Flyer Design을 선택해 청구 항목을 채운다.

- 금액0 초안에서 시작하며 발송 또는 검증 시도의 정확한 클릭은 수록되지 않았다.
- 항목 입력의 서비스 추천 드롭다운과 선택 결과가 핵심이다.

- 상위 흐름: [Adding a new invoice](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Adding a new invoice/Editing an item`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **인보이스 헤더 이미지 적용**이다. 헤더 파일 적용 상태. 업로드 선택창·진행률은 없음. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Flyer Design 항목 적용**이다. 이름 오류 테두리가 사라진 정상 입력 상태. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a new invoice](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 7. 데이터 모델링 시사점

다음은 관찰에 기반한 OneHandSales 구현 후보다. 기능 채택·스키마·업무 정책으로 확정하지 않는다.

- 서비스 카탈로그와 인보이스 항목 스냅샷 분리 후보. 항목명·설명·수량·단가·단위·총액·정렬 순서.
- 필수 이름 검증을 생성 시점/발송 시점 어느 단계에 적용할지 확인 필요.

### 단계별 모델링 근거

- 단계 01: 문서별 헤더 미디어와 로고 표시를 독립 후보로 둔다.
- 단계 02: 폼 전체 오류와 필드 오류 연결 후보.
- 단계 03: 항목명 검증과 선택적 설명·숫자 필드 후보.
- 단계 04: 서비스 카탈로그 조회와 문서 항목 복사 후보.
- 단계 05: 카탈로그 값의 문서별 스냅샷 및 수량×단가 계산 후보.

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** 카탈로그 없이 자유 입력 가능한지, 단위 변경·음수/0·소수 수량·할인 순서를 확인한다. 중복 선택·삭제·드래그 순서와 자동 저장 실패 복구를 확인한다.

- 카탈로그 없이 자유 입력 가능한지, 단위 변경·음수/0·소수 수량·할인 순서를 확인한다.
- 중복 선택·삭제·드래그 순서와 자동 저장 실패 복구를 확인한다.

### 단계별 미확인 사항

- 단계 01: 파일명 전체·용량·자르기·오류·저장시점 미확인.
- 단계 02: 어떤 버튼이 검증을 일으켰는지와 다른 동시 오류는 미확인.
- 단계 03: 가격0 허용 여부나 다른 오류는 이 표시만으로 확정 불가.
- 단계 04: 검색 필터·페이지네이션·통화·서비스 삭제 후 목록 처리 미확인.
- 단계 05: 별도 저장 버튼이 없어도 서버 저장 방식은 단정하지 않는다.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 빈 항목명 오류와 서비스 선택 시 항목 복사를 연결한다. 라이브러리 가격 수정과 기존 문서 금액을 독립시킨다.
- [이 흐름의 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-be9884fd-760f-4d30-b3e0-92b55ad8274c>)와 [공통 웹 상태·연결 기준](<../../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.


### 동일 재현을 위한 남은 분석 (R4)

- 오류 발생 버튼·초점 이동·추천 필터링·설명 잘림 규칙은 캡처만으로 확정할 수 없다. 입력/추천 패널의 실제 위치·치수와 오류 해제 시점을 보완해야 한다.
- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
