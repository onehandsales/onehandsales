## 2. 플로우 목적과 연결

연결된 Stripe 계정에서 기본 카드 결제 허용을 끈다.

- Stripe가 연결된 Payment Methods 모달에서 시작한다.
- Stripe 연결 해제와는 구분된다. Off 이후에도 Stripe Dashboard 링크와 공급자 카드가 남아 있다.

- 상위 흐름: [Connecting to Stripe](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Invoices/Connecting to Stripe/Turning off card payments`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **연결된 결제수단 유지**이다. 연결 후 안정상태. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **기본 카드 결제 비활성화**이다. 설정 성공. 연결해제와다름. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Connecting to Stripe](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
