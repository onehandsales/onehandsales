## 2. 플로우 목적과 연결

업종·회사명·국가·사업 형태·통화·매출 구간·팀 이메일·사용 목적을 설정하고 초기 대시보드로 이동한다.

- 가입 후 맞춤 설문이며 기존 운영 회사 설정 변경 플로우와 연결된다.
- 진행 표시5칸 중3번째에 해당하는 설문 캡처는 없다. 전체 문항을 모두 봤다고 주장하지 않는다.
- 화면의 Malaysia/MYR와 뒤 대시보드 USD는 일치하지 않는다. 기본 통화 정책을 단정하지 않는다.

- 상위 흐름: [Onboarding](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Onboarding/Completing account setup`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **사업 설정 시작**이다. 첫 진행 표시만 녹색. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **초기 작업·시간 빈 상태**이다. 시간그래프빈축,흐린작업샘플. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Onboarding](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 원본 크기 확대에서 진행 표시 5개와 01/09/11의 첫째/넷째/다섯째 활성 위치를 확인했다. 캡처 사이 생략된 세 번째 설문 내용, 국가 기본값 결정, 팀 초대 발송 결과와 선택 항목별 추가 분기는 미확인이다.
- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
