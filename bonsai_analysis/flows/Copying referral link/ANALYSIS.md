## 2. 플로우 목적과 연결

추천 프로그램의 개인 링크를 복사하고 복사 성공을 확인한다.

- 대시보드 Get1MonthFree에서 진입.
- 팀 초대와 추천 초대는 목적·보상·대상 접근권이 다르다. 이메일 발송은 수록되지 않았다.


- 폴더 위치: `bonsai_analysis/flows/Copying referral link`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **대시보드 — 프로젝트 타임라인과 손익 요약**이다. Dashboard가 선택되어 있으며 모달·오류·성공 토스트는 없다. 여러 플로우가 공유하는 동일한 시작 이미지다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **추천 링크 복사 완료**이다. 클립보드복사성공UI. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Dashboard](<../Dashboard/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
