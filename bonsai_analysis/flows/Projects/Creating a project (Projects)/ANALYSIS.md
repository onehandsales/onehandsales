## 2. 플로우 목적과 연결

프로젝트 보드에서 고객을 선택하고 프로젝트명을 입력해 새 프로젝트를 생성한다.

- Sample Client를 선택한 데모 시나리오다. 일반 고객과 다르게 자동 수락/결제 안내가 있다.
- 프로젝트 팀에는 Joe Doe가 미리 표시된다.
- 종료는 In Progress의 Consulting Project 생성 성공. 어떤 열의 생성 버튼을 눌렀는지는 중간 캡처가 부족하다.

- 상위 흐름: [Projects](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Projects/Creating a project (Projects)`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **프로젝트 보드의 초기 목록**이다. 프로젝트1개와 여러 빈 열. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **프로젝트 생성 성공 보드**이다. 생성 결과를 보여주는 시작 맥락. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Projects](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
