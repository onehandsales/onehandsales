## 2. 플로우 목적과 연결

프로젝트 카드의 Tags 메뉴에서 새 라벨을 만들고 카드에 적용하는 흐름이다.

- 생성된 Consulting Project/Sample Client에서 시작한다. 적용된 Sample 태그는 사용자가 만든 이름이다.
- Sample Client의 데모 성격과 Sample이라는 태그 이름은 구분한다. 태그가 샘플 동작을 켜는 근거는 없다.
- 태그 추가 뒤 카드가 커지며 프로젝트 제목·고객 아래 태그를 보여준다.

- 상위 흐름: [Projects](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Projects/Adding a tag`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **프로젝트 생성 성공 보드**이다. 생성 결과를 보여주는 시작 맥락. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **프로젝트 보드 목록**이다. 상태별 카드와 개수. 가로로 더 있는 열은 현재 뷰포트 밖. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Projects](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
