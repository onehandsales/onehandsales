## 2. 플로우 목적과 연결

고객 상세의 대표 이미지를 업로드해 고객 식별 표시를 바꾼다.

- 새 고객 Doe Company 상세에서 시작한다. 대표 이미지가 JS 이니셜로 나타난다.
- 파일 선택창·자르기 화면은 없으며 hover 표시와 최종 교체 이미지가 기록됐다.

- 상위 흐름: [Clients](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Clients/Uploading a client image`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **고객 생성 완료 상세**이다. 1client추가성공과 빈 업무 상세. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **고객 대표 이미지 교체 완료**이다. 업로드 후 성공 표시. 이미지 원본 파일명은 보이지 않는다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Clients](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
