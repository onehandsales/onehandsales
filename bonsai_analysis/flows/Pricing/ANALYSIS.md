## 2. 플로우 목적과 연결

공개 가격 페이지에서 연간 결제 요금제·포함 기능·추가 상품을 비교한다.

- 로그인된 것으로 보이는 Go to dashboard 헤더지만 계정·구독 변경은 하지 않는다.
- Subscribing과 Settings/Subscription 흐름의 구형 요금제에 연결해 비교한다.


- 폴더 위치: `bonsai_analysis/flows/Pricing`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **연간 가격 선택**이다. 연간 결제 월 환산 $21/$32/$66, Professional Best value for money. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **추가 상품 2종**이다. 각 $10/month; 좌석은 협업·시간·고객 관리, Tax는 비용·공제·분기 추정세 소개. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Subscribing to Starter plan](<../Subscribing to Starter plan/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
