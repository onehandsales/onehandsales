## 6. 공식 도움말과 API 대조

- [공식 Careers](https://www.hellobonsai.com/careers): 동일한 6가지 복리후생과 Focus·Speed·Ownership 가치가 확인된다. 현재 공고 CTA는 apply.workable.com으로 연결된다.
- [공개 API](https://docs.hellobonsai.com/api): 조회한 문서는 업무 리소스 중심이며 이 공개 페이지의 콘텐츠·검색·추천·제휴 관리 endpoint와 필드 계약은 확인하지 못했다. 화면 카드를 곧바로 업무 DB 테이블로 확정하지 않는다.

## 7. 데이터 모델링 시사점

- 채용 소개 콘텐츠·이미지·외부 CTA 후보. 지원자·인사 테이블은 근거가 없다.
