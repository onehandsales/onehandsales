## 2. 플로우 목적과 연결

생성된 표준 계약의 편집·서명 방법을 안내 투어로 확인한다.

- 생성 직후 Drafted/Standardized 문서에서 시작하며 계약 작성 본문은 바뀌지 않는다.

- 상위 흐름: [Creating a new contract](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Creating a new contract/Contract guide tour`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **계약 초안·첫 안내**이다. 입력 부분은 노란 강조. 본문에는 비용 사전 승인 불필요·지원 미제공 등 마법사에서 직접 보지 못한 조항도 있다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **투어 종료 후 초안**이다. 투어 종료 후 계약은 여전히 초안이다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Creating a new contract](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
