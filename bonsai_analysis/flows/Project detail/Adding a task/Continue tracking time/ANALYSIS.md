## 2. 플로우 목적과 연결

이미 수동1시간이 기록된 작업에서 타이머를 이어 실행하여 별도의 추가 시간 기록을 남기는 흐름이다.

- 작업에1시간이 있는 상태에서 시작한다.
- 2초·6초 실행 캡처 이후7초와1시간 두 기록, 총1시간7초로 끝난다.
- 기존1시간 레코드에 단순 덧셈해 덮어쓴 결과가 아니라 별도 행 두 개가 보이는 점이 모델링 근거다.

- 상위 흐름: [Adding a task](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Project detail/Adding a task/Continue tracking time`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **작업에1시간 누적 표시**이다. 한 시간 기록이 있는 작업. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **추가 기록과 누적 시간 상세**이다. 7초와 1시간 기록 및 총합 01:00:07이 보인다. 배경에는 같은 제목 카드 2개가 있다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a task](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- [이 흐름의 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-bbcfb9da-b056-42d0-bb2d-113093d50a8e>)와 [공통 웹 상태·연결 기준](<../../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
