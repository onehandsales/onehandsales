기존 검토 기록: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **5/5단계**. 계정 재현은 수행하지 않았다.

추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **1/5단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-eb7720d8-fb1d-405b-8058-3f1c21adf475>).

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

하위 작업을 완료 처리하고 프로젝트 팀 멤버를 개별 담당자로 지정하는 흐름이다.

- 부모 작업의 Subtasks 목록에서 시작하며 제목 변경 장면은 없다. flow 이름 Editing은 완료·할당 편집을 포함하는 의미로 기록한다.
- 완료된 Send invite에 Joe Doe를 지정하고 나머지 Prepare a deck은 미완료로 유지한다.

- 상위 흐름: [Adding a task](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Project detail/Adding a task/Editing a subtask`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **두 하위 작업 목록**이다. 두 항목이 일반 목록으로 표시된다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **완료 항목 담당자 반영**이다. 담당자 결과 표시. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a task](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** 완료된 하위 작업 담당자 변경 시 알림이 발생하는가? 수신자 계정으로 확인한다. 체크 해제하면 완료시각/완료자 이력이 어떻게 보존되는가? API·활동 기록을 대조한다.

- 완료된 하위 작업 담당자 변경 시 알림이 발생하는가? 수신자 계정으로 확인한다.
- 체크 해제하면 완료시각/완료자 이력이 어떻게 보존되는가? API·활동 기록을 대조한다.
- 제목 인라인 편집의 저장/취소는 어떻게 동작하는가? 이 흐름에는 텍스트 변경이 없으므로 별도 확인한다.

### 단계별 미확인 사항

- 단계 01: 부모 완료와 자식 상태 연동·다중선택.
- 단계 02: 입력 확정 시점·hover/포커스 구분.
- 단계 03: 완료시각·알림·부모 영향.
- 단계 04: 프로젝트 외 멤버·복수선택·할당 해제.
- 단계 05: 새로고침 후 유지·별도 할당 이력.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 완료된 하위 작업에도 담당자 변경을 표시한다. 체크 해제·제목 편집·부모 연동·알림을 독립 동작으로 보완한다.
- [이 흐름의 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-eb7720d8-fb1d-405b-8058-3f1c21adf475>)와 [공통 웹 상태·연결 기준](<../../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.


### 동일 재현을 위한 남은 분석 (R4)

- 플로우 이름 Editing과 달리 제목 변경 결과는 미확인이다. 완료 취소·담당 해제·삭제 결과와 행별 hover/focus 규칙을 별도 확인해야 한다.
- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
