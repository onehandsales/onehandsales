추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/4단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-c615a678-2203-45d5-bcc0-235f6b325516>).

## 2. 플로우 목적과 연결

팀의 초대 대기 사용자1명을 제거하고 목록·성공 알림을 확인한다.

- 대상은 가입 완료 멤버가 아니라 Invite Pending 행이다.
- 동일 이름의 다른 계정 행은 유지된다.

- 상위 흐름: [Settings](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Settings/Removing a user`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Team 목록**이다. 초대 대기와 가입 완료가 공존. 화면 표시 날짜는2024년2월. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **팀 멤버 제거 완료**이다. 제거 성공. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Settings](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
