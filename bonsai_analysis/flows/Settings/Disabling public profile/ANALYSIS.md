## 2. 플로우 목적과 연결

운영 회사 공개 프로필을 Disabled로 바꾸고 저장한다.

- 계정 삭제·고객 포털 비활성화와 다른 공개 페이지 설정.
- 공개 URL은 비활성화 선택 이후에도 입력칸에 남는다.

- 상위 흐름: [Settings](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Settings/Disabling public profile`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Company Settings — 공개 프로필과 주소**이다. 공개 프로필 활성. 주소의 Singapore가 여러 줄에 중복 표시. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **공개 프로필 비활성 저장**이다. 저장 성공. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Settings](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

위 표는 화면에서 보이는 상태·값이다. 성공 토스트가 있어도 수신자 접근·영수증·서버 저장을 독립 검증한 것은 아니다.

### R2 재검토에서 보완한 해석

Public Profile이 Enabled에서 Disabled로 바뀐 뒤 회사 정보 저장 성공 토스트가 나타난다. 공개 URL은 계속 표시되며, 로그아웃 상태에서 URL에 접근해 실제 차단됐는지는 확인하지 않았다.

### 업무 규칙과 연결 시 주의점

- 공개 프로필 끄기는 회사 정보를 지우는 작업으로 보이지 않는다.
- 저장 후에도 View Profile 링크와 slug가 표시된다. 익명 접근 결과는 수록되지 않음.
