# Adding a service to library 플로우 분석

최신 검토: **R4 전체 단계 구성·상태 대조 5/5 · 동일 재현 세부 명세 미완** (2026-11-22 KST). 장당 720×450 비교 시트로 직접 대조했다. 요소별 전수 확대·픽셀 일치 판정은 아니다. [기준](<../../../SOURCE_ANALYSIS_STANDARD.md>) · [결과](<../../../SOURCE_ANALYSIS_REVIEW.md>) · [원본 색인](<../../../SOURCE_ANALYSIS_INDEX.json>).

기존 검토 기록: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **5/5단계**. 계정 재현은 수행하지 않았다.

추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/5단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-023d6e51-ce87-40a9-a628-cf7b39cd3b14>).

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말·공개 API, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

공용 서비스 템플릿을 업종별로 탐색해 계정의 서비스 라이브러리에 추가한다.

- Services > View Templates에서 시작한다.
- Product 분류에서 Product feature prioritization and backlog management를 추가한다.
- 성공 토스트는 있지만 새로 추가된 서비스 편집 화면은 수록되지 않았다.

- 상위 흐름: [Services](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Services/Adding a service to library`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **서비스 라이브러리 목록**이다. 샘플서비스목록. 빈상태아님. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **서비스 추가 성공 알림**이다. 라이브러리추가성공. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Services](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 단계 05: 계정 서비스 생성과 편집 후속 경로 후보.

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** 템플릿 추가 시 새 카테고리가 자동 생성되는가? 계정 분류 목록 전후 비교 필요. 같은 템플릿을 두 번 추가할 때 중복 검사와 이름 충돌 정책을 확인한다.

- 템플릿 갱신이 이미 복사한 서비스에 반영되는지 확인한다.

### 단계별 미확인 사항

- 단계 01: 서비스설명은목록에없음. 표시 통화와 계정 통화 관계 미확인.
- 단계 02: 필터조합·검색매칭·결과페이지분할미확인.
- 단계 03: 6번째 항목은 화면 밖이므로 내용 미확인.
- 단계 04: 클릭 시 확인 모달 유무 미확인.
- 단계 05: 생성ID·복사필드·중복추가규칙미확인.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 템플릿 추가 후 실제 라이브러리에서 새 항목을 조회한다. 성공 토스트와 재조회 검증을 나누고 중복 복사·분류 생성은 미정으로 둔다.
- [이 흐름의 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-023d6e51-ce87-40a9-a628-cf7b39cd3b14>)와 [공통 웹 상태·연결 기준](<../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.


### 동일 재현을 위한 남은 분석 (R4)

- 템플릿 전체 371개 내용이 이 캡처에 있는 것은 아니다. 중복 추가·라이브러리 복귀/편집 결과·검색, 좌측 분류 전체와 행 높이/설명 줄바꿈은 추가 명세가 필요하다.
- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
