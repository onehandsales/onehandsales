추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/4단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../FLOW_REVIEW_MATRIX.md#flow-16a15a7f-2535-457e-838b-877a27767618>).

## 2. 플로우 목적과 연결

반복 사용하는 서비스 항목과 가격·단위·분류를 조회한다.

- Dashboard→Services 목록→하단스크롤→Categories 탐색.
- 서비스 항목을 선택해 청구서/제안서에 가져오는 경로와 연결된다.

- 하위 흐름: [Adding a service to library](Adding%20a%20service%20to%20library/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Services`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **대시보드 — 프로젝트 타임라인과 손익 요약**이다. Dashboard가 선택되어 있으며 모달·오류·성공 토스트는 없다. 여러 플로우가 공유하는 동일한 시작 이미지다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **서비스 분류 목록**이다. 분류조회. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Adding a service to library](<Adding a service to library/ANALYSIS.md>), [Invoices](<../Invoices/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
