## 2. 플로우 목적과 연결

인기 포털 도움말을 열고 목차·본문·관련 문서·피드백을 탐색한다.

- 이미지 속 당시 도움말과 현재 공식 문서의 내용을 분리한다.
- 삽입된 앱 스크린샷은 설명 자료이며 사용자 계정 조작이 아니다.

- 상위 흐름: [Help Center](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Help Center/Help article detail`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **인기 포털 도움말 강조**이다. hover 또는 focus 상태로 보이며 원인은 미확인. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **문서 하단 질문·연관 문서·평가**이다. 이메일 보안 링크 접근과 회사에 여러 연락처가 있을 때 각 연락처 접근 가능성을 설명. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Help Center](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 공통 미완: 요소별 누락 검사, 정확한 배치·타이포그래피·색/장식·자산 대응·미노출 상태는 [12개 검토 항목](<../../../SOURCE_ANALYSIS_STANDARD.md>)으로 추가 명세한다. 원본에 없는 동작은 관찰 사실과 분리한다. 이 문서의 R4 표시를 동일 재현 명세나 FE 구현 완료로 읽지 않는다.
