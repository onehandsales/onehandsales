## 2. 플로우 목적과 연결

사용자가 도움말 검색·인기 문서·주제별 컬렉션을 찾아 셀프서비스 지원을 받는다.

- 공식 도움말 사이트 전용 헤더를 사용한다.
- 하위 Help article detail에서 인기 포털 문서로 진입한다.

- 하위 흐름: [Help article detail](Help%20article%20detail/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Help Center`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **도움말 홈**이다. General Questions & Overview 55, Invoicing & Getting Paid 64 articles; Proposals·Contracts 일부. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **도움말 홈 하단**이다. Bonsai 2024 저작권 표시. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Help article detail](<Help article detail/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 6. 공식 도움말과 API 대조

공식 자료는 **2026-11-20 KST** 조회한 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 출처의 제한된 범위를 대조했고, 실제 계정이나 내부 API를 실행하지 않았다.

- [공개 API](https://docs.hellobonsai.com/api): 반환된 본문 범위 대조. 직접 확인한 규칙과 적용 한계는 [S003 공통 대조](<../../SOURCES.md#s003>)에 기록했다.
- [공식 도움말 홈](https://help.hellobonsai.com/en/): 반환된 본문 범위 대조. 직접 확인한 규칙과 적용 한계는 [S051 공통 대조](<../../SOURCES.md#s051>)에 기록했다.

화면과 대조할 때는 5절의 R2 해석 및 8절의 미확인 항목을 함께 적용한다. 현재 문서에만 있는 필수값·요금제·역할·새 UI를 과거 화면의 동작으로 확정하지 않는다.

- [API 검토 범위](<../../SOURCES.md#api>): 이 흐름의 내부 endpoint·실제 요청/응답·DB 스키마는 확인하지 않았다. 공개 API 목록에 없는 기능의 미지원 여부도 확정하지 않는다.
