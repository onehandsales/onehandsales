## 2. 플로우 목적과 연결

공개 템플릿 목록에서 Agreements·Quotes 유형을 바꾸고 템플릿 카드를 탐색한다.

- 앱 내부 문서 템플릿 선택과 별도 공개 카탈로그다.
- 하위 Template detail에서 견적 템플릿 상세로 진입한다.

- 하위 흐름: [Template detail](Template%20detail/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Filtering all templates`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **전체 템플릿 소개**이다. 초기 카드 Invoice 제목인데 Task management 라벨이 붙어 있고 첫 두 썸네일은 없다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Quotes 목록 아래**이다. 9개 카드와 일부 하단 잘림, 각각 미리보기·라벨·제목. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Template detail](<Template detail/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
