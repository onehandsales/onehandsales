## 2. 플로우 목적과 연결

기존 폼에 짧은 텍스트 질문과 날짜 질문을 추가한다.

- Graphic Design Brief 편집기에서 시작한다. 폼 자체 생성 과정은 이 흐름에 없다.
- 질문 응답 입력 UI처럼 보이는 부분은 편집기 미리보기이며 실제 제출값이 아니다.

- 상위 흐름: [Forms](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Forms/Adding questions to a form`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **폼 편집기 상단**이다. Create와 Content 선택. 이름/이메일은 기본 연락처 영역으로 보이나 시스템 필수 여부는 미확인. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **날짜 질문 추가**이다. 짧은 텍스트 다음 날짜 순서가 확인된다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Forms](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 캡처 범위 분류: **부분**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 질문 ID·타입·제목·필수 설정·순서를 분리한다. 편집 저장과 응답 제출을 나누고 변경 전 답변을 보존할 시나리오를 정한다.
- [이 흐름의 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-0452bfda-8ddd-4d2f-8314-7370006c6c68>)와 [공통 웹 상태·연결 기준](<../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
