## 2. 플로우 목적과 연결

응답 목록에서 제출 답변을 읽고 인쇄 기능을 확인한다.

- Jane Studio 응답을 선택한다. 하위 Giving a response 입력 이름은 Amanda Soh지만 여기 제목은 Jane Studio여서 연결된 고객 표시 정보와 대조가 필요하다.

- 상위 흐름: [Form responses](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Forms/Form responses/Response detail`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **응답 2건 목록**이다. 최신 시각 행이 위에 있다. 기존 0건에서 생성 과정 없이 2건으로 바뀌었다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **응답 상세 하단**이다. 비어 있는 날짜도 항목과 '-'가 유지된다. 추가 문의 질문은 보이지 않는다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Form responses](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
