## 2. 플로우 목적과 연결

Resources에서 블로그로 이동해 일반 목록·분류·검색·기사 진입점을 확인한다.

- 하위 Searching blog에서 분류+검색, Blog detail에서 기사 읽기를 다룬다.
- 공개 글의 추천 내용 자체를 앱 업무 규칙으로 취급하지 않는다.

- 하위 흐름: [Blog detail](Blog%20detail/ANALYSIS.md), [Searching blog](Searching%20blog/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Blog`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Resources 메뉴**이다. Resources가 초록색 활성. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **글 카드 저자와 다음 행**이다. 첫 세 카드에 같은 저자 사진·이름 표시, 요약 길이 차이. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Blog detail](<Blog detail/ANALYSIS.md>), [Searching blog](<Searching blog/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
