## 5. 업무 규칙과 데이터 변화

- [관찰] 완료 직후 작업 행은 남아 있고 체크/취소선이 표시된다.
- [관찰] 두 화면 사이 Unbilled Hours가06:01:16→08:01:16으로 바뀌지만 금액은120.42로 같고 중간 시간 입력은 없다. 작업 완료의 부작용이라고 단정하지 않는다.

## 6. 공식 도움말과 API 대조

- [현재 홈 대시보드 도움말](https://help.hellobonsai.com/en/articles/16785043-customize-your-home-dashboard): 섹션·권한·개인별 배치와 대시보드에서 작업 완료를 설명한다. 2026-09-02 문서는 새 Home 구성으로, 캡처의 Project Timeline/Profit & Loss 화면과 차이가 있다.
- [Tasks API](https://docs.hellobonsai.com/api/tag/tasks): PATCH `/public-api/v1/tasks/{uuid}` 그룹을 확인했다. 이 체크박스의 실제 상태 필드/요청은 미확인.
