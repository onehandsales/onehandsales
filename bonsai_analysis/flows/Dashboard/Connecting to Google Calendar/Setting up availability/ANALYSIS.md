추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/8단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-5da62684-3be7-48ac-923f-4fdf585d7db1>).

## 2. 플로우 목적과 연결

예약 충돌을 검사할 캘린더를 선택하고 요일별 가용 구간에서 점심시간을 제외한다.

- New Event Type 가용성 단계. 실제 특정 날짜의 예약이 아니라 요일 반복 기본 시간표를 편집한다.

- 상위 흐름: [Connecting to Google Calendar](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Dashboard/Connecting to Google Calendar/Setting up availability`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **기본 가용성 로드 완료**이다. 회색 로딩이 사라지고 Available/Unavailable 범례가 표시된다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Advanced Settings 초기값**이다. 가용성 단계에서 고급 설정으로 이동했다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Connecting to Google Calendar](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

아래 URL과 5절의 문서 규칙은 **R2의 2026-11-20 대조 기록**이다. 공통 상세 대조 문서는 현재 체크아웃에 없다. R3에서 모든 URL을 다시 읽은 것은 아니며, 새로 확인한 자료와 적용 범위는 [이번 공식 자료 검토](<../../../../FE_REVIEW.md#official-sources>)에 구분했다. 과거 캡처에 현재 규칙을 소급 적용하지 않는다. 실제 계정이나 내부 API는 실행하지 않았다.

- [공개 API](https://docs.hellobonsai.com/api): R2 본문 대조 기록(S003). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.
- [예약·캘린더 공식 도움말](https://help.hellobonsai.com/en/articles/6823760-set-up-scheduling-and-booking-pages): R2 본문 대조 기록(S044). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.

화면과 대조할 때는 5절의 R2 해석 및 8절의 미확인 항목을 함께 적용한다. 현재 문서에만 있는 필수값·요금제·역할·새 UI를 과거 화면의 동작으로 확정하지 않는다.

- [API 검토 범위](<../../../../FE_REVIEW.md#api-boundary>): 이 흐름의 내부 endpoint·실제 요청/응답·DB 스키마는 확인하지 않았다. 공개 API 목록에 없는 기능의 미지원 여부도 확정하지 않는다.

- 단계 01: All이 미래 추가 캘린더까지 포함하는지·기본값 결정 방식은 미확인.
- 단계 02: All과 미체크의 내부 저장 표현은 미확인.
- 단계 03: 대상 캘린더가 예약 생성 캘린더와 반드시 같아야 하는지는 미확인.
- 단계 04: 클릭/드래그 행동과 경계 포함 규칙은 미확인.
- 단계 05: 클릭 이벤트는 직접 캡처되지 않았다.
- 단계 06: 삭제 취소·재추가 및 저장 시점은 미확인.
- 단계 07: 금요일 조작 중간 단계와 저장 완료는 미수록.
