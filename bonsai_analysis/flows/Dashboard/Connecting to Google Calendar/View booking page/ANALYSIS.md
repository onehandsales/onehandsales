## 6. 공식 도움말과 API 대조

- [예약·캘린더 공식 도움말](https://help.hellobonsai.com/en/articles/6823760-set-up-scheduling-and-booking-pages): 공개 예약 페이지를 제공한다. 이 캡처에는 예약 확정이 없다.
- [공개 API](https://docs.hellobonsai.com/api): 검토한 공개 목록에서 예약 유형·가용 시간·캘린더 연결 전용 endpoint와 필드 계약은 확인하지 못했다.

## 7. 데이터 모델링 시사점

- 예약 유형 표시와 날짜/시간대별 계산된 슬롯 후보. 슬롯 목록을 예약 레코드로 혼동하지 않는다.
- 추가 확인할 후보: 예약자 정보·선택시각·동시성 제어·외부 일정 참조.

## 8. 미확인 사항과 검토 질문

- 시간 선택 이후 연락처/추가 질문/결제/확정·중복 예약 충돌 처리 화면을 확보한다.

- 주간 가용성·버퍼·리드타임·외부 일정이 슬롯 계산에 적용되는 경계를 실제 예약으로 대조한다.
