기존 검토 기록: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **5/5단계**. 계정 재현은 수행하지 않았다.

추가 검토: **R3 문서·MCP 목록 대조 완료 / FE 보완 항목 있음**. 이번 이미지 확인은 고유 이미지 기준 선택 검토이며 이 흐름에 해당하는 화면은 **0/5단계**다. 기존 R2 전수 시각 검토 이력과 구분한다. [플로우별 FE 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-dc6c28b1-c2c2-4118-9358-3578b336031e>).

## 2. 플로우 목적과 연결

예약 가능 기한·간격·추가 질문·알림 설정을 구성한다.

- New Event Type 마법사3단계에서 시작해4단계 브랜딩으로 이동한다.

- 상위 흐름: [Connecting to Google Calendar](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Dashboard/Connecting to Google Calendar/Editing advanced settings`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Advanced Settings 초기값**이다. 가용성 단계에서 고급 설정으로 이동했다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **Branding & Design 초기**이다. 3단계를 벗어나 마지막 디자인 설정에 도달했다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Connecting to Google Calendar](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
