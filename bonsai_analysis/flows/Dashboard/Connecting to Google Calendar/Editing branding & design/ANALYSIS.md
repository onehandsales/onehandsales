## 2. 플로우 목적과 연결

예약 페이지 테마와 프로필 이미지를 설정하고 이벤트 유형 생성을 마친다.

- 마법사4단계에서 시작해 생성 완료와 유형 목록으로 끝난다.
- 회사 전체 로고 설정과 별도 Add Custom Profile Image가 있다. 상속 관계는 미확인.

- 상위 흐름: [Connecting to Google Calendar](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Dashboard/Connecting to Google Calendar/Editing branding & design`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **Branding & Design 초기**이다. 3단계를 벗어나 마지막 디자인 설정에 도달했다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **생성된 유형 목록**이다. 생성한 유형이 목록에 나타난다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Connecting to Google Calendar](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 단계 10: 정의와 인스턴스의 분리.

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** Custom Theme의 색/폰트 범위와 회사 기본 브랜딩의 상속·우선순위를 확인한다. 이미지 용량/확장자/크롭/실패/제거 동작, 업로드 후 Cancel 시 자산 정리를 확인한다.

- Custom Theme의 색/폰트 범위와 회사 기본 브랜딩의 상속·우선순위를 확인한다.
- 이미지 용량/확장자/크롭/실패/제거 동작, 업로드 후 Cancel 시 자산 정리를 확인한다.
- 브랜딩 표시의 요금제 권한과 공개 페이지 캐시 갱신을 확인한다.

### 단계별 미확인 사항

- 단계 01: 브랜딩 off의 요금제 권한·이미지 제한은 미확인.
- 단계 02: Custom Theme 상세는 미수록.
- 단계 03: 키보드/hover 트리거는 미확인.
- 단계 04: 정확한 색 hex는 화면에서 제공되지 않는다.
- 단계 05: 폰트/크기 등 테마별 차이는 미확인.
- 단계 06: 파일 선택창·선택 파일 원본·취소는 미수록.
- 단계 07: 정확한 백분율·처리 단계는 미확인.
- 단계 08: 실제 자산 ID·크롭·최종 유형 연결 저장은 미확인.
- 단계 09: 전체 URL·공개 범위·생성 실패 경로는 미확인.
- 단계 10: 새로고침 후 유지와 실제 예약 연동은 미확인.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 테마·로고 초안과 Finish 성공을 나눈다. 유형 생성 후 목록과 공개 페이지가 같은 설정을 사용하도록 검증한다.
- [이 흐름의 보완표](<../../../../FLOW_REVIEW_MATRIX.md#flow-d9ed6982-0264-44ed-bb1a-82ad16b0e89f>)와 [공통 웹 상태·연결 기준](<../../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
