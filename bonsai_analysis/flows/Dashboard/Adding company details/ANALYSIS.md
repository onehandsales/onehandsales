## 2. 플로우 목적과 연결

자신의 사업체 이름·주소·기본 통화·로고를 온보딩에서 입력한다.

- CRM 고객사 생성이 아니라 서비스 사용 사업체의 설정이다.
- 주소 내부 Save Address와 전체 모달 Save가 별도로 존재한다.

- 상위 흐름: [Dashboard](../ANALYSIS.md)
- 하위 흐름: [Uploading company logo](Uploading%20company%20logo/ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Dashboard/Adding company details`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **회사 정보 온보딩**이다. 자기 사업체 설정 안내. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **대시보드 예약 온보딩**이다. 예약 페이지 생성 단계의 안내 화면. 아래 Timeline은 현재 활동 없음. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Dashboard](<../ANALYSIS.md>), [Uploading company logo](<Uploading company logo/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

### R2 재검토에서 보완한 해석

Country는 Malaysia에서 Singapore로 바뀌지만 Currency는 USD다. 상세 주소 저장 버튼과 회사 전체 Save 버튼을 구분한다. Address 1에 도시·우편번호까지 입력되어 요약에서 중복 표시되며 이를 임의 정규화하지 않는다. 마지막 대시보드에서 회사 정보 체크가 보이나 체크리스트 자동 판정 조건은 확인되지 않았다.

### 업무 규칙과 연결 시 주의점

- [관찰] 초기 국가 Malaysia/통화USD에서 국가Singapore로 바꿔도 통화USD는 유지된다.
- [관찰] 주소는1/2줄·도시·우편번호·지역·국가로 나뉘며 요약에서 합성된다.
- [관찰] 주소1에 도시/우편번호까지 입력해 요약에 중복 표시된다. 자동 주소 정규화가 있었다고 볼 수 없다.
- [미확인] Save Address가 즉시 서버 저장인지 전체 Save의 임시 값인지 미확인.

## 6. 공식 도움말과 API 대조

- [회사 로고·문서 헤더](https://help.hellobonsai.com/en/articles/1977524-how-to-update-your-company-logo-and-header-on-your-documents): R2 본문 대조 기록(S040). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.
