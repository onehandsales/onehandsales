## 2. 플로우 목적과 연결

사이드바를 아이콘만 남기는 축소 모드로 바꾼다.

- 첫 화면과 이후2장은 업무 날짜/프로젝트 수가 다르다. 동일 연속 데이터 상태라고 보지 않는다.

- 상위 흐름: [Dashboard](../ANALYSIS.md)

- 폴더 위치: `bonsai_analysis/flows/Dashboard/Hiding sidebar`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **대시보드 — 프로젝트 타임라인과 손익 요약**이다. Dashboard가 선택되어 있으며 모달·오류·성공 토스트는 없다. 여러 플로우가 공유하는 동일한 시작 이미지다. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **아이콘 사이드바**이다. 텍스트 메뉴·큰 로고가 숨고 본문폭이 늘어난다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Dashboard](<../ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

### R2 재검토에서 보완한 해석

축소 직전과 직후 프로젝트·차트는 유지되고 메뉴 텍스트가 아이콘으로 줄며 본문 영역이 넓어진다. 앞선 화면과 날짜가 달라 전체 세 장을 같은 시점의 연속 실행으로 보지 않는다. 확대 복귀와 새로고침 후 유지 여부는 미수록이다.

### 업무 규칙과 연결 시 주의점

- [관찰] 축소해도 메뉴 아이콘과 초대/추천 아이콘은 남는다.
- [미확인] 사용자 설정 영속화·브라우저별 저장·모바일 반응형은 이3장으로 확인되지 않는다.

## 6. 공식 도움말과 API 대조

아래 URL과 5절의 문서 규칙은 **R2의 2026-11-20 대조 기록**이다. 공통 상세 대조 문서는 현재 체크아웃에 없다. R3에서 모든 URL을 다시 읽은 것은 아니며, 새로 확인한 자료와 적용 범위는 [이번 공식 자료 검토](<../../../FE_REVIEW.md#official-sources>)에 구분했다. 과거 캡처에 현재 규칙을 소급 적용하지 않는다. 실제 계정이나 내부 API는 실행하지 않았다.

- [공개 API](https://docs.hellobonsai.com/api): R2 본문 대조 기록(S003). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.
- [현재 홈 대시보드 도움말](https://help.hellobonsai.com/en/articles/16785043-customize-your-home-dashboard): R2 본문 대조 기록(S042). 공통 상세 원문은 현재 없으며, 이 문서에 남은 규칙·한계는 5·8절에서 확인한다.

화면과 대조할 때는 5절의 R2 해석 및 8절의 미확인 항목을 함께 적용한다. 현재 문서에만 있는 필수값·요금제·역할·새 UI를 과거 화면의 동작으로 확정하지 않는다.

- [API 검토 범위](<../../../FE_REVIEW.md#api-boundary>): 이 흐름의 내부 endpoint·실제 요청/응답·DB 스키마는 확인하지 않았다. 공개 API 목록에 없는 기능의 미지원 여부도 확정하지 않는다.

## 7. 데이터 모델링 시사점

다음은 관찰에 기반한 OneHandSales 구현 후보다. 기능 채택·스키마·업무 정책으로 확정하지 않는다.

- 사용자 UI 선호 후보. 업무 도메인 테이블 변경을 요구하는 근거는 아니다.

### 단계별 모델링 근거

- 단계 01: 프로젝트·문서 참조, 기간·통화별 재무 집계, 빠른 생성 진입점 및 공통 내비게이션 후보. 메뉴 노출은 서버 권한의 증거와 구분한다.
- 단계 02: UI 선호 상태 후보.
- 단계 03: 사이드바 축소 여부 UI 상태 후보.

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** 다시 펼치기·hover tooltip·키보드 접근성·새로고침/재로그인 지속 여부를 확인한다.

- 다시 펼치기·hover tooltip·키보드 접근성·새로고침/재로그인 지속 여부를 확인한다.

### 단계별 미확인 사항

- 단계 01: 날짜와 집계의 기준 시간대, 그래프 산식, 타임라인 아이콘의 정확한 날짜 의미, 역할별 접근 권한, 홍보 노출 조건은 이 이미지로 확인할 수 없다.
- 단계 02: hover시에만 아이콘노출되는지 미확인.
- 단계 03: 확대복귀/영속화/모바일은 미확인.

- 같은 계정·제품 빌드에서 시작 상태를 맞춘 뒤 해당 업무의 정상·취소·실패·재진입 결과를 검증해야 한다. 화면 목록과 이미지 검토 완료는 제품 전체 기능의 의미적 완전성이나 구현 검증 완료를 뜻하지 않는다.

### FE 구현 전 보완 (R3)

- 캡처 범위 분류: **결과**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 사이드바 축소와 확장, 키보드 접근, 아이콘 이름을 정의한다. 화면 재진입 시 접힘 상태 보존은 구현 선택으로 기록한다.
- [이 흐름의 보완표](<../../../FLOW_REVIEW_MATRIX.md#flow-ff646f32-f010-478e-a3bd-572ccc501292>)와 [공통 웹 상태·연결 기준](<../../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
