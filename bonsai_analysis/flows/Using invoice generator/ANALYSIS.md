## 2. 플로우 목적과 연결

공개 방문자가 고객·항목을 입력해 합계를 확인하고 다운로드 진입을 시도하는 흐름이다. 마지막은 가입 화면이다.

- 앱 내부 Invoicing 작성과 달리 공개 단순 계산 폼이다.
- 5단계 가입으로 이동하지만 실제 다운로드 파일·앱 저장 완료는 없다.


- 폴더 위치: `bonsai_analysis/flows/Using invoice generator`
- 부모·자식은 Gummble 탐색 분류이며, 모든 하위 플로우가 순차 실행된다는 뜻은 아니다.
- 상위 흐름: 없음. Gummble 최상위 분류.
- 하위 흐름: 없음.

### 진입 조건과 확인된 종료 범위

- 진입: 첫 캡처는 **공개 Invoice Generator 빈 폼**이다. 로그인 없이 보이는 단순 생성기 형태. 이 화면 이전의 인증·권한·클릭 경로는 캡처에 보이는 범위만 인정한다.
- 종료: 마지막 캡처는 **계정 생성 화면으로 전환**이다. 이메일·이름·이전 청구서 정보가 명시적으로 넘어온 표시는 없다. 기록 종료를 전체 업무의 성공·서버 저장 완료로 확대하지 않는다.
- 관련 흐름: [Invoices](<../Invoices/ANALYSIS.md>), [Onboarding](<../Onboarding/ANALYSIS.md>)
- 관련 흐름은 기능 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 캡처 범위 분류: **부분**. 업무 전체의 완료 판정이 아니다.
- 목 구현·수용 기준 후보: 행 추가·단가·세금 합계를 재현한다. 다운로드 뒤 가입 경로와 데이터 보존을 분리하고 PDF 수신 성공은 추가 근거로 확인한다.
- [이 흐름의 보완표](<../../FLOW_REVIEW_MATRIX.md#flow-1a82151c-9539-4a12-8a4d-706c8557370b>)와 [공통 웹 상태·연결 기준](<../../FE_REVIEW.md#fe-acceptance>)을 함께 적용한다. 캡처에 없는 동작은 Bonsai 관찰 사실로 쓰지 않고 목 가정 또는 추가 조사로 표시한다.
