# 임시 비교용 로컬 글꼴

Outfit variable, SIL Open Font License 1.1. [제작자](https://github.com/Outfitio/Outfit-Fonts), [배포 파일](https://github.com/google/fonts/tree/main/ofl/outfit), [동봉 라이선스](OFL.txt).

2026-11-20 다운로드. Gummble 내부 앱의 정확한 family·font 자산은 미확인이다. 단층 a와 기하형 글리프가 있는 화면을 비교할 임시 fallback으로만 사용한다. **Outfit을 Bonsai 원본 폰트라고 주장하지 않는다.** 원본 자산을 확인하면 token과 비교 캡처를 함께 교체해야 한다.

외부 font CDN을 런타임에 호출하지 않는다. 한글은 OS의 Malgun Gothic, 미지원 환경은 Arial/sans-serif를 사용하므로 OS 간 동일한 한글 조판은 아직 검증하지 않았다.
