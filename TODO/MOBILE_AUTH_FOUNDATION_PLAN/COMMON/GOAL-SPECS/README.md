# Goal Specs

## 1. Goal 목록

| Goal | 담당 | 목적 |
| --- | --- | --- |
| `G01-BE-MOBILE-AUTH-API` | Backend | 모바일 전용 인증 API 구현 |
| `G02-FE-MOBILE-AUTH-APP` | Mobile | Expo React Native 인증 앱 foundation 구현 |
| `G03-MOBILE-AUTH-INTEGRATION` | Common | BE/FE 통합 검증과 완료 기록 |

## 2. 사용 방법

`/goal`로 작업할 때는 실행 대상 goal의 `.goal.md` 파일을 우선 읽고, 상세 판단이 필요하면 같은 이름의 이 폴더 문서를 함께 읽는다.

실행 파일:

- `TODO/MOBILE_AUTH_FOUNDATION_PLAN/BE-TODO/G01-BE-MOBILE-AUTH-API.goal.md`
- `TODO/MOBILE_AUTH_FOUNDATION_PLAN/FE-TODO/G02-FE-MOBILE-AUTH-APP.goal.md`
- `TODO/MOBILE_AUTH_FOUNDATION_PLAN/COMMON/G03-MOBILE-AUTH-INTEGRATION.goal.md`
