# 사이드바와 View 사용자 흐름

작성일: 2026-10-16
수정일: 2026-10-17 — 사이드바 순서·명칭 변경 및 상단 기능 메뉴 추가

사이드바에서 관리할 대상을 선택하고, 오른쪽 주화면에서 해당 대상의 기록을 View로 확인하는 흐름을 정리한다. 아래 항목명·컬럼·데이터는 화면 이해를 위한 예시다.

## 1. 사이드바 구성

사이드바는 상단의 홈·검색 아이콘 줄, 세로 기능 메뉴, 그룹 영역 순서로 구성한다.

기능 메뉴는 **알림(Notifications) → 메모(Memos) → 할 일(Tasks) → 이메일(Emails) → 레포트(Reports)** 순서다. 각 행은 기존 관리 대상 행처럼 아이콘과 텍스트를 함께 표시한다. 가로 아이콘 줄에 있던 알림은 이 세로 메뉴로 이동한다. 현재는 메뉴 표시 단계이며 각 기능의 화면·이동·API는 후속 범위다.

기능 메뉴는 행 높이 32px, 아이콘 20px, 글자 크기 14px이며 기본 텍스트 색상은 `#111827`이다.

그룹 영역은 위에서부터 **즐겨찾기 → 업무 목록 → 관리 대상** 순서로 구성한다. 세 영역 모두 현재 선택한 Workspace를 기준으로 보여준다.

| 영역 | 보여주는 항목 | 클릭했을 때 |
| --- | --- | --- |
| 즐겨찾기 | 사용자가 즐겨찾기로 등록한 View | 해당 View를 바로 연다. |
| 업무 목록 | 현재 Workspace에 속한 List 목록. 예: 영업 파이프라인 | 해당 List의 기본 View를 연다. |
| 관리 대상 | 현재 Workspace에 속한 Object 목록. 예: 회사·담당자·제품 | 해당 Object의 기본 View를 연다. |

관리 대상과 업무 목록에는 대상의 이름이 나온다. 실제 회사·담당자 등의 개별 기록은 오른쪽 주화면에 표시한다. 즐겨찾기에는 전체 View 중 등록한 View만 나온다.

## 2. 관리 대상에서 회사를 선택하는 흐름

사용자가 **관리 대상 → 회사**를 클릭하면 오른쪽에 회사 기록이 바로 표시된다. 이때 회사 Object에 연결된 기본 View가 적용된다.

```text
왼쪽 사이드바             오른쪽 주화면
─────────────────       ─────────────────────────────
즐겨찾기                 회사                  [+ 추가]
  주요 고객사
                        [전체 회사 ▼]    [검색] [필터]
업무 목록
  영업 파이프라인         회사명       업종       연락처
                        A회사        제조       ...
관리 대상                B회사        유통       ...
  회사 ← 클릭
  담당자
  제품
```

여기서 **전체 회사는 View의 이름**이다. 사용자가 회사를 클릭한 뒤 View를 한 번 더 선택해야 기록이 보이는 것이 아니라, 기본 View의 기록 화면이 바로 열린다.

`[전체 회사 ▼]`를 누르면 회사 Object에 만들어 둔 다른 View를 선택할 수 있다.

```text
[전체 회사 ▼]
 ├ 전체 회사       → 모든 회사를 표로 보기
 ├ 주요 고객사     → 주요 고객 조건으로 필터링한 표
 └ 서울 소재 회사  → 지역이 서울인 회사만 최근 등록순으로 보기
```

각 View는 같은 회사 기록을 사용하면서 필터·정렬·표시 컬럼을 다르게 저장한다. 예를 들어 주요 고객사에서 A회사의 연락처를 수정하면 전체 회사에서도 수정된 연락처가 보인다.

## 3. 업무 목록에서 영업 파이프라인을 선택하는 흐름

사용자가 **업무 목록 → 영업 파이프라인**을 클릭하면 오른쪽에 해당 List의 기본 View가 바로 열린다. 아래는 회사 기록을 List에 넣어 영업 업무를 관리하는 예시다.

```text
왼쪽 사이드바                 오른쪽 주화면
────────────────────         ──────────────────────────────────────────
즐겨찾기                     영업 파이프라인                   [+ 추가]
  이번 달 마감
                             [전체 업무 ▼]       [검색] [필터] [정렬]
업무 목록
  영업 파이프라인 ← 클릭      회사명   진행 단계   담당자   예상 금액
                             A회사    상담 중     김영업   500만원
관리 대상                    B회사    제안 중     이영업   300만원
  회사                       C회사    계약 완료   박영업   800만원
  담당자
  제품
```

`[전체 업무 ▼]`를 누르면 이 List에 만들어 둔 다른 View를 선택할 수 있다.

```text
[전체 업무 ▼]
 ├ 전체 업무       → 표로 보기
 ├ 단계별 진행     → 칸반으로 보기
 └ 이번 달 마감    → 이번 달 마감 조건으로 필터링한 표
```

선택한 List에 등록된 기록과 그 업무에서 사용하는 정보를 함께 보여준다. 이 예시에서는 회사명은 원본 회사 정보이고, 진행 단계·담당자·예상 금액은 해당 List에서 관리하는 업무 전용 정보다.

View를 전체 업무에서 단계별 진행으로 바꾸면 같은 업무 기록을 표 대신 칸반으로 확인한다. 이번 달 마감을 선택하면 그중 마감일 조건에 맞는 기록만 확인한다.

## 4. 즐겨찾기를 선택하는 흐름

사용자가 **즐겨찾기 → 이번 달 마감**을 클릭하면 영업 파이프라인의 이번 달 마감 View가 바로 열린다. 업무 목록에서 영업 파이프라인을 열고 해당 View를 선택한 것과 같은 화면이다.

즐겨찾기는 기존 View로 이동하는 바로가기다. 즐겨찾기 등록 여부와 관계없이 해당 View는 소속 Object/List의 상단 보기 선택 메뉴에서 사용할 수 있다.

## 5. 개발자가 이해해야 할 핵심 기준

- **Object/List는 관리 대상과 업무의 구분이다.** 사이드바에서 어느 대상의 화면을 열지 결정한다.
- **View는 기록을 보여주는 설정이다.** 같은 Object/List에 View를 여러 개 만들고 각각 표시 형태·컬럼·필터·정렬을 설정할 수 있다.
- **본문은 선택한 View를 기준으로 구성한다.** View 설정을 적용하고, 실제 값은 원본 Record와 필요한 List Entry의 업무값에서 가져온다. View 테이블에 기록 전체를 복사해 두는 구조는 아니다.
- **View 선택과 타입 변경을 구분한다.** 전체 업무에서 단계별 진행을 선택하는 것은 다른 View로 전환하는 행동이다. 현재 View 자체를 표에서 칸반으로 수정하는 것은 별도 설정 행동이다.
- **드롭다운과 탭은 같은 보기 선택 기능의 표현 방식이다.** 위 예시는 드롭다운이며, 현재 POC의 상단 가로 탭도 같은 Object/List에 속한 View를 선택하는 역할을 한다.
- **기본 View는 메뉴 클릭 직후 처음 표시하는 View를 뜻한다.** 기본 설정과 마지막 선택 중 무엇을 우선할지에 대한 세부 정책은 후속 구현에서 결정한다.
