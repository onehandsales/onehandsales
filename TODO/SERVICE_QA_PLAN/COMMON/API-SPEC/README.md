# API Spec

상태: Index / per-API template audit excluded

## 1. 문서 목록

- `ERROR_REPORT_API.md`: User Web 도움말 모달 에러 신고 접수 API 계약
- `SUPPORT_REQUEST_API.md`: User Web 도움말 모달 지원 요청 접수 API 계약

## 2. 감사 기준

- 이 README는 API 계약서가 아니라 `COMMON/API-SPEC` 인덱스 문서다.
- per-API 템플릿 필수 항목 감사에서는 제외한다.
- 실제 API 계약 필수 항목은 각 API 문서에서 관리한다.

## 3. 범위

현재 Service QA UX 개선 범위에서는 사용자가 도움말 모달에서 에러 내용을 작성하고 선택적으로 현재 화면 스크린샷을 첨부해 신고하는 User API와, 기능 문의/요금제 문의/전화 상담 요청/기능 제안/기타 문의를 접수하는 User API만 다룬다.

관리자 조회 API와 관리자 화면은 후속 범위다.
