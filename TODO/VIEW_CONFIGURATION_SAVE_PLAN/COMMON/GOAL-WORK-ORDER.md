# 작업 순서와 완료 기준

기존 사용자 승인으로 수행한 구현을 재검토하며 누락된 문서 구조를 보완했다. 이 문서의 작성 시점을 구현 전으로 소급하지 않는다. 추가 변경은 아래 의존 순서로 검토한다. `/goal` 실행이나 새 제품 결정을 자동 요청하는 문서는 아니다.

| 순서 | 목적·포함 | 제외 | 상세 / 완료 기준 |
|---|---|---|---|
| G00 | 승인 범위, 공통 API/DB/UX 계약 | 새 정책 결정 | [계약 검토](GOAL-SPECS/G00.md), request/response/error/transaction/log/DB 추적 가능 |
| G01 | BE 설정 저장·미리보기·대표 이름 | 일반 DB 테스트의 Supabase 실행 | [BE 구현](GOAL-SPECS/G01.md), 계층/소속/원자성 테스트 및 정적 검증 |
| G02 | FE 공통 초안·명시 저장·복구 | 나머지 8개 타입과 새 보기 생성 | [FE 연결](GOAL-SPECS/G02.md), 단위/브라우저 검증 및 현재 문서 동기화 |

결과는 [재검토 보고서](PLANNING-REVIEW.md)에 기록한다. API 상태는 implemented다. 앞 단계의 계약/검증 실패가 생기면 먼저 보완하고 뒤 단계에 반영한다.
