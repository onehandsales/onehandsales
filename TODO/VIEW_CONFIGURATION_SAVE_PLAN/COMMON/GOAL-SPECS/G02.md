# G02 Frontend 연결

선행: G01. 상세 명세와 필수 선행 문서는 [FE 구현](../../FE-TODO/IMPLEMENTATION.md), 화면 행동은 [사용자 흐름](../USER-FLOW.md), API/오류는 [공통 계약](../API-SPEC/VIEW_CONFIGURATION_API.md)을 따른다.

화면: 기존 관리항목/업무목록/특정 View 페이지의 헤더 메뉴와 TABLE 컬럼, 본문 상단 저장 영역. 입력: 필터 연산/값, 정렬 우선순위, 표시 역할/이름/폭/숨김/순서, 그룹/단계/표시 간격. loading/empty/error/conflict/success/권한 없음 상태를 구분한다.

완료 기준: 세 메뉴 한 번 저장, 되돌리기, 새로고침 복원, 실패 입력 유지, 명시적 409 복구, IME/좁은 화면, 저장 중 이동과 복귀, 늦은 응답의 다른 View 영향 차단. Vitest/관련 Chromium E2E/typecheck/lint/build와 문서 링크 검사를 통과하고 [검토 보고서](../PLANNING-REVIEW.md)에 기록한다.
