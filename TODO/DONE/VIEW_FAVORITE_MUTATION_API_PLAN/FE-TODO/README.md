# Frontend 후속 범위

이 작업은 Backend만 구현했다. FE 파일은 변경하지 않았다. [TODO Software 정본](../../../../AGENT/PM_AGENT/CONVENTION/TODO_SOFTWARE_AGENT_REFERENCE.md)과 [API 계약](../COMMON/API-SPEC/VIEW_FAVORITE_MUTATION_API.md)을 후속 구현 시 먼저 읽는다. 후속 구현은 별도 활성 계획으로 진행한다.

후속 작업은 현재 헤더의 유효한 viewId로 별표 등록/해제를 호출하고, isFavorite와 개인 사이드바를 갱신하는 것이다. View 없는 빈 헤더는 쓰기 요청을 보내지 않는다. 즐겨찾기 선택 이동·정렬 변경은 이번 범위에 포함하지 않는다.
