# Bonsai FE 목 계획 문서화 기록

작성일: 2026-11-20 KST
작성 당시 상태: 문서화·문서 검증 완료, G/R 실행 미착수. 현재 실행 상태는 [순서표](GOAL-WORK-ORDER.md)와 [재점검 결과](../RESULTS/G01_G15_RECHECK_RESULT.md)를 따른다.

## 요청과 범위

- 사용자는 TODO에 Goal 계획을 문서화하고, 추가 분석을 해당 기능 착수 때 확인하도록 연결하며, 로그인 전 랜딩 등 공개 화면을 포함하도록 요청했다.
- 이번 요청으로 TODO 접근·문서 작성을 허용한다. TODO_LOG는 접근하지 않고 이 파일에 문서 작업 기록을 남긴다.
- FE/BE 실행 코드, DB, 환경, 실제 계정, 커밋은 이번 문서 작업에 포함하지 않는다.

## 진행 기록

- 시작 시 Git 변경 없음 확인.
- 기존 TODO 시작 문서의 참고 기준과 연결 파일이 현재 Bonsai 방향에 맞지 않음을 확인.
- PM 계획 규칙, FRONT_AGENT의 목 개발·웹·주석·검증 규칙과 기존 134개 분석의 Goal 대응을 대조.
- 로그인 전 공개 웹, 인증·초대, 내부 업무, 외부 수신자 화면을 구분해 실행 순서를 작성.
- 공개 웹을 G02~G09, 인증·온보딩·앱 진입을 G10~G14로 배치하고 이전 대화 번호 대응을 기록.
- 공통·구현·검증 G 85개, 추가 분석 R 22개에 개별 명세·선행 조건·체크리스트·결과 기록란을 작성.
- 원본 분석 8절의 미확인 질문을 해당 G 체크리스트에 연결하고 R에서 발견할 추가 기능의 구현 배정 의무를 명시.
- 공개 CTA의 가입/로그인 인계와 입력 복귀를 G14 완료 조건에 추가.
- 기존 TODO 시작 문서의 참고 기준과 유효하지 않은 계획 링크를 새 Bonsai 계획으로 갱신.
