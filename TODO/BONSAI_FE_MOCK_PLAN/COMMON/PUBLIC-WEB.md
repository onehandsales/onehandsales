## 공개 웹의 웹 품질 기준

- 공개 route는 가상 세션이 없어도 직접 진입·새로고침·뒤로 가기가 가능해야 한다. 앱의 인증 bootstrap·workspace API를 자동 호출하지 않는다.
- 헤더·푸터·메가메뉴·검색·템플릿 카드·플랜 비교를 책임별 컴포넌트로 나눈다. 광고 이미지 속 앱 목업은 실제 입력 UI로 착각하지 않게 한다.
- 좁은 화면에서 메뉴 열기/닫기·키보드 포커스·Escape·스크롤 복귀, 긴 제목, 표/가격 카드의 재배치를 검증한다. 이미지로 보이지 않은 모바일 원본은 가정으로 남긴다.
- 검색 무결과·잘못된 상세 URL·이미지 실패·로딩·가입 인계 실패와 재시도를 구현한다. 정적 본문에 불필요한 가짜 로딩을 강제하지 않는다.
- 문서 제목·설명·canonical/index 여부·내부 링크·404·기존 정적 SEO 빌드 영향을 확인한다. 확정된 검색 노출 정책 없이 운영 배포하지 않는다.
- 쿠키/동의 UI가 원본 또는 실제 사용 기술상 필요한지는 R01에서 조사한다. 단지 랜딩이라는 이유로 새로운 정책·추적 기능을 추가하지 않는다.
- 비밀번호·개인정보를 return URL에 넣지 않는다. 초안 인계는 개발 목 저장소의 별도 데이터로 다루고 리셋/만료 시나리오를 정한다.

## 고객에게 공유하는 화면은 별도 영역

공개 폼(G48), 공개 예약(G53), 문서 검토·서명·결제(R09/R13/R14), 고객 포털(R17)은 외부 수신자가 쓰는 업무 화면이다. 일반 마케팅 랜딩과 동일한 로그인 정책을 적용하지 않는다. 링크 토큰·만료·수신자 확인·공유 해제·다른 고객의 접근은 해당 분석에서 확인한다.

## 완료 판정

- G02~G09: 각 공개 화면의 범위·의도 전달·웹 동작을 검증한다. 아직 없는 가입 목적지까지 완료했다고 기록하지 않는다.
- G10~G14: 공개 CTA → 인증/온보딩 → 의도한 화면의 왕복을 실제 브라우저에서 검증한다. G14에서 인계 누락이 있으면 내부 업무 진입 완료를 보류한다.
- G83/G84: 공개 유입과 내부·외부 업무 연결을 다시 검증하고 추가 구현 대기표의 누락을 감사한다.

## G04 현재 연결과 미확인

`/pricing`의 플랜/주기·가격 근거 버전은 이력별 로컬 snapshot으로 `/signup` 또는 `/preview/subscription`에 인계한다. G04 당시 G10/G79 인계만 있었다. 현재 G10~G14 가상 가입/온보딩과 선택 복귀는 연결했으며 G79 본문·구독 변경은 미구현이다. `/reviews`의 30카드·배지는 과거 콘텐츠이며 외부 주소는 `/outbound/reviews/{id}`의 로컬 경계로만 연결한다. 영상은 미제공 Dialog다. [G04 결과](../RESULTS/G04_RESULT.md)에서 상태 수명·원본/보완·시각/환경 대기를 구분한다. Professional services의 원본 주소는 미확인이며 `/software/professional-services`는 G03 본문 대기용 로컬 후보다. 기존 290개 메뉴 색인과 G03의 33개 배정 판정을 소급 수정하지 않는다.

## G02 현재 재검토 — 2026-11-23 KST

[현재 결과](../RESULTS/G02_RECHECK_RESULT.md#g02-r4-recheck): 20개 원본 열람·주요 구성 대조, 메뉴 초점3경로/후기 강조1곳 보완 및 DOM 회귀. 추가 검토에서 같은 목적지 재선택 뒤 메뉴 종료·본문 초점도 보완했다. 기존 G10/G11 가입·로그인 화면과 G13/G14 목 연결을 유지한다. 과거의 미구현 설명은 현재 상태가 아니다. 실제 브라우저 상세/네트워크·엄격한 시각 동일성은 대기다.

키보드 초점이 헤더 안에 있으면 hover 이탈로 메뉴를 닫지 않는다. 패널에 초점이 있으면 다른 메뉴/템플릿 유형의 우발적 hover로 초점 대상을 교체하지 않는다. 명시 클릭/방향키·Escape·외부 포인터·헤더 밖 blur는 기존 정책이다. 원본 hover/focus 동작을 관찰한 사실이 아닌 접근성 목 가정이다.
