# R02 — 인증·온보딩·워크스페이스·역할

상태: **G10~G13·G17~G18 소비 분석·목 정책/후속 배정 수행, 전체 역할·원본 미수록·초대 추가 예외 대기** · 종류: 추가 분석 Goal · 실제 계정 재현: 미수행

## 1. 실행 시점과 소비 Goal

- [시작 체크리스트](<../START-CHECKLIST.md>)와 [UX/UI 재현 기준](<../UXUI-REPLICATION.md>)을 먼저 읽는다. FRONT_AGENT를 적용하며 Backend 문서·계약 확인은 현재 선행 조건에 포함하지 않는다.
- 기본 순서: 첫 소비 Goal 직전에 수행한다. 이미 확인한 자료의 재사용은 조회일·버전·적용 범위를 대조한 뒤 기록한다.
- 소비 Goal: [G11 로그인·로그아웃](<../GOAL-SPECS/G11.md>) · [G12 비밀번호 재설정](<../GOAL-SPECS/G12.md>) · [G10 회원가입](<../GOAL-SPECS/G10.md>) · [G13 사업 설정 온보딩](<../GOAL-SPECS/G13.md>) · [G17 멤버 초대·대기 초대 제거](<../GOAL-SPECS/G17.md>) · [G18 초대 수락·협업자 접근](<../GOAL-SPECS/G18.md>)
- 선행 공통 기준: [G00 근거·버전·범위 대응표](<../GOAL-SPECS/G00.md>). 실제 FE 구현 완료가 분석 착수 조건은 아니다.
- 목적: 아래 질문을 해결하여 관찰된 화면 재현과 미수록 업무 구현의 경계를 정한다. 제품 전체 조사가 끝날 때까지 독립적인 다른 기능을 멈추는 조건으로 확대하지 않는다.

## 2. 이번 분석에서 확인할 질문

이번 R은 화면·상태·상호작용을 보완한다. 아래 질문 중 API·DB·서버 처리·실계정 검증은 후속 메모로 분류한다. 그 답을 기다리며 관찰된 UX/UI 구현을 멈추지 않으며 실제 API나 외부 서비스를 연결하지 않는다.

- [ ] 소셜 가입/연결·메일 검증·2FA·만료·재설정 토큰 재사용을 조사한다.
- [ ] 누락된 세 번째 설문·국가/통화 차이·중단 복구·건너뛰기를 확인한다.
- [ ] 초대 수락·잘못된 계정·만료·재발송·가입 완료 멤버 제거를 대조한다.
- [ ] 워크스페이스 전환과 Owner/Partner/Project Manager/Collaborator의 직접 URL·재무 접근 표를 작성한다.
