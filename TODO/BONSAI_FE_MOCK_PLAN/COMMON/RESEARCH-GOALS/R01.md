## 1. 실행 시점과 소비 Goal

- [시작 체크리스트](<../START-CHECKLIST.md>)와 [UX/UI 재현 기준](<../UXUI-REPLICATION.md>)을 먼저 읽는다. FRONT_AGENT를 적용하며 Backend 문서·계약 확인은 현재 선행 조건에 포함하지 않는다.
- 기본 순서: 첫 소비 Goal 직전에 수행한다. 이미 확인한 자료의 재사용은 조회일·버전·적용 범위를 대조한 뒤 기록한다.
- 소비 Goal: [G02 랜딩·공통 메뉴](<../GOAL-SPECS/G02.md>) · [G03 고객군·업종·CRM 소개](<../GOAL-SPECS/G03.md>) · [G04 가격·후기](<../GOAL-SPECS/G04.md>) · [G05 블로그·검색·상세](<../GOAL-SPECS/G05.md>) · [G06 공개 템플릿·상세·파일 형식](<../GOAL-SPECS/G06.md>) · [G07 공개 청구서 생성기](<../GOAL-SPECS/G07.md>) · [G08 도움말·기사·문의](<../GOAL-SPECS/G08.md>) · [G09 제휴·채용·정책 안내](<../GOAL-SPECS/G09.md>) · [G82 제휴 혜택](<../GOAL-SPECS/G82.md>)

- 목적: 아래 질문을 해결하여 관찰된 화면 재현과 미수록 업무 구현의 경계를 정한다. 제품 전체 조사가 끝날 때까지 독립적인 다른 기능을 멈추는 조건으로 확대하지 않는다.

## 2. 이번 분석에서 확인할 질문

이번 R은 화면·상태·상호작용을 보완한다. 아래 질문 중 API·DB·서버 처리·실계정 검증은 후속 메모로 분류한다. 그 답을 기다리며 관찰된 UX/UI 구현을 멈추지 않으며 실제 API나 외부 서비스를 연결하지 않는다.

- [ ] 메가 메뉴의 모든 목적지와 캡처에 없는 공개 페이지를 열거한다.
- [ ] 가격·체험·환불·혜택·약관·정책 본문의 버전과 미수록 영역을 구분한다.
- [ ] Start free / Log in / Book a demo / Get template / Download의 도착지와 가입 후 복귀·입력 보존을 대조한다.
- [ ] 반응형 메뉴·영상·후기·검색·FAQ의 키보드와 실패 상태를 명세화한다.
