# G74 — 설정 탐색·프로필·사진

상태: **미착수** · 영역: **내부 업무** · 이전 대화 번호: `G66`

## 1. 목적·포함·제외

- 목표: 사진 미리보기·Save·재진입을 확인하고 개인 사진과 회사 로고를 구분한다.
- 행위자: 가상 workspace의 소유자·허용된 멤버. 역할별 가시성은 근거 또는 명시한 목 시나리오로 구분한다.
- 포함: 제목의 동작과 아래 원본 단계, 연결된 R Goal에서 이번 범위로 확정한 성공·취소·실패·재진입.
- 제외: 실제 인증/업무 API 연결, 실제 발송·결제·서명·은행 동기화, DB 변경, 배포. 원본에 없는 기능은 분석 결과와 연결한 별도 구현 Goal로 등록한다.

## 3. 화면·입력·근거

- 주요 입력·표시: 개인 이름·사진·프로필, 회사·팀·연동·구독 탭
- 페이지/feature UI는 표시·사용자 의도, hook은 상태·요청, adapter는 저장소 경계를 맡는다. 모든 신규 컴포넌트·hook·함수에 한 줄 한글 `// 기능 : ...` 책임 주석을 둔다.
- route·진입·복귀는 [전체 사용자 흐름](<../USER-FLOW.md>)을 기준으로 해당 Goal 착수 때 확정한다. 원본 URL과 우리 URL 후보를 구분한다.

- [Settings](<../../../../bonsai_analysis/flows/Settings/ANALYSIS.md>) · `fe127bb6-984a-4b25-927f-4186b6650743` · 01~12단계. 4절의 화면/입력/버튼, 5절 규칙, 8절 질문을 함께 확인한다.
- [Settings/Uploading profile picture](<../../../../bonsai_analysis/flows/Settings/Uploading profile picture/ANALYSIS.md>) · `7f83211c-f4cf-4bc7-a715-c64a2a27626b` · 01~05단계. 4절의 화면/입력/버튼, 5절 규칙, 8절 질문을 함께 확인한다.

## 4. 목 데이터·저장·검증 경계

- 가상 ID·고정 시각·통화·역할의 시작 seed를 기록한다. 동명 객체를 같은 ID로 합치지 않는다.
- 입력 초안과 저장 결과를 구분한다. 하위 Save/전체 Save/자동 반영은 출처에 맞춰 선택하고 취소·실패 시 남는 값을 명시한다.
- 같은 객체의 목록·상세·선택지·검색·집계를 하나의 저장소에 연결한다. 이미 구현된 소비 화면은 재조회하고 아직 없는 소비 화면은 후속 Goal의 연결 검증에 남긴다.
- 조회는 초기 로딩·빈 데이터·필터 무결과·오류·권한 제한, 변경은 pending·성공·검증 오류·실패·재시도를 해당 행동에 맞게 준비한다.
- 로컬 목: [화면 상태 기준](<../MOCK-UI-STATE.md>)에 따라 표시·입력·변경을 프론트 내부에서 처리한다. API 명세·HTTP adapter·DB 스키마는 작성하지 않는다.

## 5. 기능별 완료 체크

- [ ] [UX/UI 재현 기준](<../UXUI-REPLICATION.md>)에 따라 원본과 같은 viewport에서 폰트·크기·색상·간격·배치·플로우를 비교하고 남은 차이를 기록했다.

- [ ] 사진 미리보기·Save·재진입을 확인하고 개인 사진과 회사 로고를 구분한다.
- [ ] 개인·운영 회사·브랜딩·팀·구독·연동의 저장 범위를 분리한다. 2FA·기본 메시지·연동 실행과 역할별 설정은 추가 설계한다.
- [ ] 사진 선택 미리보기와 Save 성공을 나눈다. 제거·취소·형식/크기 오류와 재진입 표시를 검증한다.
- [ ] 정상·오류 수정 후 재시도·취소·재진입 결과와 관련 화면의 같은 ID를 확인했다.
- [ ] 직접 URL·뒤로/앞으로·키보드·모달 포커스·좁은 화면을 확인했다. 관련 없는 항목은 이유를 적었다.
- [ ] 실제 인증·업무·외부 서비스 호출 없이 목으로 동작함을 네트워크에서 확인했다.
- [ ] 변경에 맞는 typecheck/lint/상태·계산 검증/브라우저 시나리오를 실행하고 실제 결과를 기록했다.
- [ ] 원본과의 차이·남은 질문·새 데이터 요구·후속 Goal을 결과 기록에 연결했다.

## 6. 이번 기능에서 잊지 말아야 할 질문

원본 질문을 보존한 목록이다. 화면·사용자 동작은 이번 FE 범위에서 확인하고, API·DB·서버 정책·실계정 동작은 후속 메모로 남긴다. 후자의 답을 확정하는 것은 이 Goal의 착수·완료 조건이 아니다.

- [ ] 설정별 권한과 저장 범위는 역할별 실제 계정에서 확인할 것.
- [ ] 2FA의 장치 기억 30일은 로그인 이외 민감 작업에도 적용되는지 확인할 것.
- [ ] 새 브랜드 기본값이 기존 문서에 적용되지 않는 경계를 문서 생성 시점과 대조할 것.
- [ ] 단계 01: 메뉴 항목별 역할 권한과 이동 URL 미확인.
- [ ] 단계 02: 필수 필드 검증·이메일 변경 재인증·사진 저장 시점 미확인.
- [ ] 단계 03: 공개 URL 중복 검증 및 담당자 선택 범위 미확인.
- [ ] 단계 04: 템플릿 변수·자동 치환·사용자 편집 여부 미확인.
- [ ] 단계 05: 체크 항목별 전송 채널과 임계값 최소·최대 미확인.
- [ ] 단계 06: 클라이언트 포털 접근과 동일 개념인지·플랜 제한 미확인.
- [ ] 단계 07: 흐린 상태의 원인·SMS 번호 등록·재인증 경계 미확인.
- [ ] 단계 08: 왕관 기능의 제한 동작·미리보기와 저장 차이 미확인.
- [ ] 단계 09: 소유자 변경, 초대 중복, 좌석 과금 시점 미확인.
- [ ] 단계 10: 카드 클릭 후 인증·동기화 방향·권한 범위 미확인.
- [ ] 단계 11: 재활성화·환불·실제 종료 후 권한 미확인.
- [ ] 단계 12: 현재 플랜·지역별 가격/세금·좌석 계산 미확인.
- [ ] 허용 확장자/파일 크기/자르기와 삭제 X 동작은 추가 확인.
- [ ] 업로드 즉시 영속화되는지 Save Changes 이전 이탈로 확인 필요.
- [ ] 단계 01: 필수 필드 검증·이메일 변경 재인증·사진 저장 시점 미확인.

- [ ] 단계 03: 진행률·실패·크롭 미확인.
