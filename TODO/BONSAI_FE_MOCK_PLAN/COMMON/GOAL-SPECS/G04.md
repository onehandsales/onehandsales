# G04 — 가격·후기

상태: **가격·후기 목 구현·2차 검토·Chromium 검증 수행 / 영상 재생·잔여 시각·추가 환경 대기** · 영역: **공개 웹** · 이전 대화 번호: `G77`

## 1. 목적·포함·제외

- 목표: 과거 가격과 현재 정책을 합치지 않고 공개 가격과 앱 구독의 선택 정보를 명시적으로 연결한다.
- 행위자: 익명 방문자와 가상 로그인 방문자. 역할별 가시성은 근거 또는 명시한 목 시나리오로 구분한다.
- 포함: 제목의 동작과 아래 원본 단계, 연결된 R Goal에서 이번 범위로 확정한 성공·취소·실패·재진입.
- 제외: 실제 인증/업무 API 연결, 실제 발송·결제·서명·은행 동기화, DB 변경, 배포. 원본에 없는 기능은 분석 결과와 연결한 별도 구현 Goal로 등록한다.

## 3. 화면·입력·근거

- 주요 입력·표시: 월/연 전환, 플랜·가격 버전, 후기·영상
- 페이지/feature UI는 표시·사용자 의도, hook은 상태·요청, adapter는 저장소 경계를 맡는다. 모든 신규 컴포넌트·hook·함수에 한 줄 한글 `// 기능 : ...` 책임 주석을 둔다.
- route·진입·복귀는 [전체 사용자 흐름](<../USER-FLOW.md>)을 기준으로 해당 Goal 착수 때 확정한다. 원본 URL과 우리 URL 후보를 구분한다.

- [Pricing](<../../../../bonsai_analysis/flows/Pricing/ANALYSIS.md>) · `981ffcc3-d6c0-4038-8db3-4ac8753aace4` · 01~03단계. 4절의 화면/입력/버튼, 5절 규칙, 8절 질문을 함께 확인한다.
- [Reviews](<../../../../bonsai_analysis/flows/Reviews/ANALYSIS.md>) · `d501af32-ef6e-4ca1-8d3f-cf6e67874a08` · 01~04단계. 4절의 화면/입력/버튼, 5절 규칙, 8절 질문을 함께 확인한다.

## 4. 목 데이터·저장·검증 경계

- 가상 ID·고정 시각·통화·역할의 시작 seed를 기록한다. 동명 객체를 같은 ID로 합치지 않는다.
- 입력 초안과 저장 결과를 구분한다. 하위 Save/전체 Save/자동 반영은 출처에 맞춰 선택하고 취소·실패 시 남는 값을 명시한다.
- 같은 객체의 목록·상세·선택지·검색·집계를 하나의 저장소에 연결한다. 이미 구현된 소비 화면은 재조회하고 아직 없는 소비 화면은 후속 Goal의 연결 검증에 남긴다.
- 조회는 초기 로딩·빈 데이터·필터 무결과·오류·권한 제한, 변경은 pending·성공·검증 오류·실패·재시도를 해당 행동에 맞게 준비한다.
- 로컬 목: [화면 상태 기준](<../MOCK-UI-STATE.md>)에 따라 표시·입력·변경을 프론트 내부에서 처리한다. API 명세·HTTP adapter·DB 스키마는 작성하지 않는다.

## 6. 이번 기능에서 잊지 말아야 할 질문

원본 질문을 보존한 목록이다. 화면·사용자 동작은 이번 FE 범위에서 확인하고, API·DB·서버 정책·실계정 동작은 후속 메모로 남긴다. 후자의 답을 확정하는 것은 이 Goal의 착수·완료 조건이 아니다.

- [ ] Monthly 전환 결과·세금·국가·통화·최소 좌석 조건은 미수록이다.
- [ ] 공개 CTA의 가입/기존 계정 구독 변경 라우팅을 확인한다.
- [x] 구형 캡처와 2024-01-18 보관본을 구현 기준으로 채택했다. 현재 비즈니스 가격 정책을 혼합하지 않는다.
- [ ] 단계 01: 월간 전환·실제 연간 총액·세금 미확인.
- [ ] 단계 02: 실제 제한 수·예외·현재 권한 조건 미확인.
- [ ] 단계 03: 좌석 역할별 과금·세금 국가 제한·구매 결과 미확인.
- [ ] 영상 전체·자막·모바일 카드 배열·누락된 후기 행을 확인한다.
- [ ] 리뷰 외부 원본·동의·선정 기준은 미확인이다.
- [ ] 단계 01: 집계 시점·외부 링크 목적지 미확인.
- [ ] 단계 02: 자막·재생 플랫폼·모달 여부 미확인.
- [ ] 단계 03: 후기 원본·검증·정렬 기준 미확인.
- [x] 단계 04: 보관본에서 30카드·목록 끝·중간 누락 행을 확인했다. 모든 카드를 Gummble에서 관찰한 것은 아니다.

질문의 체크는 근거·선택·미해결 처리 위치를 남겼다는 뜻이다. 모든 Bonsai 동작을 검증했다는 뜻은 아니다. 관련 R Goal의 결과와 충돌하면 구현 전에 정리한다.

이번 질문의 처리 근거는 [R01 결과 10절](../../RESULTS/R01_RESULT.md)과 [G04 결과 2·4·8절](../../RESULTS/G04_RESULT.md)에 있다. 월간 $25/$39/$79와 후기 30개·누락 행·외부 목적지는 2024-01-18 보관본으로 보완했다. 원본 월간 화면 실행·촬영일·원본 모바일·영상/자막은 미확인이다. $21/$32/$66의 12배는 계산 소계이며 실제 연 청구액이 아니다. 익명 G10/가상 로그인 G79 분기는 명시적 로컬 목 가정이며 실제 구독·권한을 바꾸지 않는다. 서버 정책 질문은 후속 메모다. 미해결 원본 항목의 체크는 유지한다.
