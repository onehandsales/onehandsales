## 신규 공식 보완과 충돌

다음은2026-11-21 조회한 현재 문서이며2024 전후 시안의 UI/정책으로 소급하지 않는다.

- [계정 설정 안내](https://help.hellobonsai.com/en/articles/5588945-how-to-set-up-your-account-in-bonsai): 현재 설정·팀·기능 안내. 빠진 과거 세 번째 설문이나 MYR/USD 관계를 확인할 자료는 없었다. 화면 구조는 시안 유지.
- [권한 안내](https://help.hellobonsai.com/en/articles/1894805-all-about-user-permissions-in-bonsai): Owner/Partner/Project Manager/Collaborator 구분을 확인했다. Owner/Partner는 폭넓은 관리 접근, PM/Collaborator는 재무/회사 설정 제한이 설명된다. 현재 사용자 정의 권한은 과거 캡처의 고정 역할표가 아니다.
- [2FA 안내](https://help.hellobonsai.com/en/articles/7935122-managing-two-factor-authentication-2fa-on-your-account): 검색 결과의2026-06-17 문서가6자리 코드와 이메일/SMS를 설명한다. 과거 로그인 플로우에는2FA 화면이 없으므로 기본 캡처 경로에 현재 필수 정책을 강제하지 않는다. 별도 명시적 목 분기로 다룬다. 이 문서의 이미지/실계정은 이번에 확인하지 않았다.
- 가입/로그인/재설정 정적 보관본 조회 시도는 [별도 기록](evidence/r02/archive-fetch.json). 보관본 날짜·일치 여부를 확인한 자산만 보완하고, scripts·계정 동작은 실행하지 않는다.

### 상태 수명과 격리

1. 현재 G01 메모리 session/workspace/revision 정책을 유지한다. 공개 이메일·목록 캐시·일반 초안 전체를 인증 후 계속 보존하도록 초기화를 해제하지 않는다.
2. 인증을 시작할 때 선택한 공개 intent만 복사한다. 성공 후 새 actor/workspace/revision에 명시적으로 귀속된 인계로 저장한다. 다른 이력의 선택·다른 사용자의 초안은 가져오지 않는다.
3. 동일 탭의 완료된 목 계정/회사 데이터와 진행 중 초안은 구분한다. logout/계정·workspace 변경은 진행 작업·초안·인계 무효화, 새로고침/새 탭/Reset은 초기 seed. 시나리오 변경도 진행 작업을 취소한다.
4. route 이탈/취소/입력 변경/세션 전환 뒤 지연된 성공·실패는 현재 화면을 덮지 못한다. 중복 제출과 같은 이메일 동시 가입은 저장 직전에 다시 검증한다.
5. G06 공개 template ID/format과 G07 invoice ID/rows/calc는 G10→G13→G14에서 같은 snapshot을 확인한다. 계정 편집기/PDF/구독 변경 완료로 표시하지 않는다. 생성기 복귀 시 선택한 초안만 명시 복원한다.

## 검토 판정·남은 범위

1차: 43단계 metadata/PNG와 화면별 관찰·현재 도움말·기존G01 상태를 대조. 누락 설문·2FA·메일·실제 인증을 캡처 성공으로 해석하지 않는다.

2차: 공개 intent가 기존 revision 초기화에 유실되는 연결 위험을 확인하고 선택한 snapshot의 명시 전달을 요구했다. 전역 reset 해제·새 계정을 Alex로 합치기·가격/문서를 생성 완료로 표시하기를 금지한다. 재설정 weak의 원본 필드 초기화와 일시 실패의 입력 보존을 분리했다. 소비 명세와 backlog에 배정한다.

화면/상호작용 자료 부족: 과거3번째 설문/전체 옵션/원본 모바일, 소셜/메일/2FA의 과거 UI, 정확한 강도 알고리즘, 중단 복구/만료 시간. 목 경로로 가능한 검증을 진행하되 원본 재현 완료로 쓰지 않는다. 서버 후속: 세션/토큰/소셜 계정 연결/중복 이메일/메일 발송/역할 권한/초대 과금·수락/실제 영속 정책. API/DB 계약은 만들지 않았다.

G10→G11→G12→G13에서 이 결과를 소비하고 G14에서 공개 인증 왕복, G15에서 같은 회사 저장을 검증한다. 초대 수락·재발송·제거 전체는 G17/G18 미착수로 유지한다.
