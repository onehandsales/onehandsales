## 주요 결함 수정과 공통 구조

- PublicProvider의 pathname별 이메일과 이력별 선택 snapshot을 확장했다. 인증 commit 때 선택된 인계만 새 scope로 옮기고, 전체 reset을 해제하지 않았다. 공개/업무/공유 캐시와 편집 수명을 분리했다.
- returnTo가 가입·확인·복구·온보딩 단계에서 유실되는 연결을 수정했다. 인증 후 실제 선택 화면/명시적 복귀가 있고 브라우저 POP만으로 오래된 입력을 재적용하지 않는다.
- 검색/필터/취소 후 늦은 결과, 도움말 헤더 검색 경합, 이메일 중복 제출·초안 보존, 생성기 소수/세금 계산을 필요한 단위/브라우저 회귀로 확인했다.
- G14 셸 전체 재생성 때문에 닫히던 검증 도구를 업무 콘텐츠 scope와 분리했다. 축소/폭 변경/모달의 포커스·좁은 화면 실제 경계를 보완했다.
- G15 Save 재시도 때 오류 영역이 사라져 두 번째 클릭이 모달 바깥으로 떨어지는 문제를 수정했다. 저장 후 포커스는 모달 정리 뒤 다음 안내로 이동한다. 빈 초대 문자열이 팀 완료로 계산되던 seed도 정리했다.
- 로고 File은 실제 디코딩 후 메모리에 저장하고 object URL은 표시 중만 유지한다. 교체/제거/이탈에서 해제하고 늦은 디코딩을 폐기한다. 주소 하위 Save와 회사 전체 Save를 구분한다.
- 최종 전체 첫 실행81/82의 실패는 G03 테스트가 이전 `Public` 이름을 찾던 전제였다. G14 실제 `Public site` 링크를 사용해 검증을 유지하고 전체를 다시 실행했다. 실패 이력은 지우지 않았다.

## 남은 차이와 대기

- **자료:** 일부 블로그/템플릿/도움말 본문·전체 분류·영상/자막·정책 원문/버전 관계, 제휴 보상 문구 관계, 원본 소셜/2FA/메일·누락 설문·익명 공개 off 등. 미확인 부분은 안내/가정/후속으로 표시했다. 가짜 본문·영상·발송·결제 성공을 만들지 않았다.
- **시각:** 원본의 정확한 폰트 메타데이터·viewport/DPR·일부 아이콘·간격/글줄, 미수록 내용 때문에 달라지는 문서 높이, 대비/취소·목 안내를 위한 명시적 차이, 회사 주소/샘플 신원/slug·체크리스트 상태가 남는다. 각 비교 쌍의 숫자를 완전 일치율로 쓰지 않았다.

- **후속 서버 메모:** 실제 인증/메일/세션/역할·초대, 국가/통화/청구, 정책의 효력, 게시/파일 제한/기존 문서 스냅샷 반영은 확정하지 않는다. 현재 화면 작업의 대기를 이유로 Backend 범위를 추가하지 않았다.
