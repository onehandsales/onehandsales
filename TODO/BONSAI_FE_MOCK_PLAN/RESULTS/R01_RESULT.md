## 3. G02 구현 결정과 남은 질문

- 기본 `/`는 hero → 제품 홍보 이미지 → 3군 기능 링크 → 후기 → 금융 → 고객 경험 → 짧은 후기 → 지원/체험 → 최종 CTA → 5열 푸터 순서다. 과거 정책은 원본 카피 재현이며 우리 서비스 정책으로 확정하지 않는다.

- 헤더 메뉴는 보관 HTML의 hover 설정과 캡처를 바탕으로 hover/click을 제공하고, 키보드 Enter/Tab/Escape·초점 복귀는 명시적 접근성 구현으로 검증한다. 모바일 배열·메뉴 조작의 Gummble 동일성은 미확인이다.

- 가입 입력은 메모리에만 보관한다. 이메일을 URL·localStorage·로그에 넣지 않는다. 뒤로 복귀는 입력 유지, 명시적 취소/초기화·새로고침은 제거한다. 실제 인증·저장은 없다.
- 미구현 목적지는 후속 Goal·미구현 상태·랜딩 복귀를 표시하는 인계 화면으로 연결한다. G03 이후 콘텐츠를 대신 구현하지 않는다.
- 실제 금융 국가·보험·환불·리뷰 동의·계정 정책과 서버 저장 여부는 UX/UI 완성 이후 별도 확인한다.
