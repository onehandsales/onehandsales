# CRM 20개를 이해하기 위한 읽는 순서

작성 기준일: 2026-11-16

추가 학습 안내 갱신일: 2026-11-17

CRM을 처음 접하는 사람이 각 제품의 쓰임을 이해하고, OneHand CRM의 참고 제품을 선택하기 위한 비교 자료다. Attio, folk 또는 특정 업종을 최종 방향으로 확정하지 않는다. 고객마다 작업 옵션과 가격 조건이 달라 수기로 관리하는 청소 사업 사례를 평가에 활용한다.

## 지금 이어서 읽을 문서

현재는 ‘여러 거래 관리 → 앱 안에서 견적 작성 → 실제 작업 → 청구’라는 요구에 맞춰 Bonsai를 우선 학습하는 단계다. 하나의 제품을 따라 만든 뒤 자신의 방식으로 변경한다는 방향을 유지한다. 초기 타깃은 검증 가설이며 기존 제품·UX 결정을 변경한 것은 아니다.

1. [Bonsai 학습 계획과 초기 타깃 고객](CRM_Bonsai_학습계획과_타깃고객.md): 먼저 읽을 문서. 가상 개발 프로젝트 하나로 기능의 역할을 이해하고, 누구의 업무를 먼저 검증할지 정리했다.
2. [Bonsai 기능 지도와 확인 사항](CRM_Bonsai_기능지도와_확인사항.md): 필요할 때 참고할 문서. 공식 기능과 출처, Assembly와의 차이, 청소업 요구와 미확인 사항을 모았다.

## 20개 CRM 비교 자료를 처음부터 읽는 순서

1. [CRM 공통 개념](CRM_공통개념.md): 고객 정보, 거래, 이력, 할 일, 진행 단계가 무엇인지 먼저 이해한다. 공통 설명은 이 파일에만 모았다.
2. [20개 CRM의 차별점과 업무 예시](CRM_20개_차별점과_예시.md): 제품마다 누구의 어떤 문제를 해결하는지 가상 업무 사례로 비교한다.
3. [공식 문서와 확인 범위](CRM_공식문서_출처.md): 설명의 근거, 문서 종류, 제품 변경과 미확인 사항을 확인한다.

## 예시를 읽는 방법

차별점 문서의 회사, 인물, 거래 조건, 수량은 이해를 돕기 위해 만든 가상 예시다. 실제 고객 성공 사례나 직접 실행한 테스트가 아니다. 제품 기능 설명에는 공식 출처를 연결했고, 그 기능을 어떤 업무에 적용할지는 예시로 풀었다.

‘특화’는 다른 제품에는 해당 기능이 없다는 뜻이 아니다. 해당 제품이 어떤 문제와 업무를 중심으로 구성돼 있는지를 뜻한다. 예를 들어 Assembly와 Bonsai 모두 고객 포털을 제공하지만, 이 비교에서는 각각 고객과 협업하는 공간과 견적·프로젝트·청구의 연결을 중심으로 설명한다.

## 이 비교의 범위

- 대상은 사용자가 전달한 20개 서비스다. 최초에 언급한 26개 중 전달되지 않은 6개는 추정하지 않았다.
- Mutlnyhq, Assenbly, Bonsal은 각각 공식 이름인 Mutinyhq, Assembly, Bonsai로 정리했다.
- 19개 서비스는 공식 사이트의 도움말·제품 문서·공식 설명을 확인했다. Freckle과 Clay는 각각 공식 제품 공지와 공식 활용 가이드를 중심으로 설명했다.
- Distrobird는 공식 사이트 접근 제한으로 최신 도움말 확인을 완료하지 못했다. AppSumo에 창업자가 직접 작성한 2023년 설명을 별도로 표시해 사용했다.
- Nicelydone MCP 화면 수집과 실제 계정 조작은 수행하지 않았다. 문서의 업무 예시를 검증된 화면 순서로 취급하지 않는다.
- 기능의 요금제별 제공 범위, 한국어·한국 전화번호 지원, 국내 청구·세무 연동은 제품 선택 후 해당 기능을 대상으로 확인할 항목이다.

현재 저장소의 기존 제품 방향 문서는 이 비교 자료로 덮어쓰지 않았다. 이번 사용자 지시인 ‘20개 이해 → 비교 → 참고 제품 선택 → Nicelydone으로 UX와 흐름 조사’를 이 자료의 기준으로 삼았다.
