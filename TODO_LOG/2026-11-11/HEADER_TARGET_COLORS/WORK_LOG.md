# 헤더 대상 아이콘·제목 색상과 구분자

- 요청: 헤더 대상 아이콘을 #6B7280, 제목 텍스트를 #111827로 맞춘다.
- 변경: 대상 아이콘은 이미 #6B7280이므로 유지하고 대상 제목 h1의 색상을 #4B5563에서 #111827로 변경했다. 20×20px 아이콘과 제목 14px/500 및 기존 레이아웃은 유지한다.
- 검증: 변경 컴포넌트 ESLint와 `git diff --check`를 통과했다. 대상 아이콘·제목의 색상 클래스를 확인했으며 단순 색상 변경이므로 신규 테스트 작성이나 브라우저 테스트 재실행은 하지 않았다.

## 제목과 보기 사이 구분자

- 요청/변경: 기존 1px CSS 세로 구분선을 `/` 문자로 변경한다. 구분선 색상 #E7E6E2와 좌우 여백, 장식용 aria-hidden을 유지한다.
- 검증: 변경 컴포넌트 ESLint와 `git diff --check`를 통과했다. 구분자 표시만 변경하여 신규 테스트 작성이나 브라우저 테스트 재실행은 하지 않았다.

## 헤더 버튼 기본·호버 색상

- 요청: 보기 선택·즐겨찾기·검색·필터·정렬·보기 설정의 기본 아이콘/텍스트를 #9CA3AF/#4B5563, hover를 #6B7280/#111827로 맞추고 누르는 동안 배경 #D3D1CB를 적용한다.
- 변경: 보기 선택 아이콘·펼침 화살표에 전용 hover 색상을 적용하고 공통 도구 버튼의 텍스트와 아이콘 색상을 분리했다. 미등록 하트에도 같은 기본/hover 아이콘 색상을 적용한다. 기존 enabled:active 배경 #D3D1CB와 hover 배경 #E4E2DC를 유지한다.
- 상태 표시: 등록된 즐겨찾기의 붉은 하트는 유지한다. 열린 도구·입력된 검색어·적용된 필터/정렬의 파란색은 상태 표시로 유지하며 도구 아이콘의 hover는 #6B7280이다. 앞서 변경한 대상 제목·아이콘·슬래시와 파란 기록 추가 버튼은 보존한다.
- 검증: 변경 컴포넌트 2개 ESLint와 `git diff --check`를 통과했다. 기존 API mock Playwright 헤더 UX·즐겨찾기 키보드/반응형 시나리오 2개가 통과했다(25.8초).
- 색상 실측: 기존 API mock을 사용한 브라우저 검사에서 6개 버튼의 기본 아이콘 #9CA3AF → hover #6B7280, 보기 이름 #4B5563 → #111827, hover 배경 #E4E2DC → 누름 #D3D1CB → 해제 #E4E2DC를 확인했다. 보기 선택의 양쪽 아이콘도 같은 값이며 모두 16px이다. 열린 도구의 상태색·등록된 하트의 빨간색·disabled 버튼의 active 제외와 파란 + 버튼 28×28px도 확인했고 API 쓰기는 0회다. 신규 테스트는 추가하지 않았다.

## 오른쪽 도구 영역 구분선 제거

- 요청/변경: 사용자가 지정한 mx-1/h-3.5/w-px 세로 구분선 span을 제거했다. 이 요소는 코드에서 기록 추가 버튼 앞에 렌더링되며 버튼의 조건부 표시·28×28px 크기·클릭 처리는 유지한다. 기존 제목 옆 `/` 구분자는 보존한다.
- 검증: 헤더 컴포넌트 2개 ESLint와 `git diff --check`를 통과했다. 이번 변경은 장식용 span 제거로 한정하여 신규 테스트 작성이나 기존 브라우저 테스트 재실행은 하지 않았다. 앞선 헤더 색상 변경은 기존 회귀 테스트 2개와 브라우저 색상 실측을 완료했다.
