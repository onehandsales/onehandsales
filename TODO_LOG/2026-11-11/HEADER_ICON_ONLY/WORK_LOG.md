# 헤더 도구 버튼 아이콘 표시

- 요청: 헤더의 검색·정렬·필터·보기 설정 버튼에서 텍스트를 제거하고 아이콘만 표시한다.
- 변경: 공통 ToolbarButton의 라벨·조건 개수 span과 불필요한 props를 제거했다. 모든 화면 폭에서 아이콘만 렌더링하고 `aria-label`과 기본 hover 안내용 `title`로 기능 이름을 제공한다. 기존 SlidersHorizontal 변경, 16×16px 아이콘, 활성·hover·누름 상태와 팝오버 조작은 유지한다.
- 검증: 변경 컴포넌트 ESLint, User Web typecheck, `git diff --check`를 통과했다. 기존 API mock Playwright 헤더 UX 1개가 통과했다(18.8초). 필터·정렬·보기 설정 조작과 Esc 포커스 복귀, 1440/1024px의 38px 헤더 배치를 확인했다. `TEMP/header-icon-only-20261111/` 캡처에서 네 버튼의 텍스트·조건 개수 없이 아이콘과 활성 상태만 표시되는 것을 확인했다. 신규 테스트는 추가하지 않았다.

## 기록 추가 버튼 크기

- 요청/변경: 파란색 기록 추가 버튼을 32×28px에서 28×28px로 변경한다. h-7/w-7과 p-0/justify-center를 적용해 16×16px + 아이콘을 중앙에 배치한다.
- 검증: 변경 컴포넌트 ESLint와 `git diff --check`를 통과했다. 고정 너비·높이 및 중앙 정렬 클래스 적용을 확인했으며 크기 변경만으로 별도 테스트는 추가하거나 재실행하지 않았다.
