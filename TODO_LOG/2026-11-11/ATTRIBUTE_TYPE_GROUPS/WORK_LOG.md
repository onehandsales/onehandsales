# 속성 유형 팝오버 그룹 구분

- 요청: 컬럼 생성 팝오버의 17개 유형을 사용자가 지정한 예상 사용 빈도 기준 8개·4개·5개로 구분한다.
- 변경: 첫 그룹은 텍스트, 숫자, 선택, 상태, 날짜, 금액, 체크박스, 전화번호다. 두 번째는 이메일, 위치·주소, 기록 참조, 행위자 참조이며 세 번째는 날짜 및 시간, 평점, 도메인, 사람 이름, 상호작용이다. 그룹 사이에 가로 구분선을 추가하고 기존 2열 배치·340px 폭·12px 텍스트·16px 아이콘·상태별 색상은 유지한다.
- 검색: 검색어가 있으면 일치하는 유형만 구분선 없이 모아서 표시한다. 검색어를 지우면 세 그룹을 다시 표시하며, 검색 및 방향키 이동에 같은 표시 순서를 사용한다.
- 범위: User Web 팝오버와 관련 UI 문서만 변경한다. API·DB 계약과 생성 동작은 유지한다.
- 검증: 변경 컴포넌트 ESLint, User Web typecheck, `git diff --check`를 통과했다. 기존 API mock Playwright 4개(이름→유형 생성·재조회, 빈 초안 바깥 클릭 취소, 키보드 검색 생성, 영문 모바일)가 모두 통과했다(44.8초). 신규 테스트는 추가하지 않았다.
- 브라우저 확인: 기존 API mock으로 실제 DOM을 측정해 8개·4개·5개 순서와 구분선 2개, 팝오버 340×408px, 텍스트 12px·아이콘 16×16px·2열을 확인했다. 체크박스→이메일, 기록 참조→날짜 및 시간의 아래 방향키 이동이 정상이며, `날짜` 검색 시 서로 다른 그룹의 두 결과가 같은 행에 표시되고 구분선은 사라진다. 검색을 지우면 17개·구분선 2개가 복원되고 검사 중 API 쓰기는 0회다.
- 화면 확인: `TEMP/attribute-type-groups-manual-20261111/popover-grouped.png`와 `TEMP/attribute-type-groups-20261111/`의 영문 모바일 캡처에서 그룹별 간격, 전체 목록 표시와 화면 안 배치를 확인했다.
