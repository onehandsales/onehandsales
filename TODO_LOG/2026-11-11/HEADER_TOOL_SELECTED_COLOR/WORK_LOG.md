# 헤더 도구 선택 색상

- 요청: 검색·필터·정렬·보기 설정 버튼을 열었을 때 파란색 대신 hover 배경 #E4E2DC를 유지한다.
- 변경: 공통 ToolbarButton의 선택 배경을 #E4E2DC, 아이콘을 #6B7280, 텍스트를 #111827로 맞췄다. 검색어·필터·정렬 조건에 따른 선택 상태도 같은 색상을 사용한다. 누르는 동안 배경 #D3D1CB와 버튼 28×28px·아이콘 16×16px를 유지한다.
- 검증: 변경 컴포넌트 ESLint와 `git diff --check`를 통과했다. 기존 API mock 브라우저 검사에서 네 버튼 각각의 팝오버를 열고 마우스를 벗겨도 배경 #E4E2DC·아이콘 #6B7280가 유지됨을 확인했다. hover·누름 #D3D1CB·해제 #E4E2DC, 버튼 28×28px·아이콘 16×16px를 실측했다. 즐겨찾기·기록 추가·disabled 상태도 기존 동작을 유지하며 쓰기 요청은 0회다. 신규 테스트 파일은 추가하지 않았다.
