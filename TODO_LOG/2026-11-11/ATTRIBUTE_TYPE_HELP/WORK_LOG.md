# 속성 유형 도움말

- 요청: 컬럼 생성 유형 항목을 hover하면 `?`가 자연스럽게 나타나고, 아이콘에 마우스를 올리면 클릭 없이 해당 유형의 설명을 표시한다. 승인된 17개 설명에서 예시는 제외하고 프론트엔드에서 관리한다.
- 변경: 한국어·영어 `attributeTypeDescriptions` 리소스와 도움말 표시를 추가했다. 아이콘은 16px·150ms opacity 전환이며 250ms hover 후 설명을 연다. 도움말은 12px 텍스트로 표시하고 위치를 viewport에 맞춰 보정한다. 아이콘에서 설명으로 이동하는 동안 120ms 닫기 유예를 둔다.
- 조작: 도움말 클릭은 유형 선택·컬럼 생성을 막는다. 키보드 포커스로도 설명을 표시하고 접근성 설명을 연결한다. 열린 도움말은 Esc로 먼저 닫으며 초안은 유지한다. 검색·resize·unmount 시 도움말과 예약된 타이머를 정리한다. 스크롤 시 hover 설명은 닫고, 키보드 포커스 항목이 목록에 보이면 위치를 보정해 유지한다. 터치 화면에서는 아이콘을 표시하고 탭으로 설명을 연다.
- 보존: 기존 8/4/5 그룹, 팝오버 340px 폭, 유형별 아이콘·텍스트·상태 색상, 검색·생성 흐름을 유지한다. 한국어 문구는 사용자가 승인한 설명 문장을 사용한다. API·DB 변경은 없다.
- 보완: 터치 시 pointerleave가 설명을 닫는 문제를 발견해 터치에는 hover 종료 처리를 적용하지 않도록 수정했다. 낮은 화면에서 키보드 End 이동으로 목록이 스크롤되면 설명이 닫히는 문제도 보완하여 포커스 항목이 보이는 동안 위치를 갱신한다.
- 정적 검증: 변경된 4개 TS/TSX 파일 ESLint, User Web typecheck, `git diff --check`를 통과했다.
- 기존 회귀 검증: API mock Playwright 4개(이름→유형 생성·재조회, 빈 초안 바깥 클릭 취소, 키보드 검색 생성, 영문 모바일)가 최종 코드에서 모두 통과했다(33.6초). 신규 테스트 파일은 추가하지 않았다.
- 브라우저 검증: 기존 API mock 기반 보조 검사에서 한국어·영어 각각 17개 설명, `aria-describedby`, 아이콘 fade, 클릭 없는 표시, tooltip 위 이동·클릭 유지, 화면 가장자리 보정을 확인했다. 이름을 입력한 상태에서 도움말 아이콘·본문을 클릭해도 쓰기는 0회이며 실제 유형 선택 시에만 Currency 생성 1회가 발생한다. 키보드 포커스·Esc·방향키, 검색 전환, 터치 탭, 390×360 화면의 End 키 스크롤 후 설명 표시도 통과했다.
- 캡처: `TEMP/attribute-type-help-manual-20261111/`의 한국어·영어·터치·낮은 화면 캡처를 확인했다. 회귀 테스트 산출물은 `TEMP/attribute-type-help-final-20261111/`에 있다. 실제 업무 DB에는 접근하지 않았다.
