# 헤더 도구 버튼 크기

- 요청: 검색·필터·정렬·보기 설정 버튼의 실제 hover/누름 크기를 확인하고 28×28px로 맞춘다.
- 확인: 변경 전 1440px·390px 화면에서 네 버튼의 기본·hover·누름·해제 상태가 모두 32×28px였다. 16px 아이콘과 양쪽 8px padding이 너비를 구성했다.
- 변경: 네 버튼이 공유하는 ToolbarButton에 w-7/p-0을 적용해 28×28px로 고정하고 기존 flex 중앙 정렬로 16×16px 아이콘을 배치한다. 추가 도구 등 다른 CONTROL_CLASS 사용처에는 고정 폭을 적용하지 않는다.
- 검증: 변경 컴포넌트 ESLint와 `git diff --check`를 통과했다. 기존 API mock 브라우저 검사에서 1440px·390px 화면의 네 버튼이 기본·hover·누름·해제 모두 28×28px, 아이콘은 16×16px임을 실측했다. hover #E4E2DC → 누름 #D3D1CB → 해제 #E4E2DC도 확인했고 쓰기 요청은 0회다. 신규 테스트 파일은 추가하지 않았다.

## 사이드바 열기 버튼

- 요청/변경: 사이드바 열기 버튼을 32×32px에서 28×28px로, 내부 Menu 아이콘을 16×16px에서 20×20px로 변경한다. 기존 중앙 정렬, 색상·hover·누름 상태, 툴팁과 열기 동작은 유지한다.
- 검증: AppShell ESLint와 `git diff --check`를 통과했다. 기존 API mock 브라우저에서 사이드바를 접은 뒤 열기 버튼의 기본·hover·누름 크기 28×28px와 아이콘 20×20px를 실측했다. hover/누름 배경과 클릭 후 사이드바가 다시 열리는 동작도 확인했고 쓰기 요청은 0회다. 신규 테스트 파일은 추가하지 않았다.

## 헤더 좌우 패딩

- 요청/변경: 첨부 HTML의 상단 헤더 좌우 패딩을 12px에서 10px로 줄인다. AppShell의 데스크톱 관리항목·업무목록 헤더와 모바일 헤더에 px-[10px]를 적용한다.
- 검증: AppShell ESLint와 `git diff --check`를 통과했다. 기존 API mock 브라우저 검사에서 1440px·390px 화면 모두 실제 좌우 padding 10px와 기존 헤더 높이 38px를 확인했다. 신규 테스트 파일은 추가하지 않았다.
