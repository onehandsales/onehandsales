# 데모 요청 단계 이미지의 아이콘 전환

- 작업 일자: 2026-11-07
- 상태: 완료
- 요청: 문의 흐름의 이메일·인원·문서·완료 이미지를 같은 계열의 아이콘으로 통일하고 기존 이미지 파일을 삭제한다. 완료는 파란 원형 바탕의 흰색 체크 스타일을 사용한다.
- 관련 규칙: `AGENTS.md`, `AGENT/SOFTWARE_AGENT/FRONT_AGENT/README.md`, `AGENT/PM_AGENT/DECISIONS/022_goal_completion_review_todo_log.md`

## 범위와 진행 기록

- 입력 4단계와 완료 화면, 총 5개 상태에서 이미지가 표시된다. 상세정보와 사용계획 단계는 같은 문서 이미지를 공유한다.
- 문의 페이지 외에 해당 이미지 파일을 참조하는 FE 코드가 없음을 확인했다.
- 기존 BE/Object 생성 관련 변경과 저작권 문구 수정을 보존한다.
- 이미지 생성 스킬 대신 기존 `lucide-react` 아이콘을 사용한다.

## 예정 변경

- 이메일 Mail, 인원 UsersRound, 상세정보·사용계획 FileText, 완료 Check 아이콘을 같은 원형 스타일로 표시한다.
- 이미지 렌더링과 파일 경로, 이미지 전용 밝기 보정을 제거한다.
- Contact 전용 SVG 4개와 직전 생성 PNG를 삭제한다.

## 적용 결과

- `FE/user-web/src/pages/contact/index.tsx`: 이미지 경로 대신 Lucide 컴포넌트 매핑을 사용한다. 오른쪽 장식 영역은 160px 파란 원형 배경과 72px 흰색 아이콘으로 통일했다. 완료 아이콘은 기존 완료 표시와 같은 Check를 사용한다.
- 이메일 Mail, 인원 UsersRound, 상세정보·사용계획 FileText, 완료 Check 적용.
- 기존 모바일 장식 숨김 및 데스크톱 2열 레이아웃을 유지했다.
- `FE/user-web/public/public-site/contact/`의 SVG 4개와 생성 PNG 1개를 삭제했다. 해당 디렉터리에 이미지가 남아 있지 않음을 확인했다.
- 이전 이미지용 밝기 보정, `<img>` 렌더링 및 경로 매핑을 제거했다.

- `fnm exec --using=24.21.0 pnpm run typecheck`: 통과.
- `fnm exec --using=24.21.0 pnpm exec eslint src/pages/contact/index.tsx`: 통과.
- 변경 파일의 `git diff --check`: 통과.
- FE 소스/공개 자산에서 삭제 이미지 경로와 이전 컴포넌트 이름의 잔존 참조 없음.
- Chrome/Playwright: 데스크톱 1440px, 모바일 390px에서 이메일 → 인원 → 상세정보 → 사용계획 → 완료, 각 5개 화면의 아이콘 매핑 확인.
- 모든 단계에서 배경색 `rgb(72, 128, 238)`, 흰색 아이콘, 같은 160px 규격 확인. 모바일은 기존 정책대로 장식 영역을 숨긴다.

- 이메일 및 완료 화면 캡처를 직접 확인했다.

## 검증 중 보정 사항

- 최초 확인 코드가 페이지의 모든 `<img>`를 검사해 브랜드 로고까지 포함했다. 삭제 대상인 Contact 이미지 경로만 확인하도록 검사 범위를 수정했다.
- 한 차례 검증용 Chrome 실행이 지연되어 해당 검증 프로세스만 종료했다. GPU 비활성화 옵션과 실행 제한 시간을 설정해 다시 실행했고 전체 검증을 통과했다.
