# 데모 요청 화면의 세로 중앙 정렬

- 작업 일자: 2026-11-07
- 상태: 완료
- 요청: 오른쪽 아이콘을 위로 옮기고 입력 내용이 아래에 오도록 문의 흐름 전체를 한 열로 중앙 정렬한다.
- 관련 규칙: `AGENTS.md`, `AGENT/SOFTWARE_AGENT/FRONT_AGENT/README.md`, `AGENT/PM_AGENT/DECISIONS/022_goal_completion_review_todo_log.md`

## 범위와 진행 기록

- 작업 전 Git 상태와 Contact 화면을 확인했다. 다른 작업의 BE/Object 관련 변경과 기존 UI 변경을 보존한다.
- 입력 4단계와 완료 화면에 공통으로 적용되는 2열 레이아웃을 세로 배치로 변경한다.
- 아이콘·진행 표시·제목·설명은 중앙에 배치하고 입력 필드의 읽기 방향은 유지한다.
- 모바일에서도 상단 아이콘을 표시하며, 긴 상세정보 화면은 자연스럽게 스크롤할 수 있도록 한다.
- 완료 화면은 상단 공통 체크 아이콘을 사용하므로 기존 작은 체크 아이콘 중복을 제거한다.
- 작업 중 크기 요청이 40×40px에서 60×60px로 수정되었다. 최종 상단 원형 아이콘은 모든 화면 크기에서 60×60px, 내부 아이콘은 30×30px로 적용한다.

## 적용 결과

- `FE/user-web/src/pages/contact/index.tsx`의 공통 화면을 아이콘 → 진행 표시 → 제목·설명 → 입력 폼 순서의 한 열로 변경했다.
- 본문 최대 너비는 기존 508px를 유지하고 제목·설명·진행 표시·완료 버튼을 중앙 정렬했다.
- 모든 단계의 원형 아이콘은 60×60px, 내부 Lucide 아이콘은 30×30px다.
- 모바일에서도 아이콘이 표시되며, 완료 화면의 중복 체크 아이콘을 제거했다.

## 검증 결과

- User Web 타입 검사 및 Contact 파일 ESLint 통과.
- 변경 파일 `git diff --check` 통과.
- Chrome/Playwright: 데스크톱 1440px와 모바일 390px에서 입력 4단계와 완료 화면을 각각 확인했다.
- 10개 상태 모두 실제 렌더링 원형 크기 60×60px와 내부 아이콘 30×30px를 확인했다.
- 아이콘과 본문 중심이 화면 중심과 일치하고, 아이콘이 본문 위에 배치되며 제목이 가운데 정렬되는 것을 좌표와 스타일로 확인했다.
- 가로 넘침·페이지 실행 오류·이전 Contact 이미지 요청 없음. 완료 체크 아이콘은 한 개다.
- 단계 전환과 완료 표시는 모의 API 응답으로 확인했고 실제 문의를 제출하지 않았다.
- 최종 데스크톱과 모바일 이메일 화면 캡처를 직접 확인했다.
